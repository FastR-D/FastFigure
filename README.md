# FastFigure

面向计算机类期刊和会议的 PC 科研绘图工具。工作区占满浏览器可用宽度，只维护 1920×1080 桌面验收；测试按核心风险与完整流程维护，见[开发与验收约定](docs/development/testing.md)。保留完整调研资料。

## 本地运行

需要 Node.js 22.18+ 和 pnpm 10。项目不使用 monorepo。

```bash
pnpm install
pnpm dev
```

访问 `http://127.0.0.1:5178`。`pnpm build` 生成 `dist`，`pnpm preview` 在 4178 端口预览构建结果。

## 当前功能

当前优先迭代素材、箭头和样式，新增数据绘图暂停。导出支持 SVG、PNG 和工程 JSON，draw.io / PPTX 导出相关代码已移除。

- 论文结构图：二十二类原生配方覆盖分层架构、层级树、中心辐射、单／双循环、泳道协作、集合交叠、同心圈层、结构矩阵、金字塔／漏斗，以及 FPN 多尺度融合、CLIP 式双编码器配对、U 形编解码拼接跳连、残差／瓶颈块、邻域消息传递、Top-1 专家路由、训练／推理分阶段、掩码预训练迁移，以及近期录用论文启发的时序记忆读写和跨视图／逐视图交替注意力、混合序列权限矩阵和连续条件去噪，支持参数配置、独立图元编辑和助手复用。入口为“组件 → 参数化组合 → 论文结构图”；[使用](docs/development/structural-figures.md)、[FastPPT 原图分析](docs/research/2026-10-31-ppt-structure-figures.md)、[双环与交叠扩展](docs/research/2026-10-31-relational-structures.md)、[近期录用主图与编排](docs/research/2026-10-31-recent-mainfigures.md)、[多模态结构与视觉设计](docs/research/2026-10-31-multimodal-mainfigures.md)、[旧架构视觉改造](docs/research/2026-10-31-architecture-visual-design.md)。

- 素材快速居中、以已有对象为样本统一主文字 / 描边 / 填充、导入文字可选重排；按给定坐标生成水平垂直箭头。人和助手共用程序编译、预览与显式应用，支持撤销；[用法与边界](docs/development/material-editing.md)。

- 无边框引线注释：人可新建或批量调整已有注释，预览后只重排引线或一起移动文字；助手使用源别名与受控重排，保留原文、样式和关联对象，支持保留原锚点或明确重选以减少绕行；[用法与边界](docs/development/callouts.md)。

## Harness 绘图助手

点击左侧“助手”Tab，与组件库、图库共用左侧栏，中央画布和右侧属性栏保持可用。参考 FastPPT，将会话切换放在顶部、对话和候选图放在中间、输入框固定在底部；模型设置在侧栏内展开。切换 Tab 会保留对话、草稿和正在运行的任务，关闭助手会回到此前的素材 Tab。

选择 Codex 或 Claude，填写绘图要求后发送。默认使用本机 CLI 的模型配置，也可为两种 Harness 分别指定模型名称。当前工程、选中对象会作为本轮快照发送；勾选“附带当前参考图”会同时传递所选图片。可以让模型解释当前图、修改结构或提出新图，结果通过 FigureIR 校验后显示为候选图。

底部“参考组件”支持自动、手动选择或不附带。自动模式匹配工作组件与内置配方；普通绘图和规划还默认在发送时检索本机库，合并为至多 6 项。可取消“自动检索本机素材库”；本机库支持整段名称优先和常用中英文别名，其他词在预算内覆盖首尾，目前是文字匹配，不是向量或图像语义检索，也不解析否定。发送前列表为候选，实际清单、词组与快照指纹记录在本轮详情，模型可以不使用，具体结构须核对。手动模式按所选内容发送。每轮冻结结构，运行中修改库不影响已发送任务；采用方案后沿用原清单。模型接收尺寸、节点别名和输入输出端口，程序展开结构与新 ID。内置配方可调允许参数，保存组件保留手工编辑。

助手可用 `fit` 声明组件的放置区域，由程序按实际参数生成后的尺寸计算等比缩放；也可直接指定比例。区域、实际比例会显示在复用记录中，越界和碰撞仍拒绝，不自动改变其他对象。

候选图不会自动改写画布。点击“应用候选图”后，侧栏保持打开，可继续编辑节点和连接，也可单步撤销。若生成期间修改过工程，应用按钮会禁用；重新发送要求会采用最新画布。无效 JSON、越界对象、无效端点、组件重叠或容量超限等结果会显示错误并保留原图，原始输出可展开查看。复用组件的名称、参数和来源随结果保留，可再采集入库。失败或取消后可基于当前画布重试。

候选图支持“生成前 / 候选结果”切换，改动清单按对象 ID 比较新增、删除与字段修改，可筛选、展开前后值并定位到预览。标签、图元、层级、几何、端点、样式和来源均参与比较；数组顺序变化不算改动，图片字节不进入报告。历史消息按轮次保留，点击“查看本轮详情”回看输出与预览；已应用或丢弃的结果仅供查看，撤销画布也不会重置处理状态。会话状态同步失败时会保留本页结果，并提供重试。

参考图重建候选下可展开“继续修复候选”，选择分区与修复重点，补充具体问题，准备后再发送。每一版在最终应用前都保留为候选，失败或取消可回看上一版，空补丁也保留原候选。修复时可比较本轮与累计改动；最终应用检查最初画布并只记录一次撤销步骤。每轮由用户发送，使用助手的运行时限，没有自动循环或自动接受。

也可在其中展开“批量核对分区”，按顺序勾选至多 6 区，以总时限启动一次服务端计划。每区检查一次，空补丁继续下一区；预算不足、失败、取消或本页画布变化时停止，并保留最近候选。计划会跨 Tab / 页面刷新恢复，仍需最后人工审阅应用。

“视觉审阅此分区”会把原图裁片和候选的实际渲染送入独立会话，返回问题位置、差异与建议。点击问题定位，可单独准备修复，或勾选多个可修复问题后“准备合并修复”。服务核对报告、受审候选与分区，发送时附带所选问题的完整证据，一次生成一个候选。修复后点击“复审修复分区”，使用新候选重新渲染双图；画布仍等待用户应用。文字报告会分别转录两图，候选转录与图元不一致时要求人工确认。报告可能漏检或误判，未发现问题也不代表自动验收通过。

运行 `pnpm dev` 或 `pnpm preview` 时，同一个本地服务提供 `/api/harness/*`。安装并配置本机 `codex` 或 `claude` 后即可使用；“CLI 可用”表示能执行版本检测，登录、模型与服务可用性在实际运行时验证。可通过环境变量 `FASTFIGURE_CODEX_COMMAND` / `FASTFIGURE_CLAUDE_COMMAND` 指定可执行文件路径，默认从 PATH 查找。网页不接收 CLI 路径或任意工作目录。

实现参考 FastPPT 的 Codex app-server 适配器与统一事件，以及 FastWrite 的 CLI 桥接、会话和运行服务。普通结构化绘图中，Codex 使用 stdio JSONL RPC 与只读沙箱；Claude 使用 `--safe-mode`、stream-json 和关闭工具的配置，保留现有登录方式。不提供命令审批界面、任意文件工具或 MCP 工具注册。独立图像草稿任务使用 Codex 原生图像工具，允许写入本轮临时目录，并关闭网络、Shell 和其他工具；不需要在网页配置 API Key。

会话在本地服务运行期间保存，关闭助手或刷新页面后可恢复消息和处理状态并继续会话，重启服务后需新建。最多 12 个会话、同时 2 个执行席位；每个会话一次运行或计划，单轮默认 3 分钟，可在助手设置选择 1 / 3 / 6 / 10 分钟时限并主动取消。每个会话最多保留 50 条轻量消息，当前候选和活动计划起点优先保留，消息保留原始轮次编号；完整工程快照和原始事件全局保留至多 20 轮，并保护正在执行的任务与各会话当前候选或最新运行。较早快照清理后仍可阅读保留的消息。事件流支持序号、断线重放和跨会话隔离；临时上下文目录在清理运行、移除会话或关闭服务时删除。接口限本机访问并检查 Host / Origin；这仍是本地单用户模式，静态部署 `dist` 不包含 Harness 服务。

协议与运行边界见 [Harness 接入说明](docs/development/harness.md)。

## 参考图与重绘来源

在“参考图”面板导入图片。PC 画布可并排比较原图与重绘结果；透明叠加模式可调透明度、X/Y、宽度，并可适配当前容器。参考图不拦截画布操作。可在中间的对照图或侧栏缩略图上拖动框选，也可输入百分比精确设置区域，然后关联到选中的节点或容器。

原文件限制 12 MB / 2400 万像素；导入后转换为最长边不超过 2000 像素的 WebP，每张数据 URL 最多 600,000 字符。每个工程最多 3 张，嵌入数据合计最多 1,200,000 字符，随工程 JSON 保存。超过预算或导入失败时保留当前工程。浏览器存储不足时仍可导出工程文件备份。

原文件还会尝试存入独立的浏览器缓存，供重建时裁取清晰局部；这部分不进入工程 JSON。缓存缺失或浏览器禁止存储时继续使用预览裁片，消息会显示实际输入来源和尺寸。在参考图面板可管理或补充对应原文件。

来源记录包含名称、链接或图号、原文件 SHA-256 和归一化区域；调整重绘对象的位置不会改变原图区域。编辑引用会更新当前对象的对应记录，移除参考图片仍保留已有对象来源，均可撤销。存为组件时采集这些记录；同一原图的来源合并覆盖区域，各对象保留自己的精确区域。组件文件保留结构与来源，不携带参考图片；重新导入同一原文件后可查看对应区域。SVG 的来源元数据保留，SVG 不嵌入对照图片。

支持人工证据标记，以及由 Harness 执行的整图 / 框选结构重建和分区修复，均需审阅后应用。已有自制样本的离线像素差异诊断；尚无独立 OCR 引擎、批量矢量化、在线自动质量判定或 RSI。

## 自动布局与连线

在画布工具栏点击“自动布局”，选择目标容器。分层布局按有向连接关系确定层次，将反馈环归入同一层；网格模式按列排列独立对象和子图。默认仅排列直接子对象，将子容器作为整体移动。选择“递归整理子图”会先整理内部，再排列外层，可按内容适配非空子容器尺寸；目标容器边界和节点尺寸保持固定。空间不足时将间距适配至最小 16，必要时重试整个子树；仍放不下则保持原工程，并提示所需尺寸。可以保留手动端口，或同步调整跨对象的端口方向。

路由优先使用简单折线，存在障碍时搜索正交路径，避开其他节点、无关容器和标题区域，保留约 8 单位的障碍间距。两端端口方向固定，在最近共同容器的内容区内路由；无法找到路径或端口缺少空间时，使用明确标红的回退线，允许继续调整。它不处理连线之间的交叉、重叠和全局最优布线，也不绕到父容器外搜索。

SVG 输出与画布相同的折线路径；工程 JSON 和 SVG 元数据保留连接语义。

## 复用一组可编辑对象

基础科研组件的结构在属性栏“论文组件结构”选择，内部文字可双击修改，也可在属性栏逐项填写。编码器 / 解码器预设为 Transformer 的结构示意；可切换为卷积、MLP 等，重复层数以 ×N 标注。较小组件保留紧凑轮廓，扩大后显示内部标签；“展开结构尺寸”在空间允许时恢复推荐尺寸。

点击“转换为独立图元”预览并确认后，原预设变成无标题栏的自由组合。点击外框可移动整组，点击内部形状或文字可逐个编辑；选中线段后拖动蓝色端点 / 折点，方向键精调、Shift 加速，可通过属性栏增删折点、修改坐标、线宽、颜色和箭头。中间折点可用 Delete 删除；拖动端点会解除该端绑定，单独移动整条路径会解除没有一起移动的端点绑定。移动绑定图元时端点随动，移动组合时外部连线保持绑定；解组后外部连接继续绑定到可见外框。

转换可单步撤销；空间、容量或层级不足时不修改工程。每个工程最多 240 个图元，其中科研模块最多 60 个，路径每条最多 128 个锚点，全图锚点和控制点共 4,096。普通容器仍使用标题栏与内容边距；自由组合只有四周 2 单位边距。语义色保留为配色引用，换画盘或继承目标主题时会更新；显式颜色优先。转换后保留创建时的结构来源参数，不再通过预设参数自动重生成内部图元。可将整组再次存入“我的组件”，保留手动编辑和绑定关系，助手复用时由程序重映射 ID。SVG 保留原生形状、文字和曲线。结构设计与参考论文见 [论文组件结构](docs/development/component-structures.md)。

在组件库的“参数化组合”中选择配方，可调整网络层数、神经元数量、特征分支、融合算子或流水线方向。选择“插入当前容器”会查找不覆盖同层对象的空位，空间不足时保持工程不变；“新建图件并插入”以组件自身作为根容器，可单步撤销恢复原工程。

选中容器后，在属性栏点击“存为我的组件”，保存内部节点、子容器和连接。跨越容器边界的连线留在原工程；重新插入时为所有对象分配新 ID，内部端点绑定保留。可补充来源名称及链接、图号或页码；来自内置配方的参数和参考记录会进入派生来源。这些参数记录创建时的配置，不会覆盖后续手动编辑。

含参数化对应记录的组合，可以在属性栏“调整组合参数”中预览更新。当前参数单独随图件保存，来源继续保留初始版本；有外部引用的对象不能直接删除，完整采集入库后仍可继续调整。详见[参数、手工编辑与连接边界](docs/development/recipe-parameters.md)。

我的组件存储在当前浏览器的 `fastfigure.components.v1`，独立于工程保存，最多 50 个。组件文件使用 `fastfigure.component` 格式，限制 2 MB；重复导入创建带名称的副本，避免覆盖原组件。另可“存入本机素材库”，保存到 `~/.local/share/fastfigure/components/` 并按标签和来源检索；可用 `FASTFIGURE_LIBRARY_DIR` 配置目录，不含账号或多机同步。直接插入不占浏览器名额，“用于助手”取为工作组件并选中参考，仍须人工发送。插入时可保留皮肤与配色或继承目标样式，手绘强度和种子仍使用目标工程参数。契约见 [组件模型](src/core/assets.ts)，配方见 [参数化组合](src/data/recipes.ts)，存储与备份见[本机素材库](docs/development/component-repository.md)。

## 组件接口

给导入或展开后的自由组合添加命名接口：属性栏“组件接口”设置输入 / 输出方向、供助手引用的唯一标识和沿边位置。圆点可拖动或用方向键微调；连接工具按接口方向连线，移动和调整组合边界后仍随动。存入素材库会一起保存，助手通过稳定标识复用，不再把未标记的自由图元装饰猜成输入输出。接口标记不进入论文画面；连接仍会导出。操作与数据契约见 [命名组件接口](docs/development/component-ports.md)。

## SVG / draw.io 源素材

组件库点击“导入 SVG / draw.io”，选择文件、页面及源分组，再将原生预览插入画布或素材库；也可把预览过的子图加入本机入库队列。名称只修改素材检索名称，图中原文保持。SVG 支持常见形状、直线 / 贝塞尔、闭合轮廓、文字、文件内 use、分组、变换与基本 CSS；形状和路径支持可编辑的线性渐变填充 / 描边，在属性栏调整方向、颜色停靠点及透明度，随素材复用与 SVG 矢量导出保留。黄色方点为曲线控制点，圆点为锚点；可拖动、键盘微调，或在属性栏切换线段类型。增加折点保留曲线形状。

文件上限 2 MB；draw.io 支持 1–50 页、合计解压 8 MB，批量队列按页面计数。径向 / 文字渐变、裁剪、滤镜、外部图片、draw.io 源渐变样式及复杂模板形状和部分文字排版等效果暂不支持，错误会在应用前显示。未安装字体按浏览器回退。整组透明度随组结构保存在 SVG / 工程 JSON 中。支持范围、数据模型和验证见[矢量素材导入](docs/development/svg-import.md)。

## 外部图库与论文模板

左侧“图库”检索并查看论文图，点击“交给助手”会导入参考图、勾选图片附件并填写版式分析要求；按发送后才调用模型。索引按需加载，当前使用标题 / 作者与中文主题关键词展开，没有加载 CLIP 模型。原图在线读取，保留论文来源，不随应用分发整套图片。

组件库 → “论文模板”查看 FigureForge 的可编辑模板，默认 150% 比例便于阅读；预览后可插入或存入个人组件库。原模板中的数值、误差线、显著性均为示例，需用真实实验数据更新。选中容器后可“整体等比缩放”，会同步处理字体与笔画。

固定源码、许可、可复用模块、当前边界与后续适配顺序见 [外部图件生态接入](docs/development/reference-ecosystem.md)。`pnpm resources:build` 从本地固定快照离线重建资源并核对 SHA-256。
