# 节点连线、指定折点与画布选线

2026-10-29，第廿九批。全连接网络采用逐条直线，流程与融合组件继续使用折线避障；人和助手均可显式设置连接方式。改动来自上一轮真实三图候选中全连接边合并为总线的可见问题。

## 使用与数据

组件库的全连接网络配方按相邻两层展开全部连接，新增内部边默认 `routing: "straight"`。仍是独立语义边，不合并成一张图片或一条总线；节点、标签和连接关系可分别编辑。流水线、多分支融合默认保持折线。

在画布点击连接，或 Tab 到“选择连接 N”后按 Enter / 空格，可选中连接并看到高亮；右侧属性的“连线方式”可选择“直线”“折线避障”或“指定折点”。图层列表同样可以选择连接。切换为一次可撤销修改，移动端点后重新计算，保存 / 重开工程、捕获组件及缩放复用保留设置。连接模式中不显示选线命中区，以便选择起点和终点。

```json
{
  "id": "layer-1-to-2",
  "source": "neuron-a",
  "target": "neuron-b",
  "sourcePort": "right",
  "targetPort": "left",
  "routing": "straight"
}
```

`routing` 接受 `straight` / `orthogonal` / `manual`；未指定使用折线避障。普通图体 `edges` 可保留完整指定折点记录，实例间新链接 `instanceLinks` 仍使用 `straight` / `orthogonal`。模型提示要求保留已有设置，新增相邻层全连接宜使用直线。程序展开素材、重新分配 ID 时保留内部设置，不用外部链接的方式覆盖素材内部边。

修改审阅会显示“连线方式”；未设置与显式 `orthogonal` 视作同一种方式。本批同时修复前一批的审阅遗漏：此前虽然定义了全图参考用途字段的阅读器，但工程比较未实际传入 `referenceUses`；现在新增、变更参考来源会进入修改清单，包含来源数量未变的情形。

## 指定折点（第七十九批）

选中一条连接，在属性栏选择“指定连线折点”。逐行填写中间必须经过的画板坐标 `X, Y`，1–32 个，选择斜向点之间先水平或先垂直；起终点继续跟随原节点与端口，程序补齐端口向外出线。原图 / 预览对照后显式应用，可撤销。清空输入或点“清除折点，恢复自动避障”可恢复自动模式。

选中后画板显示可拖动的蓝色折点；方向键移动 1 单位，Shift + 方向键移动 10 单位，Delete / Backspace 删除指定点，最后一个删除后恢复自动避障。每次拖动为一次历史操作。

路线必须经过全部给定点及其顺序，不自动绕过指定点。初次应用遇到越界、碰撞或立即折返时拒绝并给出原因；此后移动节点或折点可能使路线受阻，保留原折点并显示红色虚线。可改点、改端口或恢复避障。使用准确直角段，不以圆角或手绘扰动切掉指定拐点。障碍判断仍使用保守包围盒，不进行跨连线交叉优化。

内部 `manualRoute={containerId,direction,points}` 存放共同容器原点与 `metricScale` 下的局部绘制单位。单独移动节点时折点留在原位；整组或两端一起平移时折点一起移动，整个素材等比缩放时随素材缩放。组合 / 解组会重新换算坐标框架，分组及局部采集的外框包含指定折点；同一素材的接口连线若绕在原边框外，采集时增加透明外层包含整条路线，保留原边框尺寸；父容器边距不足时明确拒绝。捕获、重插、原生 SVG 元数据和 JSON 保持 ID 对应与绑定。配方更新保留手工编辑时保持存续连接的折点位置，参数重排后仍需核对是否受阻。

助手应通过受控操作提交画板坐标，由程序换算，不能自行填局部坐标或操作报告：

```json
{"message":"保留节点与端口，通过作者给定的两个折点","figure":null,"materialEdits":[{"kind":"edge-route","edgeId":"wire","points":[{"x":300,"y":230},{"x":300,"y":360}],"direction":"horizontal"}]}
```

`points=[]` 明确清除折点。操作不与新图体、实例或其他维护协议混用。无变化仅返回说明，不创建候选。现有素材的 `manualRoute` 默认保持；组件的“全部直线 / 全部折线”会明确清除内部指定折点，支持撤销。全图最多 512 个指定折点。

SVG / JSON 已检查原生恢复。draw.io / PPTX 导出适配继续暂停，未据此声称外部编辑往返可用。

## 几何约束

直线连接是两个既定端口之间的一条线段，不自动绕行。首端必须向起点端口外侧出发，末端必须从终点端口外侧进入；直线两端保持在共同容器的内容区域。方向不符、越界或与障碍相交时保留直线，显示红色虚线和具体原因；使用者可移动节点、换端口或切换折线避障。不会将错误连线静默改成另一种方式。

障碍检查使用图元 / 容器的轴向包围盒，并为直线保留随对象缩放的窄边距和描边空间。神经网络相邻层的密集斜线不再套用固定 8 单位的正交转弯空间；折线仍使用既有避障规则。直线段与矩形采用几何相交检查，擦过边界 / 角点不算进入内部。同组且完整包含在端点框体内的注释仍属于端点自身；不同组或超出框体的内容仍为障碍。命名接口沿用组合所有者折叠规则。

该检查对圆形、斜形和自由路径使用保守包围盒，可能提示实际外形之外的接近；不提供曲线语义边、交叉优化或边捆绑。层间直线仍会按全连接拓扑交叉。第卅批已补充[配方间距与组合批量改线](network-presentation.md)，已有手工几何不会因改线而重新生成。

## 连线外观（第八十一批）

中央格式栏的“连线样式”处理节点连接与普通开放路径。Shift 可混合多选图元、路径和连接，选区栏分别显示图元 / 连接数量；属性栏也可从选中的连接或组合内部连线打开。选择组合时可包含内部路径与两端均在选区中的语义连接，显式选中的跨组连接也可修改。操作先预览，再一次应用，可撤销。

颜色、线宽、虚实、起点 / 终点箭头及箭头大小分别勾选。颜色可恢复跟随所在容器主题，线宽可恢复默认，虚线间隔留空为实线；预设提供实线、虚线和点线，也可输入不全为零的非负间隔。两端独立选择实心、开放或无箭头。节点连接的 `appearance={stroke,strokeWidth,dash,arrow,startArrow,arrowSize}` 保存独立外观；省略项仍继承主题、默认线宽、无起点 / 实心终点箭头。线宽 / 间隔 / 显式箭头大小以画板单位记录，等比缩放时与内部图元一起缩放。只改终点不会清除起点，箭头大小可用 null 恢复默认。

该操作保持路径控制点、指定折点、路由模式、端口与 ID。不会用样式掩盖受阻：受阻连接仍显示红色虚线与原因，畅通后恢复作者设置。图表管理连接 / 路径、带图表语义的路径、闭合轮廓与非等比变换描边按项保留。线宽变化不重排路径，也不是对完整描边包络和连接交叉的独立证明。

原生 JSON / SVG 元数据、素材采集、重插 ID 对应与存续配方连接保留外观，修改审阅单独列出“连线外观”。按中心统一组合外框尺寸时，独立子图元与折点的画板位置保持；整体缩放是另一项操作。draw.io / PPTX 的外部导出样式映射继续暂停。

助手与手工操作共用 `materialEdits`：

```json
{"message":"统一作者选中连接的样式，保持全部几何与绑定","figure":null,"materialEdits":[{"kind":"line-style","objectIds":["wire"],"includeDescendants":false,"style":{"stroke":"#287f72","strokeWidth":2,"dash":[7,4],"arrow":"open"}}]}
```

省略样式项保持；`stroke` / `strokeWidth` / `dash` 可设 `null` 恢复默认，`dash=[]` 明确固定为实线。不接受模型提交前后报告、最终路径或新绑定。实现、精确尺寸匹配及测量边界见[素材整理](material-editing.md)。
