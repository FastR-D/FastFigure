# 插入后调整组合参数

第五十七批为六种内置配方增加画布参数更新：全连接网络、多分支融合、流水线、透视张量栈、缩放点积注意力、图像分块与嵌入。参数化组合保存源图元与画布对象的对应关系，完整采集入库、缩放和重新插入后仍可继续调整。

第八十四批新增六类[论文结构图](structural-figures.md)，目前十二种内置配方共用下述参数更新流程。分层架构保留嵌套分区，层级／辐射／循环的路径端点在重绘后仍绑定对应对象；循环方向变化明确重算相邻阶段连接。

第八十五批继续加入耦合双循环、泳道协作、集合交叠和同心圈层，目前十六种内置配方共用此流程。双环两侧独立计数并保留共享状态身份；泳道任务按序号保持身份，切换独立／交接模式时重绘位置和绑定。改变圈层数量会重算环带与核心尺寸；集合交叠通过真实半透明图形叠加表达，没有自动集合布尔运算。

第八十六至九十一批继续加入多尺度、配对、跳连、图聚合、路由、阶段迁移，以及近期录用论文启发的时序记忆和交替注意力，目前二十八种配方共用此流程；具体参数和语义边界见[论文结构图](structural-figures.md)。

## 使用

选中组合或其内部节点，在右侧属性栏点击“调整组合参数”。此入口用于包含参数化对应记录的组合；手工导入的独立图元继续使用普通图形编辑。

窗口冻结当前工程。调整配方参数后，可以在“当前组合”和“更新预览”之间切换，两者使用同一视野比较尺寸与结构。预览列出重绘图元、新增 / 移除对象、保留 ID、另加对象和手工设置的数量，以及工程文字提示 / 受阻连接相对原工程的变化。

更新范围有两种：

- **保持绘制比例，按内容调整外框**：保留原组合的基准缩放和左上角，根据新参数调整外框。增加的面积不能覆盖同层对象，结果须位于父容器内。
- **适配原外框，内部等比缩放**：固定原外框位置与宽高，按新内容统一计算内部比例，保留余白。仍须符合字号、描边、图元和工程容量约束。

默认勾选“保留手工改字与外观”。仍存在的对象可保留标签 / 名称、注释、图标、文字格式、颜色、结构设置及命名接口的手工设置；配方自动生成且未被手改的公式、维度和说明会随参数重算。取消勾选后，生成对象使用新配方的默认文字与外观。来源和另加对象保持。

文字格式按属性保留：只改加粗或颜色时，未改过的字号仍随新内部比例缩放，避免整个旧格式对象覆盖新字号并造成截断；明确手改的字号继续保持。

生成对象的位置、尺寸、曲线和内部连接按参数重绘。另加注释、图形、接口、子组件和连接保留原 ID 及位置。应用后可以单步撤销；预览自身保存原工程标识，工程变化会阻止旧预览覆盖。打开异步窗口期间也会暂时阻止全局画布编辑快捷键。

## 连接与手工修改

仍存在的源对象使用原画布 ID，新对象才分配新 ID。MLP 的输出神经元按输入 / 隐藏 / 输出角色匹配，因此增减隐藏层不会把原输出连接接到新增隐藏层。普通流水线阶段、分支、片层和网格按配方图元标识匹配；图示计数继续表示示意结构。

新增 / 删除的生成连接由程序计算，外部连接保持。若更新会移除被外部连接、路径端点或另加对象引用的节点 / 容器，整次拒绝。生成连接已经被手工改接、生成路径改绑到另加对象、图元已删除 / 移出或重新分组时，也明确要求先处理该结构；不按显示顺序猜测新的对应。

外部路径引用仍存在的原生图元时，保留绑定并随新几何同步。保留注释超出新外框、端点类型不再有效、字号过小或总容量超限都会拒绝，当前工程和历史保持。可改用适配原范围，或先调整组合、注释与连接。

手工改过的公式或解释也会按保留选项处理，需要对照新掩码、分支和维度含义查看。参数预览中的路由 / 文字结果用于发现几何问题，仍需核对科学含义。

## 当前状态与来源

容器 `parametric` 保存当前配方 / 参数、修订数、更新时间和源标识到画布 ID 的对应表。完整捕获时将根对应到 `stage`，重新插入时按实际 ID 重映射，整体缩放保持对应关系。局部采集的透明样式层不携带不完整的参数管理记录。

`component.recipe` 和组件派生记录继续保存初始来源配置；更新当前参数不改写原库快照或原来源版本。参数更新后的图件可以再采集为新素材，沿用已有不可变入库和来源追溯。重建匹配记录保留初次复用信息，调整后的外观可重新对照原图。

助手的完整 FigureIR 回复可省略已有 `parametric`，程序会恢复已知记录；携带相同内容时允许键顺序变化，新增或改写记录会被拒绝。第五十八批支持[助手提出已有组合参数修改](assistant-recipe-updates.md)，程序重绘后仍由人审阅并应用；助手生成新实例时继续使用目录中的 `parameters` 展开。审阅差异显示配方、参数、修订和管理对象数量，避免把整张 ID 对应表挤进参数说明。
