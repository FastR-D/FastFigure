# 图表数据点与路径的鼠标选择

数据图中的小点现在可以直接鼠标选中、拖动和改格式。图表笔画的透明命中层位于数据点与文字下方，避免后绘制的误差棒 / 折线挡住点；细线保持约 12 CSS px 的点击范围。小数据点另有约 5 CSS px 的扩展命中区，真正画出的对象优先于其他点的扩展区，扩展区相互重叠时按绘制顺序选择。范围不随画布缩放一起变细。

重叠处用 **Alt 单击**选择下层的笔画路径或语义连线；命名接口和已选路径控制柄仍使用专门的编辑操作。普通自由插图路径与填充形状保留原有前后顺序。键盘 Enter / Space、Shift 多选、局部采集的 Ctrl / Meta 多选，以及曲线控制点和绑定编辑继续保留。点的可访问名称使用已有系列 / 样本标识，便于识别具体对象。

小对象的缩放手柄移到点外侧，避免手柄盖住整个数据点，把原本的移动误当成缩放。双击标题、注释及结构内部文字，仍进入对应文字字段。

## 实现边界

`FigureHitLayer.ts` 复用同一 SVG 场景的曲线、变换、裁剪和字形构建透明命中层，保留填充路径的实际内部 / 孔洞。绘制层与鼠标操作层分离；共享图例中暂隐的节点不会出现在命中层，零整体透明度的对象也不会产生画板鼠标目标。这里不改变模型中的图元顺序、坐标、原始观测、统计、路径绑定或来源。

这些是编辑器交互范围，不写入工程或 SVG / draw.io 导出。改变点的位置仍是原生图元编辑，不会反向推测实验值；数据重绘仍通过图表编辑器执行。极密的重叠点仍按图层顺序选择，也可使用图层面板或键盘。

## 当前验证

复用现有 1920×1080 编辑流程，检查：

- 50% / 100% 画布缩放下，实际约 2.49px / 4.98px 的点，在轮廓外 4 CSS px 仍能鼠标选中，选择本身不改图件。
- 鼠标拖动改变点的位置，点的宽高与源配置保持，撤销恢复完整图件；手柄不覆盖点中心。
- Alt 鼠标选择路径、结构内部文字双击编辑、共享图例保留和改色后的失配恢复。
- 重建流程在真实线段附近、偏离细笔迹 4 CSS px 选择绑定引线，再解除 / 撤销绑定；不依赖稀疏 SVG 的联合包围盒中心作为点击位置。
- 编辑、数据、助手、重建四流程及原 541 项核心 / 服务检查通过，Lint、类型和构建通过。未增加维护测试脚本或文件。

测量在现有流程中直接断言，四流程结果为 `test-results/ui/results.json`；不再另存逐功能测量文件。变换、裁剪与透视插图继续由现有重建流程及原核心检查覆盖；上述数值是本机开发证据，不是所有图件或性能的保证。
