# 独立风格素材

在左侧“样式 → 我的风格”保存当前容器的配色、容器样式、字体、可选连线规范及使用说明；可预览当前图件、加标签、检索、编辑、备份 / 导入、移除与恢复，也可从可采用的绘图方案保存。

保存本身不改画布。应用到当前容器时，改变该容器的基础配色和皮肤，可选择统一原生节点与容器标题字体，并设置后续新文字的默认字体。几何、拓扑、文字内容、字号、粗斜体及未选通道的手工颜色保持；显式保存的连线规范会统一其勾选项。图表数值编码、图表文字和带定位矩阵的字形保留。内部容器仍可有局部覆盖。应用为一次可撤销编辑，预览显示字体 / 连线处理数量和原生文字检查结果。

对只有绘制缩放、未显式设置字号的素材，应用字体前先记录当前画板中的实际字号，避免新文字样式让缩小素材突然恢复默认大小。文字扩框需单独在中央格式栏选择“适配文字”，见[素材整理](material-editing.md)。

素材采用现有配色、六种容器皮肤、四个手绘主题和八种字体选择，另可选择纯色底、斜线底纹或透明；手绘轮廓默认白底，底纹须显式选择。底纹由容器填充字段控制。手绘主题的默认字体、曲线类型和起伏强度也可保存，见[手绘主题](handdrawn-themes.md)。使用说明可解释颜色角色、图示和注释位置。它保存可审阅的视觉选择，不会自动从图片识别并证明精确的视觉规则；自定义调色板和任意容器皮肤仍属后续工作。

风格可选择并保存当前配色的默认主题色；原生素材另可在方案中按实例绑定色槽。默认色改变继承颜色，手工颜色、对象显式色槽和内层覆盖保持，数据图表使用独立工具。规则见[组件默认主题色](component-color-bindings.md)。

需要调整多个对象色槽时，可在风格编辑中展开“编辑风格颜色映射”，或从对应容器保存当前生效规则。映射可替换显式色槽，但固定 RGB 保持；同层同时解析、子层表独立，数据图表不解析通用映射。见[多色角色映射](color-mapping.md)。

“用于助手”附带一份独立快照，普通绘图与方案规划均可使用。规划固定皮肤、配色、容器填充与字体建议，采用后服务恢复当时的风格和原生素材；在库中修改或删除原素材不会改变已发送输入。候选由程序核对基础皮肤、配色、已指定的笔触 / 起伏强度和根容器填充，保存风格来源；实际字体、局部语义配色和图示质量仍须审阅。数据选型与重建使用各自的固定来源流程，切换任务会清除风格附件。

风格素材保存来源文字和图片指纹，不自动携带历史图片字节，也不声称模型本轮看到了这些图片。从方案保存时合并继承的样式来源，可显式精简至 12 条，原方案仍保留完整记录。独立文件采用 `fastfigure.style`，最多 60 KB；本地库最多 50 项 / 600,000 字符，重复导入创建副本。它目前是浏览器本地库，尚未接入同步服务。

图件保存最多八份风格使用记录，记录包含完整素材修订快照和应用范围。手工应用记录实际字体调整 / 保留数，助手候选将字体标为建议。根容器属性可删除记录并撤销。工程、组件捕获 / 缩放 / 插入及原生 SVG 元数据保持来源。模型不能伪造或删除程序维护的记录。

## 可复用连线规范（第八十三批）

在风格编辑中勾选“保存连线规范”。默认范围为“仅节点连接”，也可明确包含普通开放路径；可从当前连线采用格式，再分别勾选颜色、线宽、虚实、两端箭头与大小。预览列出实际可处理、调整、保留数量；滚动编辑下方参数时，右侧图件预览保持可见。没有可处理连线时报告零项，风格的其他部分仍可保存 / 应用。

```json
{
  "lineStyle": {
    "scope": "edges",
    "style": {"stroke":null,"strokeWidth":2.5,"dash":[7,4],"startArrow":"open","arrowSize":12}
  }
}
```

`scope=edges/all-lines`。`style` 与[批量连线样式](material-editing.md)共用契约：至少选择一项，省略项保持；颜色 / 线宽 / 虚线 / 箭头大小可用 null 恢复各自默认。箭头大小未自定义的样本保留默认策略，不假定路径与语义连接有相同的初始大小。显式颜色可覆盖原来的手工线色；选择跟随主题时清除所选线的固定色 / 渐变，让其解析所在容器的主题。

应用到子容器时，只处理内部路径和两端均在范围内的连接；跨组外部连接保持。保留 ID、控制点、端口、路由方式和指定折点，不改文字或科学关系。图表管理对象、图表语义路径、闭合轮廓与变换描边按项保留。规范不保存渐变、透明度或虚线偏移；修改虚线时偏移重置。渐变样本不能假装采集为完整规范，界面提示手工选色。

人和助手执行相同的程序规则。普通助手候选和采用方案生成的候选会在编译完成后应用发送时冻结的规范，并报告实际数量；模型不提供计算报告，也不能替换来源。方案保存为新风格时继承所采用风格的连线规范。原生图元的几何与拓扑保持，具体视觉表现仍需审阅。

连线规则与使用记录一起保存在风格备份、工程 / 组件及原生 SVG 元数据中。整体缩放会改变实际线宽和箭头大小，使用记录中的原始规则快照保持；再次应用规范，会按记录的画板单位值重新统一。当前风格库仍为浏览器本地库，未增加云端同步。draw.io / PPTX 外部导出适配和新增数据绘图继续暂停。

本批 575 项核心 / 服务检查、四条 1920×1080 桌面流程、Lint 与构建通过，仍使用原有 40 个核心 / 服务文件和一个桌面入口。证据为 `test-results/style-lines-verification.json` 和 `test-results/style-lines-proof/saved-line-rules.png`；桌面期间源文件保持一致，暂停的数据与导出文件保持第七十七批基线字节一致。本批没有调用真实模型，CLI 夹具验证协议与候选链路，不代表模型绘图质量。

第三十三批在 1920×1080 完成预览、保存、手工应用与撤销、助手附件、原生素材规划与采用、删除库中来源后生成候选、来源和最终应用的 UI 验收。单元 / 服务集成检查覆盖数值与定位字形保护、作用范围、备份 / 存储失败、来源往返、快照冻结、冲突拒绝和两种 CLI 夹具。第三十四批补做一次两阶段真实调用，保留原生结构与来源，但也发现局部颜色未完整遵循方案，详见[真实组合验证](composition-style-live.md)。测试方式见[当前验收约定](testing.md)。
