# 素材居中、统一格式与按点直角箭头

当前开发重点回到素材、箭头和样式。数据绘图新增功能已中止，未完成的均值 / SD / SEM 汇总已撤回；已有数据功能保留。draw.io / PPTX 导出适配暂停。

## 手工操作

画板中央格式栏提供“居中”“统一格式”“适配文字”“统一尺寸”和“连线样式”。操作冻结当前工程，提供原图 / 编辑预览，显式应用后可单步撤销；预览期间工程变化时必须重新打开。

- **居中**：选中素材或 Shift 多选同层对象，可选择水平、垂直或双向居中。按父容器的可用内容区域计算，整组选区平移，内部布局保持。重复选择父组和其后代只移动一次。普通语义连接保留引用并随端点更新；所选路径若绑定到选区外的对象，需要一起选中关联对象或先解除绑定。
- **统一格式**：选择已有对象作为样本，分别勾选主文字、描边、填充及是否包含内部图元。组素材优先取带文字的内部形状作为初始样本，可手工另选；填充默认不选。主文字默认仅统一字体，保留字号、字重、斜体、字距、颜色和对齐；可改为“统一字形”（字体、字重、斜体、字距）或“主文字完全匹配样本”。注释默认保持，单独勾选后仅统一其字体，保留注释层级。描边复制颜色 / 渐变、线宽、虚线和端点；填充复制颜色 / 渐变和填充透明度。
- **适配文字**：单独检查选区，或在统一格式后勾选适配。扩大有空白空间的文字框，保持中心或左上角；不缩小已设字号、不改原文、不移走邻居。可允许无填充、无描边的透明组合随之扩展。成功、空间不足及保留项逐项报告；有些对象失败时，其他成功项仍可应用。根画板可作为检查其后代的范围。
- **统一尺寸**：按已有图元或容器精确匹配宽度、高度或宽高，固定中心或左上角。只改外框，容器内独立图元和字号不缩放；形状自身的结构示意随外框排布。样本自身保持。无法容纳子对象、指定折点或超出组件尺寸上限 / 父边界时整次拒绝，不静默改成其他尺寸；阻塞原本畅通的连接也会拒绝。文字检查提示可能新增的省略，适配和整体等比缩放仍是独立操作。
- **连线样式**：统一勾选项中的颜色、线宽、虚实和终点箭头，适用于显式选中的节点连接、普通开放路径及选区内两端均被选中的连接。选择组合并包含内部图元可批量处理内部连接。颜色可恢复跟随各自容器主题，线宽可恢复各自默认，空虚线间隔为实线。保留路由方式、指定折点、控制点、ID 和端点绑定；跳过图表管理对象、带图表语义的路径、闭合轮廓及变换描边。节点连接受阻时继续显示红色虚线，恢复畅通后显示作者样式。
- **导入文字重排**：定位文字默认保留，可明确勾选重排。程序保留原文、基点、旋转 / 仿射矩阵，更新字形框并检查容器限制。普通统一格式默认保持非定位文字外框，只有选择适配才扩框。预览保留程序文字检查，列出省略和宽高不足，可定位查看。
- **按点箭头**：画板工具栏选择“按点绘制直角箭头”，逐行输入 `X, Y`，2–64 个画板坐标。先水平 / 先垂直模式在每对斜向点之间插入一个折点，全部给定点和顺序保持；严格模式要求相邻点已有相同 X 或 Y，否则不能应用。两端分别选择实心 / 开放 / 无箭头，可设双向箭头；可显式设置两端箭头大小，也可按默认线宽取值。
- **节点连线指定折点**：选中连接，在属性栏指定 1–32 个中间折点；端点跟随节点与端口。可在画板拖动、键盘微调或删除，整组移动 / 缩放与采集保持。详情见[节点连线](edge-connections.md#指定折点第七十九批)。
- **调整路径**：选中开放路径后，在属性栏选择“按点调整直角箭头”。保留 ID、外观与绑定；绑定端点必须与给定坐标相符。已有曲线会改成按锚点连接的折线，界面明确提示控制点将移除。

统一格式不改标签、注释原文、结构、路径点或绑定。样本自身保持，透明组合外框、接口和图表管理对象不批量覆盖；变换描边按描边项目保留，定位文字按所选策略处理。按项目跳过的对象在预览中列出。复制实色会清除同通道旧渐变，未选择的颜色通道保持。单独改字体、统一格式与应用风格 / 手绘主题会先固定当前实际字号，避免缩放素材的隐式字号跳回默认值。

## 文字适配的范围

椭圆、圆形和菱形按内接文字区域换行，避免注释只在外接矩形内却跨过曲边；居中的单个数学运算符保持原有排版。适配复用渲染器的可见行与完整性标记；浏览器等待当前字体加载后，以 Canvas 检查这些行的实际字形宽度和行间高度。核心 / 助手在没有 Canvas 时使用估算，摘要明确标记，仍需对照浏览器预览。

搜索为有界的尺寸候选网格，每个方向 25 档，另含宽度提示；优先尝试面积较小的尺寸，最多验证 16 个通过文字和空间初筛的候选。检查父容器、画板、组件尺寸上限、已有对象矩形交叠，以及原本畅通的语义连接。不能证明全局最小尺寸、完整像素遮挡或其他软件的字体效果；也不承诺修复既有交叠和格式重排已产生的遮挡。由内部结构尺寸派生的小字可能随外框变化；用户显式设置的主文字和注释字号保持。

接口、图标、路径、图表 / 共享图例 / 色标管理对象和不可见文字保留。定位文字须明确选择重排，其字形框沿用既有基点和矩阵。空间不足时保留该目标并报告，不隐式缩字或删除内容。

按点箭头是固定几何路径，不自动避障，也不持续约束以后拖动的锚点。移动绑定对象后，可再次按点调整。需要语义连接和自动避障时继续使用“连接两个节点”。

## 助手共用操作

“交给助手提出方案”将当前选区和样本要求带入左侧助手。普通绘图协议支持 `materialEdits`，由与手工预览相同的编译器执行；仅生成待审候选，当前画板不变。操作必须单独提交，`figure=null`，不能混入新实例、配方更新或其他维护操作。程序生成实际操作摘要，模型不能提交计算后的坐标报告。

```json
{
  "message": "将作者选中的素材整体居中",
  "figure": null,
  "materialEdits": [
    {"kind":"center","objectIds":["material-group"],"axis":"both"}
  ]
}
```

其他操作：

```json
{"kind":"format","sourceId":"sample-shape","objectIds":["material-group"],"channels":["typography","stroke"],"textPolicy":"family","includeDescriptions":false,"includeDescendants":true,"positionedText":"preserve"}
```

```json
{"kind":"fit-text","objectIds":["material-group"],"includeDescendants":true,"anchor":"center","expandGroups":true,"positionedText":"preserve"}
```

```json
{"kind":"match-size","sourceId":"sample-shape","objectIds":["target-shape"],"dimension":"width","anchor":"top-left"}
```

```json
{"kind":"line-style","objectIds":["material-group"],"includeDescendants":true,"style":{"stroke":"#287f72","strokeWidth":2,"dash":[7,4],"arrow":"open"}}
```

```json
{"kind":"arrow","parentId":"stage","points":[{"x":100,"y":180},{"x":300,"y":260}],"direction":"horizontal","arrow":"filled"}
```

连接已有节点的操作为 `{kind:"edge-route",edgeId:"wire",points:[{x:300,y:230}],direction:"horizontal"}`，空 points 清除指定折点。

`textPolicy=family/typeface/match`，省略默认为 family；`anchor=center/top-left`。`axis=both/horizontal/vertical`，`direction=horizontal/vertical/strict`，`arrow=none/open/filled`。修改已有路径增加 `nodeId`；定位文字仅在明确要求时用 `positionedText="reflow"`。每次最多 8 项；格式字段非法、引用失效或操作结果不符合工程约束时整次拒绝，输入工程保持。文字适配的逐项空间不足属于可审核结果；成功项可以应用，无变化时只返回说明，不创建候选。

尺寸的 `dimension=width/height/both`。连线样式的 `style` 至少一项；省略项保持。`stroke` 为六位颜色，`strokeWidth=.01..64`，`dash` 最多 16 个非负线段 / 间隔且不能全零，`[]` 为实线；三者可用 `null` 恢复主题色 / 默认线宽 / 实线。节点连接保存到 `edge.appearance`，宽度和虚线为画板单位，随素材整体缩放。节点连线外观在修改审阅中单独列出。工程、原生 SVG 元数据、采集 / 重插和存续配方连接保留，draw.io / PPTX 外部导出适配仍暂停。

`arrow` 是终点箭头，`startArrow` 是起点箭头，均为 `none/open/filled`；起点省略时无箭头，已有受控编辑中省略则保持原设置。`arrowSize=.1..256` 是画板中的两端箭头长度，`null` 恢复默认，缩放素材时显式大小一起缩放。普通路径字段位于 `node.path`，节点连接位于 `edge.appearance`；`line-style` 共用同一补丁，不改控制点或反转绑定。首 / 尾开放子路径的箭头沿端点切线朝外；闭合部分和孤立点不绘制箭头，也不跨越 move 推断方向。曲线控制点重合时回退到有效的端点方向。

双向箭头是作者选择的视觉表达，不改变 `source/target` 或接口输入输出契约。原生 SVG 元数据能恢复两端设置；一般外部 SVG 的起点标记仍未适配，继续明确拒绝，避免猜测源 marker 的形状和方向。箭头大小不自动避障，也不证明完整描边外包络可用。

要在其他图件或助手生成中复用这些设置，可在“样式 → 我的风格”中保存可选的连线规范，分别选择仅节点连接或包含开放路径。保存、采用方案和应用数量的规则见[风格素材](style-materials.md#可复用连线规范第八十三批)。
