## 用户入口与数据流

左侧“图库”按需加载静态索引；搜索标题和作者，支持部分中文主题到英文关键词的展开。没有下载 CLIP 权重，也没有调用检索服务或 LLM。当前不是图像相似度检索，也不使用论文摘要。搜索结果显示命中词，不把相关度当成正确率。图片直接从固定版本的上游仓库加载，当前仓库不捆绑整套论文原图。

打开图件后可阅读原论文、导入对照，或“交给助手”。导入时读取与校验图片、生成 SHA-256、复用现有参考图压缩及容量约束，保留论文标题、作者、会议、年份、原文链接和图库 ID。参考图仍最多 3 张；长作者名单在工程内引用中按 500 字限制截断，完整名单保留在图库索引与详情中。相同指纹复用已有参考图；异步期间画布变化或关闭弹窗不会把图片写进其他工程。网络失败原子退出。

“交给助手”导入当前图、切换到侧栏并勾选图片附件，填入“先分析布局、信息层次、结构与配色，再依据当前方法重新组织”的要求。用户点击发送后才调用已有本地 Harness，结果仍经过 FigureIR 校验、候选预览与人工应用。一次请求仍只附带当前参考图，没有宣称已经实现多个图件的联合视觉分析。

组件库 → “论文模板”按需加载 FigureForge 模板。缩略图作为独立 SVG 图片显示；选择后通过已有 SVG 解析器变成原生文字、形状与曲线，不把源 SVG 挂进编辑器 DOM。字体改用已打包的 Inter / MiSans。可配置比例、预览后插入，或存为“我的组件”再供 Harness 复用；源 SVG 的哈希、仓库版本、MIT 署名随素材保存和再次采集。

这些模板的数值、误差线、统计显著性和生物医学文字都是演示内容。界面及素材说明明确标记“示例”，助手契约要求先取得真实数据与统计依据，不能把演示数值当作实验结果。接入的模板包括柱状 / 分组柱状、折线 / 多折线、散点、环形、面积、箱线、森林、生存曲线、火山、单面板 / 左右 / 上下 / 四宫格 / 标题图注、流程示意与主副图组合。

第七十七批接入原生线性渐变后，`heatmap` / `comp-abc` 已可转换与复用，静态模板由 18 增至 20。仍暂缓 `violin` / `comp-ab`：源文件含负高度矩形，原样转换会得到错误的数据几何；保留源快照与资源清单中的原因，没有静默拉伸或拍扁。

第廿四批另实现从用户原始矩阵编译的 [数据热图](heatmaps.md)，复用该固定版本 `heatmap.dv` 的发散色端点，采用独立原生色块显示数值色标；来源与 MIT 署名保留。它不移植示例的聚类树，当时尚未增加通用渐变 SVG 导入，静态模板数仍为 18；当前能力见[线性渐变](svg-import.md#线性渐变编辑与复用)。

第廿五批再增加 [原始样本箱线图](boxplots.md)，只从使用者声明的逐次观测计算描述统计，未从静态模板的箱体几何反推样本，该批次静态模板数仍为 18，现为 20。

## 图表语义与整体缩放

节点增加可选 `chart={role,series,channels}`。role 分为 series / axis / grid / stat / heat / band / annotation / frame；series 是 0–11 的索引；channels 是 fill / stroke / text。SVG 导入从 FigureForge 标记推导此字段。图元重排、组件捕获 / 重插、缩放、候选差异、Harness 快照与省略字段恢复都保留该信息。

应用画布配色时，同系列图元及图例的指定通道一起换色，轴、网格、统计标记与热图色阶保持现有值。单对象填充 / 描边编辑仍可用，下一次主动应用画布配色会重新按系列设色。系列索引保留原模板的分组定义，不自动推断实验组的含义。

“整体等比缩放”对选定容器及后代提供 10–400% 相对比例、中心 / 左上角基点和预览，应用为一次可撤销操作。组件插入与模型实例同样支持 `scale`。位置、几何、实际字号 / 字距、描边、虚线、圆角、内部间距、绑定偏移与内部语义线同步缩放，命名接口保持边界比例；外部语义线保留引用并重新布线。

`metricScale`（0.05–16）记录预制结构固定绘制细节的基准缩放。几何与字体字段仍保存画布上的实际数值，避免只缩小外框。路径控制点、仿射文字、语义配色保持原语义。字体实际 1–256、描边 .01–64 等约束及父容器边界不放宽；超限整轮失败。缩放不能替代对长标签的重新排版。

## 后续直接复用的优先级

1. 已接入 `planSemanticRegions` / `planDetailRegions`、`regionObjectCatalog` / `applyRegionPatch`、`snapshotVersions`，建立到 FigureIR 的受控适配器，保留已有 ID、命名端口、来源、人工对象和候选审阅。其独立场景不能直接作为 FastFigure 工程；坐标注册、严格路径校验和完整工程引用检查由适配器补充。操作及验证见 [结构重建](reconstruction.md)。
2. `reconstruction-core.mjs` 的分块合并、缺失对象目录、质量缺口和 `acceptReconstructionRepair` 仍需结合独立样本与阈值接入；目前人工选择分区并审阅，不把已有函数或简单图片调用成功等同于自动质量门或 RSI。
3. FigureForge 的语义配色优先延伸到我们的编码器 / 注意力 / 检索结构和论文实验图。下一步把模板变成受控的数据参数配方、面板组合和直接标注，先解决真实实验数据输入，再补梯度色阶和有几何问题的模板。
4. CLIP 作为后续可选增强，与纯 CPU 标题检索对照测量，避免在初次打开编辑器时强制下载模型。多个参考图的构图总结应作为独立可审阅中间结果，再交给结构生成与图像模型。

## 许可和离线重建

两个项目代码为 MIT，原始许可随仓库与构建产物保留。Top-Conf 的 MIT 明确不涵盖论文图片；第三方原图、论文、标识仍归作者 / 出版方。图片政策和署名见 `third-party/topconf/IMAGES_POLICY.md` / `NOTICE.md`。FigureForge 的原始派生声明也保留。我们只打包图库元数据、模板定义及配色，不把论文图片宣称为可商用素材包。

```sh
pnpm resources:build
pnpm test
pnpm lint
pnpm build
pnpm test:ui
```

资源构建使用本地固定快照，先核对 SHA-256，再在隔离 VM 中求值模板生成代码并输出数据；应用运行时不动态求值模板脚本，没有引入第三方 key / relay / 模型服务配置。未修改的源文件保留；检索代码在 `src/vendor/topconf/retrieval.mjs` 只增加可选向量数组校验路径，实际调用传入标题 / 作者词项与零语义分数；重建几何 / 分区 / 补丁模块作为本地依赖直接导入。静态索引和模板在首次打开相应面板时加载。

默认回归用少量明确样例覆盖中文主题展开、筛选组合、精确标题 / 作者匹配、无结果、来源地址和重复 ID、图片大小与错误处理；模板转换 / 导出 / 缩放 / 采集 / 模型实例编译仅保留图表与结构示意两个代表，以及系列换色和保护中性层。资源总数不再作为断言；不逐份模板重复相同流程。浏览器使用自制图片验证运输与引用链，未把真实论文图片放入测试素材。
