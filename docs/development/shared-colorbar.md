# 热图统一色阶与可编辑共享色标

“多子图编排 → 共享色标”把 2–8 张已有热图的有效数值范围取并集，再从原始数据重绘颜色，生成一份横向数值色标。它要求相同色阶、完全相同的色标标题 / 单位，以及相同的发散中心；作者仍需核对它们表示同一物理量。不会转换单位、归一化、截断、补缺失或重排行列。

## 使用

先将各图放到共同外层容器，选择图表、顶部 / 底部位置、字体和 8–24 字号。在原图 / 共享色标之间比较后应用，整次变化可单步撤销。面板编排可预留底部 100 个画布单位；多视图数据选型请求共享色标时，程序自动预留这部分空间。空间不足、图元容量超限或刻度文字重叠时整次拒绝。

范围包含所有观测与原有固定边界。顺序色阶取各图有效范围的并集；发散色阶还要求中心一致，保留原中心及不对称固定边界。相同数值最终通过同一个颜色函数映射。源图的范围设置会更新，但原始值、零、缺失、来源、外框、字体及未选图表保留。

共享组件由 32 个矩形色段、一个标题和三个数值刻度组成，均可原生编辑。颜色段是既有数值插值的分段近似；不是连续渐变图元。可整体移动 / 等比缩放，也可独立改字体、粗斜体和文字颜色。较大的手工字号仍可能产生文字重叠，需要作者查看预览。

## 同步已有色标

在同一工具切换到“调整已有色标”。选中色标组后打开工具会优先调整该组；也可以从已有关系中选择。保留原色标组件及 36 个条目的 ID，更新它关联的原热图，不另插一份色标。

可以同时调整色阶、范围、发散中心、字体、字号与位置。未指定字体 / 字号时，保留各文字已有的混合设置和粗斜体、颜色等格式。位置可保留当前左上角，或移至共同容器的顶部 / 底部空白区；不移动源热图。预览报告显示真实前后范围、外框和各图重绘结果，无变化时禁用应用，助手也不产生空候选。

| 范围方式 | 行为 |
| --- | --- |
| 包含当前各图范围（并集） | 包含各关联图的有效范围，包括已有固定边界。默认方式。 |
| 按当前观测重新取范围 | 明确清除旧固定边界，从所有源观测重新计算；发散色阶按中心求自然范围。 |
| 指定统一范围 | 同时填写下界 / 上界；必须包含全部观测和发散中心，不允许裁剪数据。 |

色阶默认保留原共享色标的选择。发散中心默认保留，切到顺序色阶须清空中心；发散色阶未设置中心时使用该色阶默认值 0。由顺序切到发散时，若原范围把中心放在端点，应明确选“按当前观测重新取范围”或填写包含中心的固定范围，不会悄悄扩大范围改变所选策略。

源数据、色阶或固定范围经正常图表编辑后，可以使旧关系停用。只要源图仍与其数据配置一致，就能预览重新统一并恢复关系；标题 / 单位必须在所有源图中完全一致，更新不推断单位换算。手工改色 / 移动数据格，或改写共享刻度、移动单个色段、改变透明度等失配仍拒绝，避免覆盖作者的独立修改。

同步保留原始值、零 / 缺失、行列顺序、来源、手工标题 / 格式、额外对象、绘制顺序和原有连接。命名接口随外框更新，绑定到色标文字的外部引线继续跟随原对象。字号调整后的选择边界预留字体行框空间，排布同时检查新增文字范围；手工对象冲突、父容器空间不足或特殊文字变换会整次拒绝。

## 保留与失配恢复

源色标不从工程中删除；共享关系有效时，只在渲染和导出中隐藏重复色标。源图元 ID、手工文字 / 格式、另加对象、接口、连接与图层顺序保持。格内文字的自动前景色会按新的背景色重算，保留显式手工格式覆盖。共享组件记录色阶来源，单独采集成素材后仍保留来源引用。

源热图的色阶、范围、中心、单位、可见数值、色块颜色或几何与配置不符时，恢复各图本地色标、隐藏旧共享条目并显示停用提示。改写共享刻度、移动单个色段 / 刻度、修改颜色或透明度也会使关系停用。标题与刻度字体可变，数值和锚点保持才继续生效。删除源热图或创建重复关系同样会停用。

创建前，手工改色 / 移动的数据格、改写 / 隐藏的数值与色标、外部绑定到源色标、重新分组 / 增删生成图元会被拒绝，以免静默覆盖或隐藏语义锚点。影响所有后代的容器整体透明度会改变颜色编码，当前拒绝；仅淡化容器背景的 visual.opacity 不影响数据色块，允许使用。

解除共享会恢复各图色标，保留共享副本及已统一的范围；若要恢复操作前的范围，应撤销整次创建。后续独立编辑不会主动联动其他图，需要明确预览 / 应用上述同步；每次渲染 / SVG / draw.io 导出都会核对一致性。独立采集共享组件会解除来源关联，成为普通可编辑快照；采集完整图件并插入时映射源图表与色标条目的 ID。

## 助手和多视图

Harness 上下文提供 colorbarTargets、已有共享状态 / 可更新原因、各源图当前范围与数值色阶清单。新建请求：

```json
{"message":"统一热图颜色含义","figure":null,"sharedColorbars":[{"containerIds":["heat-a","heat-b"],"placement":"bottom","fontFamily":"MiSans","fontSize":14,"reason":"比较相同物理量"}]}
```

已有关系使用单数 containerId，不能混入新建的 containerIds：

```json
{"message":"按当前观测同步已有色标","figure":null,"sharedColorbars":[{"containerId":"shared-scale","paletteId":"heat-teal","range":"data","center":null,"placement":"preserve","fontFamily":"MiSans","fontSize":12,"reason":"两图仍表示同一物理量，源数据已更新"}]}
```

range 可为 union / data / fixed，fixed 必须同时给 min / max。省略 center 保留原中心，null 明确清空；fontFamily / fontSize 省略则分别保留每个文字的现有格式。

每轮最多一组，不能混入其他改图、组合参数、共享轴 / 图例 / 绘图区或新实例。范围、重绘及实际报告由程序生成，进入事件、历史和候选审阅，候选不会自动应用。

多视图选型可设 sharedColorbar=true，所有视图必须是可比较的原生热图；不与共享系列图例混用。逐图实际报告更新为统一后的数值范围，避免仍显示编排前的自动色标。图元总数仍受 240 限制，不会为容纳共享色标删掉源色标或观测。
