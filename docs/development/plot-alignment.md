# 原生图表绘图区对齐

“多子图编排 → 绘图区对齐”对齐实际坐标轴或热图矩阵围成的区域。面板外框、图表外框、字号和数值范围保持；只从保存的原始数据重新计算图元位置。支持折线、柱状、散点、原始样本箱线图与热图混排，热图单元格始终保持正方形。

## 使用

先把图件放到现有网格，选择共同外层容器和 2–8 张图表，指定 1–4 列。列表显示行列位置，可前移 / 后移，按从左到右、从上到下理解；一列用于上下比较，两列用于并排或两列矩阵。左侧可切换原图 / 对齐结果，报告逐图显示画布单位的宽高与重排数量。预览不改画布，应用为一次可撤销操作；设置随工程、组件和 SVG 元数据保存。

同行取各图可用范围的最大上沿与最小下沿，同列取最大左沿与最小右沿。可用范围由每张图的原始配置、字号、刻度宽度、图例和说明重新计算，固定区域只能多留空间，不能挤进标签区域。不同缩放比例通过容器的 metricScale 换算到同一画布坐标后求交，再写回各自 760 × 460 的原生坐标。

这不会替用户移动图件或推测布局。错误的行列顺序、没有共同区域或标签过密时整次拒绝。数值坐标图仍要求至少 240 × 140 原生单位；热图按行列数和实际格宽检查字体与密度，允许合法的窄矩阵。各图字号继续独立，想统一物理字号可先编辑图表；想统一数值轴范围可另用“统一纵轴”。布局对齐本身不表示不同图的数据、单位或方法等价。

## 热图的方格约束

热图取 matrix-frame 的实际边界作为绘图区，保留标签、色标及说明的空间。同行共用一组上下边界、同列共用一组左右边界；矩阵列数 / 行数同时约束该列宽度与该行高度。程序在可用空间内求每组相关尺寸的最大可行比例，再居中放置，不把矩阵拉成长方形。

不同行列比例的热图可以同排，也可与普通数值图组成网格。例如 3 行 2 列、3 行 3 列、2 行 2 列三张矩阵加一张折线图，能共同对齐；但在最后一格再放 2 行 2 列矩阵，会使这个 2×2 网格的比例条件互相冲突，此时应改顺序、列数或分开编排。程序明确拒绝，不通过删行列、转置、隐藏单元格或改变数据凑布局。

固定绘图区必须严格对应方格比例。列名方向按实际单元格宽度决定，放不下时要求调整字号 / 排布，不缩字或省略列名。之后修改行列数量、长标签或字号可能使旧固定框不再合适，可在图表编辑器“恢复自动绘图区”后重排。

已有共享数值色标可继续生效：矩阵及保留在工程中的局部色标从源数据重新排位，数值颜色、范围、原共享色标组件与条目保持。对齐不主动同步色阶，不修复之前已经失配的手工色标。

## 保留与边界

- 原始值、顺序、零、缺失、误差含义、对数映射、箱线统计规则、来源、论文尺寸、图表外框和未选图表保持。
- 原节点对应关系、颜色、线型、手工文字格式与改字保留。另加对象、接口和连接保留，手工注释的位置不跟着数据点自动排布。重绘维持原有图层顺序，避免将新数据标记压到用户注释上。
- 数据标记或坐标轴被手工移动 / 改形、生成对象增删 / 重新分组、外框被单独拉伸或同一容器有其他受管理结构时拒绝，避免覆盖手工几何。
- 图表编辑器显示固定绘图区状态，并提供“恢复自动绘图区”。改字号、标签或范围后，如果固定区域放不下，会提示恢复自动布局再调整 / 重新对齐；不会缩字或隐藏刻度。
- 固定绘图区保存在每张图的配置中。后续移动或独立编辑不会动态联动其他图；可重新对齐。共享图例有效时仍按原图例留白，不自动回收内部空白。手工改字或字体造成的遮挡仍需预览核对。

## 助手

普通 Harness 上下文提供 plotAlignmentTargets，包含当前真实绘图区、可用范围与不可用原因；热图另提供 matrix.rows / columns。模型仅能单独提交：

```json
{"message":"对齐已有图表","figure":null,"plotAlignments":[{"containerIds":["left-chart","right-chart"],"columns":2,"reason":"对齐并排比较区域"}]}
```

每轮最多一组，不能夹带图件、配方、共享纵轴、共享图例或新实例。程序原子编译实际重排，报告进入事件、历史和候选审阅；无变化不产生候选。多视图选图可设 alignPlots=true，在程序完成面板编排后、共享图例 / 色标生成前执行同一操作；全热图多视图可同时请求 sharedColorbar=true。
