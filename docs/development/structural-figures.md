# 论文结构图

在 **组件 → 参数化组合 → 组件分类 → 论文结构图** 选择分层架构、层级树、中心辐射、循环闭环、结构矩阵、金字塔与漏斗、耦合双循环、泳道协作、集合交叠、同心圈层、多尺度特征金字塔、双编码器配对对齐、U 形编解码、残差／瓶颈块、邻域消息传递、Top-1 专家路由、蒸馏训练／推理、掩码预训练迁移、时序记忆读写或跨视图／逐视图交替注意力、混合序列注意力掩码或条件去噪展开。点击卡片配置参数，查看预览后插入当前容器，或新建图件并插入。新建图件替换当前画布，可撤销。

这些配方生成 FigureIR 原生图形，不依赖原始 PPT 文件在运行时存在。层标签、模块、周边单元、矩阵单元、层片和旁注可分别选中、改字与编辑。层级和辐射的路径保存端点绑定；循环使用可编辑的三次贝塞尔弧，首尾闭合。分层架构每一层保存为真实的嵌套自由组合，整体布局与采集保留其后代。

属性栏“调整组合参数”沿用现有预览／应用流程，支持保持比例扩框或适配原框，并保留仍存在单元的手工文字、格式、外部连接和来源。增删参数会重新生成几何；若要删除的单元仍被外部对象引用，整次更新拒绝。手工删改配方管理对象后，需要按现有参数更新规则先处理对应记录。见[参数更新](recipe-parameters.md)。

## 参数与含义

| ID | 参数 | 含义 |
| --- | --- | --- |
| `mixed-modal-mask` | `format=text-image/image-text/interleaved/text-only`, `textTokens=1..3`, `imageTokens=2..3` | query 行／key 列许可；同一图像内双向、跨块因果；类别色块无数值权重 |
| `conditioned-denoising` | `steps=2..4` | 连续潜变量推理的示意区间；共享噪声预测、独立采样更新、固定条件和最终解码，非离散 token 替换 |
| `streaming-memory` | `memories=2..4`, `prompt=show/hide` | 历史 <t 读取、当前帧与可选提示、掩码及无条件图像特征编码、后续状态 ≤t 写入；不是同帧循环 |
| `alternating-view-attention` | `views=2..4` | 同身份视图行、跨视图联合／逐视图独立注意力交替、符号重复 L、相机／稠密头及另需查询点的跟踪模块 |
| `distillation-stages` | `hardTargets=show/hide` | 固定教师／学生软目标与可选硬目标；部署只迁移学生 θ，训练更新与参数迁移分开 |
| `masked-autoencoding` | `grid=2..4`, `visible=few/half` | 可见块编码后加入掩码与恢复顺序、仅掩码位置损失、下游只迁移 Eθ；网格和模式仅示意 |
| `graph-message-passing` | `neighbors=2..5` | 局部邻域、逐邻居消息、求和、结合旧状态更新；不含全图读出或注意力 |
| `top1-expert-routing` | `experts=2..5`, `activeExpert=1..experts` | 单 token 的显式示意路由，仅选中专家有数据路径，门控值独立输入乘法；不计算概率和容量 |
| `unet-encoder-decoder` | `levels=3..5`（含瓶颈） | 收缩／扩展、共享瓶颈、copy/crop → C 拼接；2×2 池化、2×2 上卷积、1×1 输出；阶段概括两次 3×3 conv+ReLU |
| `residual-block` | `block=basic/bottleneck`, `shortcut=identity/projection` | 主分支与恒等／投影捷径相加后 ReLU；卷积后 BN，中间卷积后 ReLU；不代表 pre-activation 版本 |
| `feature-pyramid` | `levels=3..5` | 自底向上、横向 1×1、自顶向下 2× 上采样、相加、3×3 输出；层数为示意变体 |
| `dual-encoder-alignment` | `pairs=3..5`, `objective=symmetric/alignment-only` | 两路编码与配对矩阵；对角仅表示配对身份，双向目标可显式省略 |
| `layered-architecture` | `layers=2..5`, `modules=2..4`, `shared=show/hide` | 层内包含模块，共享区独立；层次不默认表示数据流 |
| `hierarchy-tree` | `branches=2..4`, `leaves=1..3`, `direction=down/right`, `branch1Leaves..branch4Leaves=0..3/inherit`（可省略） | 支持不均衡及无叶终端；根、分支、叶子；方向控制展开，连线表示从属 |
| `radial-hub` | `items=3..8`, `relation=none/outward/inward` | 默认无向，仅明确选择方向时生成箭头 |
| `cycle-loop` | `items=3..8`, `direction=clockwise/counterclockwise` | 单闭环，方向决定相邻阶段的连接顺序 |
| `structure-matrix` | `rows=2..4`, `columns=2..4`, `headers=show/hide` | 类别或模块对照；实验观测应使用现有数据图表 |
| `tiered-pyramid` | `levels=2..5`, `profile=pyramid/funnel` | 层级轮廓；宽度不编码数值、比例或转化率 |
| `coupled-cycles` | `leftStages=2..5`, `rightStages=2..5`, `rightDirection=clockwise/counterclockwise` | 两个闭环共享一个状态节点；左环固定顺时针，右环明确选择方向 |
| `swimlane-process` | `lanes=2..4`, `stages=2..4`, `flow=parallel/handoff` | 嵌套泳道表示任务归属；独立序列没有跨道连线，交接序列沿交替方向串接 |
| `set-overlap` | `sets=2..3`, `overlap=narrow/broad` | 半透明集合圆的真实交叠；没有面积计数或集合运算 |
| `concentric-layers` | `layers=2..5`, `labels=show/hide` | 带孔复合路径形成环带，核心独立；圈层表示上下文和包含 |

双循环每一侧有“阶段数 + 1”条弧线，包含从共享状态出发和返回共享状态的关系。改变一侧阶段数不改变另一侧的对象身份。泳道任务以执行序号命名，切换为交接模式时，偶数显示行的任务从右向左排列；序号及人工文字跟随任务，跨道线通过侧边空隙连接。

集合圆的名称和图形分开编辑，半透明填充随图形移动自然改变视觉交叠。没有持久的布尔交集对象或面积编码。同心环带是带 `evenodd` 填充规则的独立复合路径，可编辑控制点；独立移动后不会自动保持同心。示意图的空间关系需要作者按实际含义维护。

每个结构提供 `structure-left` / `structure-right` 双向命名接口，表示组件边界。它们不自动赋予科学输入／输出含义，可在已有接口编辑器中按实际方法命名、调整或补充。独立路径和图形继续使用现有端点绑定、曲线、批量样式、主题色槽和撤销功能。

## 助手、素材和导出

目录检索包含中英文关系词，助手冻结目录时得到实际参数、节点别名、双向接口、来源和 `structureSemantics`。后者明确各类关系、示意计数及允许编辑方式。模型通过内置 `recipe:<id>` 实例编译或受控参数更新提出候选，仍需人工审阅应用。保存为组件后直接复用快照，保持手工修改；需要参数重绘时使用内置配方或“调整已有组合参数”。

结构仍使用已有素材 JSON／采集／重插和原生 SVG 导出链路。SVG 元数据保留可恢复图元、参数对应与来源。真实模型质量仍需验证。

来源取自 [FastPPT 结构研究](../research/2026-10-31-ppt-structure-figures.md) 和[关系结构扩展](../research/2026-10-31-relational-structures.md) 的本地原 PPTX，记录资源 ID、页码、相对源路径和文件 SHA-256。仅抽象结构关系独立构造中性示意，未搬入第三方整页、Logo、文字样例或数据。参数和原生图元受现有 1,000×620 画板、240 图元、21 容器及六层嵌套等约束；多个复杂结构组合时可能需要缩放或拆分。

## 验证

已有 `assets.test.ts` 增加七项不同风险检查：嵌套层与共享区、树方向／绑定随动、辐射方向、闭环曲线／反向更新、类别矩阵、闭合分层轮廓，以及一次助手编译／手工修改／外部引用保护／采集重插／SVG 元数据往返。边界检查采用默认、极值及非对称代表，未穷举参数笛卡尔积。文字检查同时覆盖小尺寸说明，发现并修复矩阵说明截断。

原编辑 UI 流程保留一个结构代表，当前使用不对称双循环：左环两阶段、右环五阶段逆时针，检查曲线预览、共享状态、真实首尾绑定、画布改字及撤销恢复。没有新增 UI 文件或模型夹具。

第八十四批验收为 582 项核心／服务检查、40 个文件通过，Lint、类型检查与生产构建通过；四条 1920×1080 UI 流程通过，本机实测 53.767 秒。另检查了当时六类默认配方的浏览器渲染并生成结构总览，未执行新的真实模型调用或外部编辑器往返验收。

第八十五批新增五项资产风险检查：不对称双环闭合和阶段身份、泳道归属／交接避开任务内部、集合交叠和独占区域标签、复合环带孔洞，以及一次助手参数更新／嵌套绑定／外部引用保护／保存重插。提取共用绘图函数前后核对了原有十二种配方默认结果，保持完全一致。

第八十五批为 587 项、40 个核心／服务文件通过；Lint、类型和生产构建通过，四条桌面 UI 流程通过，本机实测 55.89 秒。另用浏览器核对四类默认和四组边界配置的实际字形范围，并检查[新增结构预览](../research/assets/ppt-relational-overview.png)。没有新增真实模型调用或外部编辑器验收。

## 论文参考与复合主图（第八十六批）

新增 FPN 与 CLIP 原文结构抽象，结构配方共十二类，全部参数化组合十八种。原文核对、语义边界与混合结构示例见[论文主图编排](../research/2026-10-31-paper-composition.md)。

层级树可为各分支设 0–3 个叶子或继承默认数量，零表示终端分支；隐藏的分支参数保留，旧默认几何保持。

选中 1–24 个原生对象，点击画布工具栏“放大选中局部”，可选 1–4 倍、共同外层容器和位置，预览后应用。副本来自实际选中图元，保留文字、外观、数据及内部关系；框内未选对象不复制，外部语义边不复制，指向外部的路径端点保留几何并解除绑定。源框和副本框以无箭头引线对应。源图后续编辑不自动同步，证据记录保留历史对象 ID、时间、倍率和省略关系。局部图表必须整体选择；容量、放置和文字失败时整次拒绝。

助手通过单独的 `materialEdits: [{kind:"detail-inset", objectIds, parentId, scale, caption, guides, position?}]` 使用同一编译器；当前与新实例生成／采用方案不能混合提交，需在已生成图上继续处理真实选区。概念性机制解释可在方案生成阶段直接绘制，但不能声称为实际选区快照；用同名阶段和对应标记关联而无需引线时，方案可用 membership 说明关系。见[单尺度融合的实际修改](../research/2026-10-31-mainfigure-revision.md)。

## 编解码、残差与结构适配（第八十七批）

新增 U 形编解码／拼接跳连、残差／瓶颈块，当前十四类结构、二十种参数化组合。已核对原论文图、相加／拼接的区别、激活位置及投影假设；形状和层数仍为示意，不填造通道／空间尺寸或性能。旧十八种默认资产保持一致。

原生目录增加 `compositionUse`：结构族、适用角色、选择条件和误用提醒。主图／复合请求的自动推荐保留相关性，降低同族原生配方连续占位，缺省项先补不同族；普通查询和手选入口保持原路径。个人手改资产独立考虑，不据原配方认定它与其他资产等价。至多六项仍是候选，助手不必全部采用，也不能推断组件之间存在真实科学关系。

[分析与完整主图示例](../research/2026-10-31-skip-composition.md) 包含任务概览、U 形架构和真实选区拼接局部；图元、参数记录、来源和分区方案均可导入编辑。

## 图聚合、专家路由与新方案约束（第八十八批）
