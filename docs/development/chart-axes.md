# 对数坐标、数值范围与助手选型

2026-10-29，第廿六批。数据图表增加线性 / log10 坐标与数值 X 范围，并接入编辑、选图、保存后的样式重绘、实际坐标报告及 SVG 数据往返。用于模型规模、延迟、计算量等跨数量级比较；不会因为数值为正就自动切换。

## 使用

在“组件 → 实验图表”配置折线或散点，可分别选择横纵轴的“线性 / log10 对数”，并填写可选最小 / 最大值。“载入数量级示例”提供明确标记的自制示例。箱线图提供纵轴选择，样本标识轴继续按组等距排列。编辑器预览显示实际采用的坐标类型与范围；图内对数轴标题自动附上 `· log10`，原始单位与用户填写的标题保存在数据配置中。

从左侧助手导入原表时，可直接描述研究问题，例如“比较模型规模每增大十倍时延迟的倍数变化”。模型可选择图型、原始字段、坐标表现与配色，解释理由及备选。程序读取原数据编译图形，并产生 `axes` 报告；报告中的类型和边界不是模型自行宣称的结果。仅在候选审阅后应用，仍可撤销。

| 类型 | 数值 X | 数值 Y |
| --- | --- | --- |
| 数值折线、散点 | 线性 / log10；可手动范围 | 线性 / log10；可手动范围 |
| 分类折线 | 等距分类，无数值范围 | 线性 / log10；可手动范围 |
| 箱线 | 组名等距分类 | 线性 / log10；可手动范围 |
| 分组柱状 | 等距分类 | 线性，保留零基线 |
| 热图 | 原始矩阵列与行 | 独立数值色标，不用这些坐标参数 |

直接编辑器切换到柱状时，恢复线性坐标并清除旧的手动范围，自动覆盖输入和零基线；取消不改当前工程。助手重绘使用显式参数，若源图有不适用于柱状的对数刻度或 X 范围，须明确恢复线性并用 `null` 清除范围，程序不会默默覆盖请求。

## 显示与数据约束

数值按 `t=(log10(v)-log10(min))/(log10(max)-log10(min))` 映射，等倍数变化等距；标签仍显示原值和原单位。对数变换与有效域的依据见 [D3 对数坐标说明](https://d3js.org/d3-scale/log) 和 [Matplotlib LogScale](https://matplotlib.org/stable/api/scale_api.html#matplotlib.scale.LogScale)。本项目使用自己的原生图元编译器，没有增加 D3 / Matplotlib 运行依赖。

本批只支持正值、底数 10 的对数轴。所有输入 X、有效 Y、误差上下端点及手动边界须大于 0；即使某行 Y 缺失，其 X 仍保留并检查。零 / 负值 / 跨零误差整轮拒绝，提示线性或补充确认，不通过丢点、遮蔽、裁剪、加常数或单位换算凑图。暂不支持 log2、自然对数、负域、symlog 或断轴。

原始误差是已声明的对称 ± 半宽，程序分别映射 `v-e` 和 `v+e`；对数图上两侧长度可以不同，不把已取对数的误差当作输入。原始值、误差说明、缺失、备注、来源及示例身份保持。该显示不计算误差估计、拟合或因果关系。

箱线先在原始样本上计算既定 type 7 四分位数、1.5 IQR 须线和离群，再映射这些统计量及原始点。不会在 log 样本上重新计算，也不会因为坐标切换而改变 n / 缺失 / 离群分类。非正原始观测仍拒绝，包含非叠加显示的样本。详见 [原始样本箱线图](boxplots.md)。

自动对数范围向外扩展至十的整数幂，常量场扩展为正的非零区间；极小正数下界若幂计算下溢，则保留实际可表示的原值。短范围可用 1 / 2 / 5 倍刻度，宽范围稀疏选整数幂，最多 10 个主刻度；无合适内部刻度时显示真实边界，不发明新的观测。精度不足或标签无法区分时拒绝，不重复显示相同刻度。自定义范围必须覆盖全部数据及误差。

## 保存与协议

`dataChart.spec` 增加可选 `xScale/yScale='linear'|'log10'`、`xMin/xMax`；省略 scale 时为线性，省略边界时自动。既有 `yMin/yMax` 继续使用原值。分类 X 不接受 log10 或数值范围；热图不接受这些轴字段；柱状 Y 不接受 log10。

`chartOptions` 支持同名表现字段：省略表示保留设置，边界 `null` 表示恢复自动，恢复线性需明确传 `linear`，不能用 `null` 清除 scale。工具固定所有原始观测和声明，按新表现重绘生成图元，保留另加对象。推荐对象可选择同名轴字段，但不接受 `offset`、`base`、新 log 值或模型提供的 `axes` 报告。

程序生成 `axes={x:{scale,min?,max?},y:{scale,min,max}}`；分类 X 只报告 `scale=category`。推荐和图表重绘记录、SSE、消息历史及刷新回看均保留该报告。刻度切换不改变原始样本匹配身份；组件捕获 / 缩放 / 重插、工程 JSON 和 FastFigure SVG 元数据往返保留坐标设置。
