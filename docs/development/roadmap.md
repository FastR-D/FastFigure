# FastFigure 逐项开发清单

以可编辑的计算机科研图为核心，采用 pnpm 单应用。PDF 系统只作参考，界面复用 FastPPT 组件；业务模板不得直接使用 HTML 元素。以下区分已实现、已检查和后续工作，不把研究目标记为产品能力。

当前布局与验收只面向固定 1920px 工作区。下文旧批次的窄屏 / 多宽度记录仅为历史；测试不再维护宽度矩阵或逐功能浏览器脚本，最新维护范围见[开发与验收约定](testing.md)。

## 第一批 已实现

- [x] Vue 3、TypeScript、Vite、pnpm 项目与锁文件，无 workspace 包。
- [x] 将 FastPPT 基础组件复制到 `src/components/ui`，本地维护；复用控件、焦点管理、图标、颜色令牌与主题工具。
- [x] 工作台头部、导航、组件库、图层、画布、属性栏、工程与导出弹窗。
- [x] FigureIR 版本、节点、容器、端口、连接、样式和输入校验。
- [x] 八个内置组件种子，使用模块、token、张量和队列四种图元表示。
- [x] 添加时查找空位；对象拖动、标签和位置修改、节点删除与关联边清理。
- [x] 通过点击两个节点建立连接；在图层中选择边并编辑端点和端口。
- [x] 六种容器皮肤、图件色系和固定 seed 的手绘生成；样式切换保留拓扑。
- [x] 单步撤销重做、快捷键、本地显式保存、校验后导入 JSON；导入失败保持现有工程。
- [x] SVG 导出、带原生节点与端点引用的 draw.io XML、完整 JSON 工程。
- [x] 桌面与窄屏布局、可关闭面板、图标按钮标签和对话框焦点管理。
- [x] ESLint 检查 Vue 业务与基础组件模板中的裸 HTML；SVG 渲染集中在绘图组件和渲染器。

当前使用 0.2 工程模型。旧版工程和本地存储不迁移；图件源数据统一表示容器树与节点父级。draw.io 的皮肤采用近似映射，外部编辑器兼容需要单独验收。
