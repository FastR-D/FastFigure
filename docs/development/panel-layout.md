# 多子图编排

入口在中央画布工具栏的“多子图编排”，以及右侧选区操作。只维护 1920×1080 桌面布局。

## 使用

先把每张图放在独立容器中，再打开编排，选择共同的外层容器。可选择 2–8 张同层图件、调整顺序，设置 1–4 列、面板间距、外侧最小留白、标号字号、起始字母和可选说明。选中原生组件时默认使用它的外层，避免把组件内部结构当作多张子图。

按从左到右、从上到下生成 `(a)`、`(b)` 等标号。标号与说明组成一个原生面板标题，当前位于图件上方，可用画布双击、右侧对象标签和文字工具栏继续编辑。已有面板使用“自动布局”重新排列，不再次包一层面板；编排工具不会自动重编号已有标题。

预览不修改工程。应用创建透明的 `panel` 容器，将原图件整体放入其中，保留内部对象 ID、数据图配置、手工注释、命名接口与组件来源。选中新面板后可一起移动，应用是一次可撤销的修改。SVG 和 draw.io 保持原生文字、图形与分组，组合仍可捕获为素材。

## 几何与数据

网格使用等宽列，预留面板标题区。需要时对所有源图件使用同一个缩小比例，不放大、拉伸或单独改变某一张图的比例。字号、描边、路径、接口与几何同步缩放，数据值、单位和误差含义保持。图件较短时面板高度随内容收紧，整组在外层内容区垂直居中，避免标题与图件间出现大片空白。

关闭“统一等比缩小”后，放不下就拒绝。面板至少 200 × 120，沿用 240 图元、21 容器与六层嵌套上限；不能通过编排绕过约束。标题与说明限制为单行，超出估算宽度时要求缩短说明或调整列数 / 字号，不静默裁字。

未选的同层对象保持；网格与这些对象重叠时整次拒绝。外层共享引线和语义连线保留。子图内部路径若绑定到该子图之外，要求先把跨图引线放到共同外层，不自动解除绑定。几何、绑定或字号无效时原工程保持。预览冻结打开时的工程，后台候选应用等变化会阻止旧预览应用。

数据图表仍在内部原容器中，后续修改数据只重建受管理图元，保持面板归属与手工注释。本功能不合并数据、不重新统计，也不自动生成共享坐标轴 / 图例或判断多个图是否可以科学地比较。

界面显示缩放比例与最小主标签 / 注释字号；小于 8 个画布单位时提示人工核对出版尺寸。该数字不是完整字形可读性评测，结构内部小标签、定位字形和遮挡仍需人工查看。

## 验证边界

在既有 `layout.test.ts` 中增加三个不同风险场景：数据 / 来源 / ID 与嵌套图表更新保持、整次历史与持久化；无效参数 / 重叠 / 宽度与空间失败保持原图；内部引线保留及跨图绑定拒绝。没有新增测试文件。

既有编辑流程加入两张原生数据图的预览、换序、应用 / 撤销、标号编辑和刷新恢复，仍为五个 UI 文件、四条 1920px 流程。首次夹具比较暴露内存 `undefined` 与 JSON 的差别，随后修正测试序列化；第二次失败来自测试误用可见字段文字而非 `对象标签` 的实际可访问名称。两者记录保留。实际查看后收紧了短图的面板高度。

独立临时服务中混排原生图像分块组件与折线图：137 图元、九条边，数据配置、来源、原 ID 与保存恢复保持，零运行时错误。输入、原生工程、SVG 和截图位于忽略提交的 `test-results/panel-layout-ui-v1/`；早期混排准备命令误写配方字段，校验拒绝并保留记录，修正后使用注册表默认参数。均为自制开发样例，没有真实模型调用或论文质量结论。

最终源码通过 Lint、类型 / 生产构建、514 项核心 / 服务检查及四条桌面 UI 流程，最新 UI 用时 26.967 秒。`selected-component/` 另核对选中复杂组件后的默认共同外层，产出与此前原生混排工程逐项一致；记录的源码 SHA 已与最终实现核对。实际查看了编排对话框、收紧后的两张数据图和混排工作区。
