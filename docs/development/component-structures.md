# 论文组件的结构表达

当前 24 个组件种子中，9 个带可调内部结构，覆盖 8 类绘制方式。矩形、圆形、菱形、圆角矩形、文字、直线和箭头等保留在组件库；配色和图标各有独立 Tab。结构以 SVG 原生几何生成，与外部图标资源分开。

| 预设 | 绘制内容 | 可改参数 |
| --- | --- | --- |
| Transformer 编码器 | Self-attention → Add & Norm → Feed-forward → Add & Norm，两条残差旁路 | 内部标签、×N |
| Transformer 解码器 | Masked self-attention、交叉注意力及编码器上下文输入、FFN、三条残差旁路 | 内部标签、×N |
| 缩放点积注意力 | Q/K/V 分路，QKᵀ / √d、Softmax、加权 V | 六项标签 |
| MLP | 三列神经元、相邻列全连接 | 输入 / 隐藏 / 输出标签 |
| 卷积 | 层叠特征图、网格、局部卷积核与输出 | 特征 / 卷积核 / 输出标签 |
| 向量检索 | 查询向量、索引圆柱、搜索与 Top-k 文档 | 查询 / 索引 / 结果标签 |
| 特征融合 | 两个输入分支汇入拼接块，再投影输出 | 输入和算子标签 |
| 键值存储 | Key / Value 槽位、高亮访问行、读写箭头 | 键 / 值 / 访问标签 |

Transformer 预设依据 [Attention Is All You Need，§3.1–3.2 和 Figure 1–2](https://arxiv.org/html/1706.03762v7)，采用该文的后归一化层顺序；查询、索引和 Top-k 的关系参考 [RAG，§2.2 和 Figure 1](https://arxiv.org/html/2005.11401v4)。程序重新构造结构示意，没有拷贝原图像素或 SVG。MLP、卷积、融合和存储为通用表达预设，不声称复现某个具体方法。

编码器不必是 Transformer。创建时请显式选择与方法一致的结构，或使用 `none` 回到通用模块。内置种子显式记录类型，改名字不会改变结构；少数常规英文名称的现有 module 会显示对应默认示意，第一次编辑或由助手修订时保留为显式参数，选择 `none` 可关闭。

`FigureNode.structure={type,repeats?,labels?}` 中，`repeats` 为 1–12，显示为 ×N，不展开 N 份计算图；`labels` 每项最多 40 字、最多 6 项，省略位置使用预设文字。结构仅对 `module` 生效。几何依照节点尺寸生成，内部字体为 8–11 单位；尺寸不足时保留拓扑轮廓并隐藏内部标签。主标题仍遵循用户选择的字号，不通过缩小主文字来塞内容。

画布支持双击主标题、注释及内部标签编辑；属性栏提供结构选择、标签、重复层数及展开尺寸操作。展开会检查同层空位与父容器范围，失败不改工程。格式栏负责主标题与注释的字体等格式；内部几何随组配色变化，内部文字跟随主标题字体家族。

## 转换为独立图元

属性栏“转换为独立图元”先预览，再一次性写入可读尺寸下的形状、文字与路径。转换前的节点 ID 保留为隐藏的外部连接接口，放进 `role=component` 的自由组合中，接口包围盒跟随组合；外部 edge 的 ID、source、target 和端口均不改写。自由组合不绘制隐式标题栏，标题、注释和 ×N 均为独立文字。四周边距为 2，最小尺寸 5×5。普通容器仍至少 200×120，内容区保留标题和边距。

`kind=path` 节点包含 `path={points,arrow,fillRule?,start?,end?}`。2–128 个锚点 points 使用包围盒内 0..1 相对坐标，节点的 x/y/width/height 保存绝对包围盒，允许一条轴为零。arrow 为 none/open/filled。可选 start/end 各含 `{nodeId,x,y,offsetX?,offsetY?}`：引用有效非路径节点，以相对位置和至多 ±24 偏移保存端点。程序为结构内相邻图元生成绑定，移动 / 缩放目标时重算包围盒；路径不能绑定另一条路径，避免循环依赖。

选中路径会显示端点与折点。鼠标拖动、方向键精调、坐标输入、增删折点、线宽 / 描边 / 箭头均可操作；拖动端点会解除该端绑定，单独移动路径会解除未一起移动的目标绑定，编辑中间折点保持端点绑定。Escape 取消拖动，整个拖动只产生一次撤销。删除图元同时移除关联原生路径；解组时原外部接口变为可见外框，原外部连接继续随该框移动。纯原生图元可以组合为无标题栏的透明分组。

图元总数上限 240，科研节点仍限 60，语义 edges 仍限 120；容器限 21、深度限 6。转换、绑定、引用、重名、几何与容量均经过 FigureIR 校验。重复层数仍是 ×N 说明，转换后不会由预设参数重新生成内部图元；要恢复参数预设，可撤销转换或重新插入种子。

转换后的图元用 `visual.colorIndex`、`tone=fill/hatch` 和 `textTone=ink/deep` 保存语义配色，显式 fill/stroke/textStyle.color 优先。自由图元内部使用精确几何；转为普通图元解组时会保留当前局部外观。局部图元组合再次入库会继承祖先素材来源与谱系，各对象原有精确证据不改写。组件采集、JSON、重新插入、Harness 实例编译均重映射接口和路径绑定，不让两个副本共享端点。递归外层布局将自由组合当作整体，保留其内部几何，避免将装饰线段当成独立流程层次重排。

Canvas、组件预览、SVG 和 draw.io 共用结构几何。SVG 使用矩形、椭圆、路径和文字；draw.io 将每个内部图形和线段写成子 cell，生成 ID 避让工程已有 ID，外部连线仍绑定主节点。已验证 XML、引用和原生结构表达，尚未完成外部编辑器中的真实编辑往返。SVG 字体仅保留名称，没有嵌入字体文件。

Harness 上下文含结构类型、默认标签、推荐尺寸、原生路径、端点绑定与组件接口契约，模型通过同一 FigureIR 提出修改；候选差异包含路径、接口和结构来源。省略现有格式、结构、路径、接口、注释和图标时保留这些字段；`none` 可显式清除预设结构。原生组件清单对外暴露稳定接口，模型引用别名，由程序编译为各自独立的端点。该能力是结构化输出与程序绘制，没有注册新的 MCP 工具，也没有执行模型生成的绘图代码。本批未新增真实模型调用验收。

后续扩展为直线、二次 / 三次贝塞尔和闭合复合轮廓；控制点可拖动编辑，新增锚点按原曲线精确拆分。SVG 源素材通过同一 FigureIR 转成可编辑对象。曲线 / 导入文字在 draw.io 中以独立 SVG 对象保留外观，控制点在 FastFigure 编辑；整组透明度导出限制、128 锚点与全图 4,096 点上限见 [SVG 素材导入](svg-import.md)。

自由图元组合现可在属性中添加命名输入 / 输出接口，供手动连线与模型复用。它们与展开时保留原节点 ID 的整组接口分别管理，已有外部连接继续保留。公开接口、反馈路由和入库行为见 [命名组件接口](component-ports.md)。
