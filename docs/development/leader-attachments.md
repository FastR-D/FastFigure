# 注释引线的几何附着

第四十一批补齐库素材与描摹标注之间的连接。侧注引线可以绑定到片层等独立闭合路径的某个锚点；移动目标、修改该锚点或整体缩放时，引线端点跟随。人和助手使用同一几何绑定编译，不推断算法关系或实验含义。

## 人工操作

选中一条开放路径，在右侧路径属性中设置“起点附着”或“终点附着”。普通图元使用包围盒比例位置，可调 X/Y 百分比；独立闭合路径使用明确的几何锚点，默认选择距离当前端点最近的现有锚点，也可手动选择。界面的编号从 1 开始，工程与模型协议从 0 开始。

若现有锚点不在期望位置，可先选目标轮廓的线段，增加折点，再编辑新锚点坐标。直边上的共线点可以提供附着位置而不改变轮廓；曲线拆分保留原曲线形状。系统没有自动求轮廓交点或自动插点。

增加目标锚点时已有引用随编号调整；删除被引用锚点会解除该端绑定并保留当前像素位置，其他引用随编号前移。选择“自由端点”或解除绑定也保留当前位置。拖动引线端点会解除该端绑定。相关操作可撤销，保存恢复、组件捕获 / 重插、等比缩放和原生 SVG 元数据保留绑定；只捕获引线而未捕获目标时解除外部引用。

命名输入输出接口继续使用语义边。闭合或复合路径不能作为引线；其他开放路径不能作为几何锚点目标。数据图表生成路径不允许作附着引线，应另外绘制注释路径，避免把曲线或坐标轴端点移到装饰图元上。

## 助手契约

普通绘图和素材辅助初建均可返回顶层 `attachments`，最多 12 项，同一个路径端点只能声明一次。例如：

```json
{
  "pathId": "callout",
  "end": "start",
  "instanceId": "embeddings",
  "nodeId": "plane-0",
  "anchorIndex": 1,
  "reason": "将侧注起点附着到第一片层的已公布锚点；末段位置会调整。"
}
```

普通绘图的 `pathId` 指向本轮底图路径，`instanceId` 指向 `instances`；混合重建的 `pathId` 指向 `scene.nodes` 中的源路径 ID，`instanceId` 指向 `reuse`。编译器在展开组件和描摹节点后解析实际 ID，不要求模型猜测随机 ID。

`nodeId` 必须来自本轮选定素材的源节点别名，`anchorIndex` 必须在目录公布的 `attachmentAnchors` 中。每条独立闭合路径最多公布前 16 个端点，每个素材最多 128 个；结构目录明确报告未公布数量。坐标为相对图元包围盒的比例，曲线控制点不作为附着锚点。目录和图谱描述默认配置；允许的配方参数可能改变位置，新增而未公布的节点不能用于此次附着。

仅显式声明的开放注释引线可以在放置组件时与组件交叠，其他对象继续执行原有碰撞检查。目标、源路径、端点、编号或实例无效时整份候选拒绝，画布保持。绑定理由写入 `path.start/end.note` 并在候选审阅和属性栏展示。重建修复保留既有绑定，不让分区响应改写原生组件结构。

内部 `nodeAliases` 只导出展开前已声明的源节点 ID，避免数据图表重生成的私有随机 ID 进入公开别名和确定性结果。既有图表工具确定性检查继续通过。
