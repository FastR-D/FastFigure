# 开发与验收约定

只验收 **1920×1080 PC 浏览器**。工作区占满浏览器可用宽度，避免固定 1920px 与系统滚动条占位造成页面横向溢出；左侧栏默认 264px，可拖拽调宽，各 Tab 共用宽度。不维护手机、平板或多宽度测试矩阵。长内容在各面板内滚动，长文本省略、配色偏好与减少动画的设置继续保留。

## 运行

```bash
pnpm lint
pnpm test
pnpm build
pnpm test:ui
```

`test:ui` 只有 `tests/ui/run.mjs` 一个入口，使用临时端口、CLI 夹具、新浏览器页面和临时素材目录，不依赖用户已打开的服务，不读写用户工程或长期素材库，也不调用真实模型。Chromium 可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定。

## 检查范围

核心 / 服务检查覆盖数值和统计、几何和连接、原始数据与来源、契约注入、持久化、候选状态和 CLI 协议。图型、配方和参数的边界组合在这一层验证，UI 不再重复穷举。

UI 共用一个入口，当前五个文件、四条流程：

| 流程 | 保留的结果 |
| --- | --- |
| 编辑与导出 | 侧栏拖宽、跨 Tab 共享与恢复；Comic 真实字体加载及用户覆盖；原生文字与结构字段可编辑；真实选区快照的预览、复制、来源与撤销有效；注释实际字形边界正确，拖动时引线跟随，已有注释可显式重排；SVG 文字、字体、元数据及毫米尺寸正确；子图与共享图例新建 / 调整、源改名 / 换色明确匹配可应用；小点命中、拖动、Alt 选线与手工改色失配恢复有效 |
| 数据选图 | 长表整理预览、明确采用与配对误差；导入目标与表格，生成互补视图；原值、重复值、缺失和误差保留；候选显式应用及保存恢复；共享色标新建 / 同步后的实际颜色与文字边界；热图矩阵对齐、实际方格及共享关系保持；手工改色后恢复局部色标 |
| 助手与素材 | 组件和风格可复用；批量导入的相同原生图形可核对、并排预览并另存独立来源；draw.io 多页及压缩页拆项，失败页隔离，明确入库后保留原文件 / 页面 / 对象指纹与路径绑定；版本、归档、范围及丢回执重试有效；召回和筛选保留实际清单、原响应指纹及源快照；规划显式采用；来源变更后仍复用冻结快照，画布变化阻止旧方案；组合参数候选及报告可审核应用；整图设计审阅实际图片可回看、建议可定位并选中对象且不改图 |
| 参考图重建 | 图像输入、裁片与草稿指纹有效；素材图谱实际解码；原图回看与应用组一致；原生组和描摹分区可预览采集、明确入库，来源可追溯；曲线、AI 来源及手工注释保留，修复可撤销 |

撤销 / 重做、保存恢复和错误导入不覆盖工程，通过代表性编辑与各主流程核验，不在每个按钮之后重复整套操作。

每条流程只留一张结束截图，失败时保存失败截图。运行前清理专用的 `test-results/ui/`，避免上轮成功结果混入本轮失败结果；机器结果为 `results.json`。耗时只记录本机实测，不作为性能保证。

## 控制测试规模

- Codex / Claude 分别检查文本协议、续接、取消、图片顺序和字节传输。共享业务规则只运行一次，分配到不同适配器；素材筛选、召回、张量配方、看图找素材、冻结组件复用、数据选图、候选分支和规划采用不再重复整套 CLI 矩阵。
- 参考图重建与修复、裁片服务、独立视觉审阅和分区核对计划也各保留一个适配器的业务流程；双适配器的有序图片字节传输继续分别验证。
- 图表的数值、统计、错误列、注入数据、截断范围、非法对数值及重复透视键由核心测试验证。服务层保留数据选图的正常 / 分析 / 拒绝流程和长表明确采用的两阶段流程，不再逐图型重跑编译及重绘。复合透视和互补视图使用已有核心测试与 UI 流程；不增加对应 CLI 服务矩阵。
- 组合参数在核心测试检查无效目标、注入字段、混用响应和原子性；服务检查报告、历史及无变化不生成候选，UI 检查助手选任务与显式应用。网络间距及内部路由不再另跑一次 CLI 编译。文字检查保留一个伪造模型报告被程序重算的服务场景，清空问题的组合由核心测试负责。
- 共享图例、共享色标、绘图区对齐、引线注释及已有注释重排共用报告传输检查的准备与断言代码，各保留独立命名场景及结果断言；共享图例 / 色标在同一场景内继续验证已有关系更新和无变化报告。数据 UI 同时检查色标实际填充和 SVG 文字边界，不把程序估算当作浏览器测量。
- 共享图例源同步沿用原传输场景；核心检查显式对应、原值与绑定保护、增删及整体透明度，UI 在原编辑流程检查未完成对应不可应用和实际图示 / 字体。不要为改名、换色、每种图型另建服务矩阵或脚本。
- 四种手绘主题的确定性和数据保护由核心检查负责；浏览器保留 Comic 代表，验证真实字体、独立曲线和手工覆盖。移除逐主题截图及逐功能测量 JSON，测量断言直接在流程中执行。
- 主题各自检查默认字体、确定性渲染和手工覆盖；素材采集、缩放与 SVG 元数据往返复用通用风格场景，不随主题重复整套链路。注意力配方的网格和因果分支检查几何边界，采集 / 缩放 / 再插入只运行一个含手工调整的代表。
- 配方和路由不做笛卡尔积，保留最小 / 默认 / 最大、一个非对称布局、分支、端口和实际障碍相交；缩放保留有不同几何风险的代表。
- 网络配方边界由素材检查负责，直线与间距变化的路由由 `edgeRouting` / `networkPresentation` 检查；通用路由只保留融合分支与横 / 纵管线代表，不再重建相同的网络边界矩阵。
- 不锁定模板、图标、配色总数和提示语文案；提示中的真实数据、附件顺序、冻结来源及答案泄露检查继续保留。
- 预览不能修改输入的约束由核心检查负责。UI 不读取上次保存的 `localStorage` 来推断当前画布是否被改动；保留实际应用后的工程内容、撤销、保存恢复和浏览器渲染检查。
- 普通回归不遍历整库资源、不采样 UI 性能、不另建逐按钮脚本。可逆的小排版与文案修改复用现有流程；出现新风险或实际缺陷时才补最小必要检查。不要为了减少测试数字合并不同失败原因，也不要因新增功能机械堆积用例。
- UI 每种独立交互风险保留一个代表，不逐功能重跑完整编辑流程。组合参数在助手流程检查；数值坐标、统一范围与对齐的组合在核心检查；面板弹窗用子图 / 共享图例和数据流程的热图对齐代表，不再重跑每种图型。删除场景时同时移除专用夹具分支、开关和无用导入，避免保留失去调用方的测试代码。
- 回执丢失的 UI 检查保留批量入库重试与反馈表单冻结两个代表；元数据另存及归档检查正常操作、来源保留和列表状态，端点各自的幂等与冲突交给服务层验证。素材预览之间不反复保存并比较整份工程；在素材流程结束、候选显式应用与撤销处检查实际工程。
- 渐变的仿射颜色场、曲线极值边界与退化笔画合用现有 SVG 检查；两个新模板沿用模板转换场景。UI 只补一个停靠点 / 单色切换 / 保存代表，素材入库复用原 SVG 夹具，不增加新流程或逐渐变参数矩阵。浏览器像素对照属于显式开发证据，不加入普通测试。
- 节点连线指定折点复用 edgeRouting 与 Harness 检查，验证保留端口、给定点、受阻、组合 / 解组 / 移动 / 缩放、局部采集和 ID 重映射。编辑 UI 在原素材流程增加真实折点调整，并复用一次助手审核链路；不再另跑一次居中助手调用。
- 素材居中、格式样本、按点直角箭头共用现有几何 / Harness 检查与编辑 UI 流程；重点验证真实坐标、后代 / 绑定、渐变通道、导入文字基点及候选审核，不增加每种方向 / 颜色 / 字体的浏览器矩阵。
- 文字层级、缩放字号、空白扩框及空间不足由已有几何 / 风格 / Harness 检查负责；浏览器在同一次格式应用中核对默认保留层级、显式完全匹配、适配结果和椭圆内真实 SVG 字形边界。Canvas 测量与核心估算须区分，不另建字体或形状矩阵。
- 精确统一外框尺寸与批量连线样式复用几何 / 连线 / Harness 文件。检查不缩放字体、不截断内部内容、不解除绑定，虚实 / 箭头实际 SVG、重置、受阻警示和样式随采集 / 缩放 / 配方更新保留。编辑 UI 复用已有按点箭头与语义边，验证同一次样式应用 / 撤销；已有助手审核夹具同时验证恢复自动路线和改变样式，不增加服务或 UI 入口。
- 两端箭头与大小继续复用同一连线 / Harness 检查及编辑 UI：核对真实端点切线、重合控制点、孤立 / 闭合部分、箭头三角形的顶点与长度、共享 marker 无重复 ID、独立修改 / 重置、缩放与原生元数据恢复。桌面只在原按点箭头和混合样式流程增加起点 / 大小选择及实际 SVG 检查，不建立逐端口 / 每种箭头 / 尺寸矩阵。
- 连线规范复用已有风格文件、来源往返场景及一次冻结风格的服务链路；检查内部 / 跨组范围、未选通道、样本值不别名、图表保护、备份和方案继承。桌面在同一风格保存 / 应用 / 撤销和方案采用流程验证实际连线与冻结规则；增加底部参数编辑时预览仍处于可视区域的检查，避免只凭 DOM 存在判定可预览。共用控件的批量编辑仍由原编辑流程验证，不另建脚本。
- 不保留仅断言存在任意椭圆、所有字号大于零或默认示例固定坐标的弱检查。文字检查应验证具体文本、字号、行数或字形边界；导出检查应验证几何、绑定、转义与可恢复内容。
- 论文结构图在已有资产检查中覆盖独立几何风险和来源／参数更新往返，保留极值、非对称、包含、关系方向和闭环；后续四类增加双环共享状态、泳道任务归属及交接避开内部、集合标签独占区域和环带孔洞。UI 沿用编辑流程，以一个不对称双环代表检索分类、曲线预览、共享状态绑定、改字与撤销；不逐结构重复整套素材／助手流程，也不把示意矩阵、面积或环宽当作观测数据。

- 主图设计审阅与重建双图保真度审阅分开。沿用现有视觉审阅核心／服务文件及助手 UI 流程，检查报告只读、几何别名、图片与工程版本、实际解码和定位，不增加审美评分或每种结构的 CLI 矩阵。
- 方案到图像草稿沿用图像草稿服务文件和助手 UI 流程，核对完整方案／参数／关系编译、参考图号重映射和实际字节、输入漂移拒绝、提示容量及来源往返；桌面只补一次准备表单不调用模型／不改图、明确生成和返回助手。不增加逐方案、逐方向或逐风格矩阵，夹具成功不作为视觉质量证明。

- 默认论文角色、显式覆盖、颜色映射、富文本、出图区域、图片字节与来源共用风格文件中的四个组合风险场景；数据图表与图例继续使用已有统计与几何检查。编辑 UI 只增加一份论文场景，覆盖真实图片命中与拖动、上下标片段编辑、裁切后的 SVG、保存与刷新，不建立每种角色或插画的 UI 矩阵。真实透明插画与一次 Codex 候选属于显式开发证据。

## 手动实验与历史证据

真实模型实验只维护 `experiments/` 的四个综合入口：多参考图 / 规划、参考图重建、视觉审阅、区域修复；另有两个共享辅助文件，必须显式运行，不进入普通测试。历史逐功能脚本不再保留可执行副本；既有输入、输出、源码快照与评测记录继续保留。此次清理没有调用真实模型。

调研索引构建、离线统计预期和基准工具位于 `scripts/`。素材召回的固定相关性对照使用 `pnpm benchmark:retrieval --output <全新目录>`，范围见[样例说明](../../benchmarks/component-retrieval-v1/README.md)。开发反馈和离线响应回放不作为独立人工标签或新的真实模型验证。
