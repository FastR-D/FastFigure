# 原生图表统一字体与字号

“编辑图表数据”可以选择图表字体和基准字号，适用于折线、柱状、散点、热图与原始样本箱线图。使用已有自托管的 Inter、MiSans、思源宋体、JetBrains Mono；基准范围 8–36，默认 10。

基准字号是图表生成坐标中的大小：标题为其 1.7 倍、轴标题 1.2 倍、分类 / 图例文字 1.1 倍，刻度、数值和注释采用基准。实例缩放与整图毫米宽度共同决定最终 pt。已有论文尺寸设置时，编辑器显示该图表生成文字的最小等效字号，方便与[整图尺寸检查](publication-size.md)一起核对。

应用前只预览，更新后可撤销；配置随数据图表、组件和工程保存，继续重绘时沿用。另加的手工注释、命名接口和有效连接保留；被管理的图表文字按保存的标题 / 数据配置重新生成，独立手改的生成标签不会自动变成新的输入配置。

## 排版与数据边界

字号变化会重新计算标签宽度、刻度位置、轴标题留白、图例换行及图下注释。注释可以拆成多个可编辑文字对象，原始注释仍保存在数据配置中；续行保留各自生成标识。换行按 Unicode 字符处理，避免在括号前断开数学字母的代理对。

测量使用确定性的保守估计，不调用主机 Canvas 字体测量参与编译，浏览器与服务端使用同一几何结果。等宽字体使用等宽估计。纵轴标题使用独立左侧空间，可以超过绘图区高度，但不能碰到主标题或图下注释。

图表外框保持原大小，放大文字会相应缩小绘图区。标题、刻度、图例、组名、样本量或热图数值过密时，整次预览 / 重绘失败；不自动缩字、隐藏刻度、删注释、舍弃行列或改变观测来腾空间。不是所有图表都能容纳范围内的任意字号，需调整字号或拆分视图。原始数值、误差声明、缺失值、示例身份、箱线统计和色阶含义保持。

当前不自动解决所有标注相互遮挡，也不保证所有字体 / 字符的真实字形都被估计覆盖。字体在外部 SVG 查看器中的可用性仍需处理，未嵌入字体文件。

## 助手协议

已有图表素材的 `chartOptions` 可使用：

```json
{"fontFamily":"MiSans","fontSize":20}
```

省略字段沿用源配置；没有指定过字体 / 字号的图表使用 Inter / 10。能力清单给出字体、范围和源配置。程序从冻结资产读取原始观测，重新生成图表，再应用实例缩放；`components[].chart.typography` 报告实际采用的基准配置。

数据选图的 `ready` 推荐及每个多视图 `chart` 同样可给 `fontFamily/fontSize`。编译后，单图报告的 `typography` 或多视图每项的 `typography` 记录实际配置，不改变列映射、统计规则或来源。助手仍需结合论文尺寸判断字号，不能通过改宽度、降阈值或改观测消除提示。

最终 526 项核心 / 服务检查、Lint、类型与构建通过；仍为 40 个核心文件、5 个 UI 文件、4 条 1920×1080 流程。本机最终 UI 37.689 秒通过，不作为性能保证。

一次真实 Codex 验证使用自制的两系列、四个条件数据，包含缺失值、Mean ± SE、示例身份、独立 Owner note 和两个命名接口。CLI 0.165.0，57.149 秒，具体模型身份未报告；文本输入，没有附图。运行 `5d956073-e9d4-4e58-a760-9f5c9f950a81` 保持待审候选。

模型选择 MiSans、基准 20 和约 1.289 倍等比缩放，生成 49 个原生节点。在相同 182mm 整图宽度下，源图最小字号 5.159pt，候选最小 12.640pt（保留的手工注释），生成文字最小 13.305pt；偏小字段由 17 项变为 0。原值、误差、缺失、文字、数据声明、接口和 Owner note 的相对格式保持。这是一例能力验证，不是最优排版、真实论文质量或成功率结论。
