# 可编辑透视张量栈

第四十批增加 `recipe:tensor-stack`。上一批真实模型查看实际组件图谱后，指出普通 tensor 卡片和 volume 长方体与橙色斜向片层不匹配并弃用；本批补足这种常见科研图示的原生素材。

## 操作与表示

在“组件 → 参数化组合 → 透视张量栈”配置并预览，可插入当前容器或新建图件。默认五片透视层片，前片显示网格，标题和 `Schematic grid` 注释独立可编辑，没有外围卡片框。插入后每片、每条网格线、标题与注释均为独立原生图元，可移动、改字、调格式、缩放、撤销和保存组件。

| 参数 | 范围 / 选项 | 含义 |
| --- | --- | --- |
| `layers` | 1–8，默认 5 | 示意片层数 |
| `rows` / `columns` | 各 2–8，默认 4 / 5 | 前片示意网格 |
| `spacing` | compact / normal / loose | 片层间隔 |
| `tilt` | flat / mild / steep | 平面、轻微或明显倾斜 |
| `note` | show / hide | 显示或隐藏示意说明 |

这些计数控制视觉布局，不是实验观测或张量维度；不从图片网格推断真实数据。该配方由程序独立构造，来源记录写明示意含义，没有把它登记成论文原图或某次 AI 输出的精确矢量化。

命名接口为 `features-in` / `features-out`，方向固定为输入 / 输出，并带短接入线。它们是图件组合接口，不代表已证明的内部计算过程。片层和网格使用语义配色，默认为 Publication Soft 的橙色色槽；改画盘或按实例映射会同步填充与描边，手工固定 RGB 保持。

## 人和助手共用

该配方进入同一组件检索、实际预览图谱、结构目录、方案规划与实例编译。参数只接受清单中允许的键与选项；`labels['tensor-label']` 可改主标题，显示注释时可通过 `labels['schematic-note']` 编辑。显式空字符串可清空已有原生标签，保留图元与留白，以便另绘源图文字；清空操作仍须披露。清单明确说明片层和网格是示意几何。

助手引用 `recipe:tensor-stack` 时由程序生成完整独立图元，支持按比例放置和命名接口连接。保存为“我的组件”后，按实际图元快照复用，不因配方参数记录而重新生成或覆盖手工编辑。混合重建仍须明确开启，模型可以因结构、含义或外观不符而不使用。

SVG 保留独立路径、文字及 FigureIR 元数据。draw.io 沿用独立 SVG 矢量对象表达曲线与自由路径，尚未验证外部编辑往返；PPTX 继续暂缓。

## 颜色解析与验证

自由路径可显式用 `visual.tone` 选择语义填色，普通路径仍默认不填充，显式 `fill` 优先。画布 / SVG、draw.io 矢量对象和重建只读目录共用同一解析；固定描边与语义填色并存时，色槽清单仍保留填色引用。

现有核心文件增加两项场景，覆盖极值 / 平面布局、曲线控制点边界、示意来源、手工快照与缩放、命名接口组合，以及颜色映射 / 固定 RGB / 默认空填充。现有服务文件增加一项双 CLI 配方参数与接口协议检查。实测后再补一项显式清空原生标签的回归，源别名仍须存在，纯描摹空文字仍拒绝，数据图表的生成标签保护保持。累计 517 项核心 / 服务检查、Lint、类型和构建通过。

现有编辑流程加入参数配置、改标题、撤销重做与保存恢复；重建流程使用新配方进行实际图谱和只读分区修复，最终四条 1920×1080 流程通过，19.555 秒。仍为五个 UI 文件，没有新增逐控件脚本或宽度矩阵。已查看工作台与六格图谱；两个实例的接口连接另做程序核对，路线为 clear。

## 真实选择与原输出离线编译

保留上一批相同源裁片字节、区域、用户要求及前五项清单，将第六项融合配方换为新张量栈，重新渲染实际六格图谱。真实 Codex CLI 0.165.0 仅调用一次，运行 `fc063158-5ccc-486d-a8d9-36b0b2cbfe73`，167.405 秒；模型选择 `recipe:tensor-stack`，理由是实际可见的橙色平行四边形片层与前片网格最接近源图。

原运行因两处空标签失败：模型明确要求清空组件标题与底注，再独立重建源图大标题和右上侧注，原组件覆写契约却只接受非空标签。程序没有应用候选，原始失败、响应与源码快照均保留。

修正为允许已知原生节点的显式空字符串后，不改原响应、不追加模型调用，离线重放编译通过：18 个原生组件图元（五片层、前片网格、两条接口短线、两个空标签和两个命名接口），加 4 个原图标注，共 22 个图元、16 条路径。两个空标签保留几何和留白，源素材与完整图谱指纹不变，原生几何按 1.2276151840 等比展开，原始生成规格及 AI 图片证据保持，捕获组件可保存。

已查看离线结果。颜色更浅、片层宽高比例、接口短线与原图存在差异，侧注引线与片层边缘仍有间隙；这些保留在审阅说明中。两处定位文字未进入原生换行检查，零项报告不代表文字适配通过。原图是 AI 视觉草稿，网格不证明张量维度或实验结果。

真实运行仍为失败，离线编译不是修正后的真实重跑。该单例只记录素材选择和编译链路，不证明普遍视觉质量优势、科学正确性或 RSI 效果。运行、输入 / 图谱、原始响应和第一次源码保存在 `test-results/tensor-stack-library-live-codex-v1/`；原输出离线候选 / SVG / PNG / 捕获组件 / 新源码及核对记录在其 `offline-replay-v1/`，均未自动应用到用户画布或晋升入库。
