# 重建评测与实际输入审阅

2026-10-29。本批建立自制 CS 图件的独立参考与分项评测，改进实际输入回看、流式事件和运行预算。没有引入自动质量接受、自动应用或 RSI。

## 独立参考与控制

`benchmarks/cs-figures-v1/` 包含六类图：编码器残差、多头注意力、检索融合、训练 / 推理、消融误差线、密集多面板，共 219 个标注对象，其中 83 个文字对象。两例用于开发，四例单独评估；它们是可见的自制小样本，不能称为真实论文大样本或隐藏训练留出集。

源图由独立 SVG 绘图程序生成，不导入 FigureIR、重建编译器或应用预设。浏览器测量文字与几何边界、65 点轮廓 / 线条采样和箭头方向，生成固定 2000×1200 PNG；标注使用 1000×600 坐标。源 SVG、PNG、字体、清单和评分器的指纹都可核查。重建时仅发送栅格图片和普通要求，不发送 SVG、对象目录答案、标注数量或正确坐标。

离线控制通过源 SVG 几何生成正确的 Scene，并分别移除文字、线条、箭头。六例正确控制的文字 / 形状 / 线条召回均为 100%，有箭头的五例箭头召回均为 100%；移除文字时精确召回为 0、字符错误率为 1，移除线条时线条召回为 0，移除箭头时有箭头的例子对应召回为 0。控制验证评分器能发现既定缺陷，不能作为模型质量证据。

命令、数据字段、初始阈值及限制见 [评测集说明](../../benchmarks/cs-figures-v1/README.md)。输出在忽略提交的 `test-results/benchmark-controls/`。

## 分项指标与表示差异

文字按位置约束和一对一分配检查，使用 Unicode 码点计算错误率，同时列出错字、缺字与新增文字。形状按包围盒和双向轮廓覆盖匹配，避免用同尺寸矩形冒充椭圆。线条检查采样覆盖和反向精度，允许拆段，排除移动子路径间的虚假连接；箭头独立核对尖端及方向。绘制圆角矩形时按真实圆角轮廓取样。RGB 色差只统计已匹配对象。

严格一对一对象计分可能受合法的矢量分解影响：同一个圆柱可由完整路径表示，也可拆为主体和椭圆。评分器保留严格召回及 unmatched，同时计算跨所有非文字图元的合并轮廓覆盖。边界已覆盖的对象归入 `encodingDifferences`，未覆盖的才列入 `missing`；合并覆盖的反向精度仍会惩罚多余内部线。参数集中定义并随报告保存，不自动调整来让模型结果通过。

这些是初始诊断指标，未在真实论文样本上校准。它们不证明图语义、逻辑连接、统计结论、字体、基线、线宽、遮挡或填充区域正确；文字位置有适度偏移仍可能算识别正确。原图、可编辑结果与差异图仍需人工核对。

## 真实调用与失败保留

选择四个 evaluation 例子中的 `retrieval-fusion`，使用真实 Codex CLI 0.165.0，仅提供固定栅格图。没有追加真实 Claude 调用，也没有宣称六例模型评测完成。

- 默认 180 秒调用超时，保留完整失败记录、6,706 个已收到字符及部分 JSON，不补齐 JSON、不产生候选图。记录在 `benchmark-codex-retrieval-v1/`。
- 使用明确的 360 秒预算复测同一图片，226.842 秒完成，返回 30 个原生对象。该次不是与前一次严格受控的性能 A/B，因为模型输出具有随机性。
- 15 / 15 文字精确识别，字符错误率 0；严格形状匹配 8 / 9、严格线条匹配 5 / 6、箭头 5 / 5。目视对照发现差异集中在圆柱主体与圆柱帽的分解；统一轮廓诊断中，15 个非文字目标全部达到覆盖阈值，平均覆盖 1、反向精度约 0.9764，没有未覆盖轮廓。严格计分仍保留，未改成“完美重建”。
- 与固定 PNG 的离线栅格对照中，2,400,000 像素里 41,467 个存在大于 16 的通道差；平均通道差约 1.927、前景交并比约 0.9738。字体和文字基点等仍有可见差异，这些全局数字不能代替小字与连线检查。

原始调用在 `test-results/benchmark-codex-retrieval-budget360/`；最终离线复算在 `benchmark-codex-retrieval-final/`，包含新的评分器快照与指纹。原始模型输出保留，后续复算不再调用模型。一次回归发现本地轮廓阈值回退，已恢复为预先使用的 0.8，集中参数来源，并以同一保存输出重算；严格计分结果不变。新增合并轮廓诊断用于解释分解差异，而非删除较低的原始分项。

新的真实评测脚本会保存实际编码输入及其指纹、评分器 / Harness 源码快照，并检查加载期间评分器是否变化。离线复算没有新的推理预算，调用预算与 CLI 版本应查看原始采集报告。较早调用没有保存编码图片文件时，不补写伪造的“实际输入字节”证据。

## 工作台改进

候选审阅直接读取本轮实际输入裁片，刷新后也可查看。图片失效、损坏或尺寸不符时明确回退工程参考图，可重试；切换历史结果时释放对象 URL。裁片随 20 轮重型快照清理，JSON 历史只保留元数据。

CLI 单字符流会在 128 字符或 100 毫秒时合并为 SSE 事件；保留文本内容、顺序、取消前已收到的尾部和单一终态。该次成功样本的 7,138 字符归并为 130 个文本事件。固定文本及取消单元检查证明合并不会丢字，也不会在终态后继续发送。

助手设置加入每轮 1 / 3 / 6 / 10 分钟时限，默认仍为 3 分钟；选择保存到本地，消息记录实际预算，修改设置不改写既有轮次。API 校验 30–600 秒，后端按本轮预算停止，运行中仍可主动取消。较长预算是明确选项，不是自动延时或自动重试。

本批累计 251 项单元 / 集成检查；类型、Lint、生产构建和完整 PC 浏览器回归通过。浏览器覆盖运行预算选择与恢复、实际图片回看、刷新、裁片失效 / 损坏回退与重试，并回归重建、分区修复、入库与缩放。下一步在更多独立样本及真实论文图上评估指标，再建立明确次数 / 时间预算、候选回滚和停止条件的修复循环。
