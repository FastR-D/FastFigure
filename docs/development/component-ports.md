# 组件的命名输入输出接口

PC 属性面板现在可以给自由图元组合添加输入、输出和双向接口。它们把复用时的连接位置与内部形状、注释和装饰区分开，适合 SVG 导入和结构预设展开后的素材。接口处于组合边界；当前不会自动推断内部图元的计算语义，也不把接口自动连到某个内部算子。

## 操作

1. 选中自由图元组合，在“组件接口”添加输入或输出。
2. 修改名称、唯一标识、方向、所在边界和沿边位置。左 / 右边的位置从上到下，顶 / 底边从左到右，范围 0–100%。接口列表和画布圆点都能选择接口。
3. 拖动圆点沿当前边界调整位置；方向键每次 1%，Shift 每次 10%。Escape 取消拖动，一次拖动只产生一次撤销记录。
4. 使用连接工具，先点输出 / 双向接口，再点输入 / 双向接口或普通节点。属性中的“从此接口连接”也能选定起点。一个组件有多个候选接口时，需要点击具体接口；只有一个匹配接口时，点击组合边界也可连接。
5. 选回所属组件并存入“我的组件”。组件详情列出接口名称和标识，助手清单使用同一记录；插入多个副本后各自的接口和连接独立。

输入只能作为连线终点，输出只能作为起点，双向允许两者。改变接口边界会同步更新现有连线的朝向；改变方向与已有连接冲突时整次编辑不应用。位置随组合移动 / 尺寸调整，不会因为自动布局调整普通节点端口而被覆盖。

选择组合或接口时显示编辑圆点和标签；连接模式显示可连接的命名接口。标签超过 18 字时缩略，完整信息在提示中。编辑标记不进入论文 SVG 外观；它们的语义元数据和实际连线仍保留。接口不显示在普通图层树，也不会被框选、全选或内部自动排布当成独立图形移动。

移除接口会一并移除其关联连线，面板显示数量；可撤销。连接起点被删除或改为输入时，程序清理待完成连接，避免悬空起点。解组一个仍在使用命名接口的组件会提示先改接连线，或移除接口及其连接；未使用的接口在解组时移除。结构展开时保留的原始整组接口继续遵循已有解组行为。

## 模型与校验

命名接口使用现有的隐藏 `kind=port` 节点，`interfaceFor` 与 `parentId` 均指向自由组合。`label` 为 1–40 字名称，新增字段：

```ts
socket: {
  key: string; // 1–32 字符，以英文字母开头，其后为字母、数字、_ 或 -；组件内唯一
  direction: 'input' | 'output' | 'both';
  side: 'left' | 'right' | 'top' | 'bottom';
  position: number; // 0..1
}
```

每个组件最多 16 个命名接口，计入工程 240 个图元上限。接口几何由组合边界维护；相对位置决定实际 anchor。普通语义 `edges` 引用接口节点 ID；对应 sourcePort / targetPort 必须与固定边界一致。命名接口目前只用于语义连接，原生 `path.start/end` 继续绑定普通内部图元，不绑定命名接口。

避障计算将接口代表的组件视为整体，不把其隐藏代理和内部装饰重复当作障碍。两个接口属于同一组件时，反馈回路在外层容器中绕行；若空间不足，沿用受阻连线提示。其他组件仍作为障碍，不允许直接穿越它们的图元。

组件捕获、源 SVG 元数据恢复、工程保存和实例展开均保留 socket；程序为每个副本重映射接口节点 ID 和 owner，稳定 key 不变。候选差异新增“命名接口”字段，模型省略同 ID port 的 socket 时保留原值。

## Harness 清单与组合

`catalogue.ports` 列出根组件公开的 `{nodeId,name,key,direction,side,position}`；`inputs` / `outputs` 仅列相应方向的节点 ID。双向接口同时出现在两者中。没有命名接口的旧式结构保留原整组接口；普通流程配方保留基于入边 / 出边的接口。没有标记接口的自由图元素材不再把无边的矩形、文字等装饰全部猜成输入输出。嵌套子组件的接口不会自动成为最外层的公开接口。

模型优先通过稳定标识连接：

```json
{
  "id": "encoder-to-decoder",
  "source": {"scope":"port","instanceId":"encoder","port":"output","key":"features"},
  "target": {"scope":"port","instanceId":"decoder","port":"input","key":"context"},
  "sourcePort": "right",
  "targetPort": "left"
}
```

程序按选定素材快照查找并重映射接口；命名端点的固定边界由程序填写，sourcePort / targetPort 只控制普通节点。方向、标识不存在、容量、布局等错误仍使整轮候选原子失败。`index` 继续适用于未命名的流程配方，也可按清单顺序访问现有接口；新模板优先使用 key，以免节点数组次序改变影响连接。

SVG 用工程元数据保存接口，画面仅绘制连线。本批没有新增真实模型调用。

## 验证

本批新增 18 项单元 / 集成检查，累计 168 项。覆盖接口容量与几何、方向与固定边界约束、移动 / 缩放 / 布局、重复障碍与反馈回路、入库和两个实例隔离、稳定 key 编译、字段保留、SVG 数据、删除 / 解组、原子失败和撤销，以及待连接起点的失效清理。

PC 浏览器检查真实面板新增与改名、固定边界、圆点键盘 / 拖动 / 取消、方向冲突、连线、移除与撤销、来源素材捕获、刷新恢复、导出坐标，以及 1280 / 1440 / 1920 视口，并回归原有编辑、素材、参考图和 Harness 测试流程。产物在忽略提交的 `test-results/component-port*` 与 `test-results/component-interfaces.*`。
