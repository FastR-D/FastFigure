# 已有图表统一纵轴范围

中心画板“多子图编排 → 统一纵轴”可选择 2–8 张已有原生图表，在应用前预览并报告原范围、目标范围和修订。已包入子图面板的图表也可选择。范围取当前有效范围的并集，包括误差棒、离群点和显式留白，柱状图保留零点，不截断原数据或猜测单位。只有相同且非空的纵轴标题 / 单位和相同线性 / log10 刻度才可合并；作者仍须判断科学含义是否可比。

操作只同步本次范围，不建立动态绑定，不等同于绘图区像素对齐、合并图例或删去重复刻度；可另用[绘图区对齐](plot-alignment.md)和[共享图例](shared-legend.md)。热图使用独立色标；有其他受管理结构或可见纵轴标题与数据配置不符的对象会拒绝。输入错误、文字放不下或手工表示无法对应时整次不应用。

程序从源数据配置重建位置，保留生成标识、接口、外部连线、手工颜色 / 线型 / 字体 / 标题、来源与另加对象。未改变内容的定位文字沿原测量框平移，不按保守字高重新估算；新数值标签在保留手工格式时重新测量并检查边界。重复相同显式范围为无改动。人工应用进入一次撤销；助手响应使用 `sharedYAxes=[{containerIds,reason}]`，由程序生成候选和实际报告，待人审阅应用。多视图选型也可请求一次统一范围。

## 开发验证与失败记录

原生 Codex 运行 `26c8a78b-ea1c-44b4-98dc-f876c5d28951` 实际返回一组 Accuracy 图表请求，目标 0–100；服务编译失败，原画布未改变。问题为手工 12px 标题被重新估算字高，误判越过容器顶边。修正为保留原文字框，并修复重绘意外引入外框默认外观字段的问题。

随后离线复用该轮原响应，零追加模型调用。离线运行 `564c4446-1712-4c6a-a380-3e94b762e498` 编译为 120 图元（源 117），新建三个刻度相关图元。实际浏览器候选审阅、应用 / 撤销 / 重做、保存恢复及重复人工操作无改动通过。源数据、误差、缺失项、未选 Latency 控制图、手工样式、附加注释、两接口及连接逐项核对；源码在验证期间冻结，提示与原轮一致。

原生失败证据保存在 `test-results/shared-yaxis-live-codex-v1/`，修正后的原响应浏览器复核在 `test-results/shared-yaxis-replay-v3/`。这证明受控协议与确定性编译流程；原生端到端首次运行仍是失败，不将离线执行时间记作模型耗时，也不代表通用论文质量验证。

核心检查位于原 `chartAxes.test.ts`、选型测试及服务测试，人工操作复用原编辑 UI 流程；未新增维护脚本。图表字体和物理尺寸另见 [图表字体](chart-typography.md)、[论文尺寸](publication-size.md)。
