# 科研图的默认表达与风格约束

2026-11-07。将[图库阅读与训练部署图修订](../research/2026-11-07-gallery-study.md)中发现的模板化问题落实到实际生成入口，避免修改一张示例后，默认绘图仍继续产生通用标签、同款圆角框、重复标题和机械对称。

## 默认规则

统一定义位于 `src/core/figureDesignPolicy.ts`。它是生成与审阅的上下文，不是根据外观判断图片是否由 AI 生成的分类器，也不构成自动审美验收。

| 方面 | 默认行为 |
| --- | --- |
| 内容依据 | 先提取材料中的机制、输入输出、具体操作与关系。已知内容使用具体名词和变量；信息不足且会改变机制时提出必要问题。布局骨架可以留占位，说明待填内容。 |
| 对象角色 | 按样本、序列、张量、模型、算子、存储和证据选择表示。同类一致，不强制形状种类、细节数量或图标。 |
| 阅读与对齐 | 用共同的阅读轴、行列基准与明确间距排版。可比较对象对齐；分区面积服从主次。独立分区标题和解释默认左对齐，模块短标签和公式可居中。 |
| 边界 | 默认开放图版。外框承担真实边界、分组或状态含义；减少整图装饰框、重复套框与重复标题。 |
| 文字 | 统一图内标注语言，保留用户原文、专名与数学符号；准确使用上下标，线路避开文字。来源与使用说明置于图注或元数据；必要图例、尺度和定义保留。 |
| 关系 | 区分数据流、条件、梯度、参数复制、状态读写与局部对应。训练/推理按已知规格说明更新对象、迁移对象与保留内容；不补画未知损失、梯度或冻结状态。 |
| 克制 | 颜色对应身份与功能。没有真实数据就不加示例曲线、权重、统计显著性或比例尺；不能为消除模板感增加未经声明的模块、反馈或伪细节。 |
| 范围 | 用户的内容、显式风格和任务范围优先。局部改字、换色、对齐和参数更新只做所要求的修改；忠实重建仍保留源图组织。 |

删除了旧 prompt 的“默认布局必须对齐、居中”“分区内容包围框与分区内容区同心”“分支按公共中轴对称安排”等普遍性要求。几何对齐仍要精确，但对齐方式依内容选择；没有将随机偏移、故意不齐或增加装饰当作改进。

例如用户已提供监督学习的样本、模型、标签和优化关系时，可用样本片层、预测向量、模型与损失算子区分角色，用更新回路和参数复制线解释训练/推理差别。用户只给出“训练部署”主题时，不能为了把图画得更丰富便推定某个损失、优化器或迁移算法。

## 实际接入点

- `src/data/scientificPresentation.ts` 的 `scientificFigureDesign` 合并共享规则。普通绘图的 `materials.figureDesign` 和方案规划 prompt 均携带它。
- `src/core/harness.ts` 的原生绘图 prompt 使用新的对齐说明，独立标题/说明明确设置 `textStyle.align=left`；对已有手工排版保持原有任务范围。
- `src/core/compositionPlan.ts` 要求 `visual` / `rationale` 写明具体内容、阅读轴、对象轮廓和无框区域；`style.usage` 说明颜色/线型，`checks` 覆盖本图实际风险。
- `src/core/paperStyle.ts` 的论文主题说明采用共享对齐与风格规则。内置论文主题自动携带新说明；主题字体、色板、尺寸和渲染参数保持可配置。
- `src/core/styleAsset.ts` 新采集风格的 `guide` 使用具体默认说明。用户已有风格快照和自定义说明保持原值，生成时仍收到公共表达约束；无需迁移或覆盖历史素材。
- `server/imageDrafts/prompt.ts` 的整图草稿使用同一组规则；独立透明插画保持单主体、无标签和无箭头，不套用整图分区要求。
- `src/core/designReview.ts` 要求审阅者报告可见位置、阅读影响和具体建议，检查占位、同款框、重复层次、关系歧义与文字问题；不以“像 AI”猜生成来源，不自行补全科学机制。

手动点击应用风格仍沿用既有行为：更改所选字体、轮廓、配色和连线规范，并保留几何与内容。它不会自动把旧图重排或删框；结构重设计需通过相应绘图任务提出。

## 验证与边界

`src/core/figureDesignPolicy.test.ts` 从真实入口构造普通绘图、指定风格绘图、规划、整图草稿、局部插画和设计审阅请求，核对公共规则进入实际 prompt、旧强制居中语句消失、风格快照与原工程没有被改写；内置论文主题仍通过原 schema。现有风格、规划、原生编辑和图像草稿测试继续覆盖兼容性与提交容量。

```sh
pnpm test
pnpm lint
pnpm build
```

这些检查验证约束接入和功能回归，不能证明每次模型输出都符合视觉目标。实际成图仍需查看生产渲染，在目标尺寸下核对阅读路径、字号、路径与关系；独立设计审阅保留人工判断，不自动接受候选。
