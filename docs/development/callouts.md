# 无边框引线注释与自动选位

中心画板工具栏“添加引线注释”提供选对象、填原文、预览和应用。文字使用无边框原生文本，引线两端分别绑定源图元与注释，原有图形、数据、文字、来源及图层顺序保持。适合给编码器、输入输出或具体片层补充短说明，减少把解释堆进框内的情况。

## 人工使用

选中普通图元后打开工具，填写最多 160 字的原文（可换行），设置字体、8–32 字号、40–300 最大宽度及放置侧向。默认自动搜索四侧；指定某侧时只在该侧搜索。当前放置容器默认是目标父容器，空间不足时可选更外层。左侧提供原图 / 注释预览；应用为一次可撤销操作。

程序按渲染器相同的换行估算计算完整文字区域，不改写原文、不缩字，也不移动源对象。普通图元附着到侧边，独立闭合路径选择已有的实际锚点。组合容器请先选择内部图元，命名接口继续使用语义连接；任意开放路径不作为几何附着目标。

生成后可独立改文字、字体和折点。移动目标或文字会更新引线相应端点，其他折点保持；不是持续自动路由。移动后应检查引线是否又穿过对象。删除其中一个对象按现有编辑规则处理，不提供整组自动清理。普通图元和绑定继续通过工程、原生 SVG 元数据、组件采集 / 缩放和 ID 映射保存。

## 调整已有注释

在同一工具中切换“调整已有注释”，选择最多八条已有的双端附着文字 / 引线：

- **仅重排引线**：文字位置和框尺寸完全保持，重新寻找避开对象与连线的路线。
- **文字与引线一起调整**：可指定自动 / 四侧，保持原文、字体、字号、手工样式、框尺寸、层级和 ID，仅修改文字位置与路径几何。

附着点策略默认为“保留原附着点”：完整保留闭合路径锚点编号、比例坐标、偏移与作者说明，即使换侧也不换点。需要减少绕行时可明确选择“重新选择附着点”：在同一普通对象的侧边，或同一闭合路径的已有几何锚点之间搜索，注释端也可换侧；仍保留对象身份、原偏移和绑定说明，不重建源对象或在路径上发明新点。具体指向会改变，应在预览中核对。引线原有朝向、箭头、颜色、线宽和虚线保持。

工具通过明确的路径端点识别注释，不按名称猜测。两端都是文字时会列出两个方向，需选择实际要移动的那一端；同条引线或同段文字不能在一轮中重复出现。配方、数据图表、共享图例或色标管理的标签不可调整；隐藏对象或有其他外部引用的注释也会拒绝。批量条目互为目标时需拆开调整。

预览不修改当前工程，应用为一个撤销步骤；任一条无可用位置时整批拒绝，没有变化时只给出报告并禁用应用。它仍是按需重排，不会在每次拖动后持续自动计算。

## 选位与边界

- 在父容器内容区内，以三个距离、三个偏移和四个方向生成候选；按离目标的距离尝试。文字使用保守对象边界避让，连接复用既有路由器。重选模式比较路线长度与转折代价，代价相同优先保留原附着点和文字位置；闭合路径保留原锚点并尝试距注释最近的八个实际锚点，单条最多尝试 96 次路由，不保证全局最优。
- 路径搜索把已有语义连线与原生笔画加入障碍，随后再次检查文字覆盖和引线交叉；开放原生路径用线段检查，二次 / 三次曲线分 24 段近似。数据网格可被引线穿过，数据 / 坐标与其他实际笔画继续参与检查。
- 隐藏对象、共享图例 / 色标暂隐的原图元不会成为可用目标或文字障碍；共享关系停用后，依据实际渲染状态重新核对。不可用目标在上下文带原因，界面不提供这些目标。
- 这是估算几何，不是像素遮挡、真实字体轮廓或科学正确性证明。复杂曲线、空心图形、实际字形和手绘线条可能与边界估算有差别，需查看预览。
- 没有找到位置、路线受阻、容器过小、内容超限或图元超过 240 时整次拒绝。每轮最多八项，不删除不易放置的注释，不为容纳说明修改实验数据。不能保证找到所有存在的排布或最优排布。

## 助手

普通绘图上下文增加 calloutTargets，包含可附着图元的位置、可用外层与闭合路径锚点。已有图件可单独提交：

```json
{"message":"补充编码器说明","figure":null,"callouts":[{"targetId":"encoder","parentId":"stage","text":"Frozen encoder\nParameters stay fixed","fontFamily":"MiSans","fontSize":12,"maxWidth":180,"side":"auto","reason":"补充作者给出的参数状态说明"}]}
```

不能与配方更新、共享轴 / 图例 / 色标 / 绘图区维护混用。实际新对象和报告由程序产生，进入事件、历史及候选审阅，候选不自动应用。说明文字由作者或模型提供，程序不推断科研结论。

新绘图时，也可随完整底图与 instances 提交 callouts。自绘对象使用 targetId；复用素材的内部对象使用本轮实例与源图元别名，例如：

```json
{"instanceId":"encoder-pipe","nodeId":"step-0","parentId":"stage","text":"Frozen weights\nEncoder stays fixed","fontFamily":"MiSans","fontSize":12,"maxWidth":180,"side":"auto","reason":"关联作者提供的说明"}
```

实例 ID 与 nodeId 必须来自本轮实例和冻结素材目录，不能猜测插入后的 ID。程序先组合所有素材并完成原有路径附着，再按真实位置放置注释。原组件内部内容保持；任何一项无法布置时拒绝整个候选。

已有注释上下文为 `existingCallouts`，包含实际 leaderId / labelId、原文、位置、路径、双端绑定、目标类型、选中状态和不可用原因。助手仅选择操作，不返回新位置或自报验证结果：

```json
{"message":"为原注释避让","figure":null,"calloutReflows":[{"leaderId":"leader-original","labelId":"note-original","mode":"layout","side":"bottom","anchorPolicy":"preserve","reason":"为上方流程留出空间"}]}
```

`anchorPolicy` 默认为 preserve；只有作者允许换点或明确要求减少绕行时才选 reselect。`route` 模式的 side 必须是 auto，文字位置保持，仍可明确允许换点；调整请求不能与新建注释、新底图、实例、图表维护、配方更新或已采用方案混用。程序返回实际 `calloutReflows` 报告，贯通事件、历史和待审候选；全为无变化时返回报告，不生成候选。字段不接受模型指定 before / after、绑定、长度或保留性声明。实际报告给出 anchorPolicy、bindingsChanged、beforeBindings / afterBindings、beforeLength / afterLength 和 targetPreserved；长度采用与避障相同的折线 / 24 段曲线估算。界面显示长度变化比例和两端的实际换点方向。
