# 相同原生图形候选核对

批量导入组件 JSON / SVG 时，在准备原生预览后核对当前本机库。发现其他快照具有相同的规范图元内容时，默认取消本项勾选；可选择已有候选并排查看原生预览与来源，再明确“保留为独立快照”。新的来源、检索信息和快照身份各自保存，原快照保持。

同一份完整快照仍由原 SHA-256 去重与回执重试处理。新检查只负责提示图形候选，不把不同来源替换成旧回执，也不归档或合并已有快照。已归档的相同图形同样可供核对，查看和重复入库不会自动恢复它。

## 比较范围

算法为 `native-content-v2`，与完整快照的 `componentSnapshotJson` / SHA-256 分开：

- 内部 ID 按原数组顺序归一，同时映射父级、指定连线折点的坐标容器、语义边端点、组件接口、开放路径绑定、配方对象表、共享图例和色标引用。保留图元与同层绘制顺序、分组、连接拓扑、端口及路径锚点。
- 保留可见文字、说明、标题、曲线与控制点、尺寸、矩阵、字体、配色、透明度、线型及原生数据。数据图表保留整个 spec，包括原值、缺失、误差、统计口径和数据声明；不按渲染后的小数标签判重。
- 保留实际配方与对象对应关系；配方 / 数据重绘的修订计数和时间不参与。来源、祖先、重建过程记录、检索名称 / 标签、选择用名称及路径绑定说明各自留在完整快照中，不参与这个图形指纹。
- 根文档标题不作为组件内部图形；component 容器不绘制的标题不参与，实际绘制的容器标题保留。非手绘样式不比较无效的随机种子；手绘种子和样式保持，内部 ID 改变仍可能使随机笔画细节不同。
- 直接位置 x / y 和指定折点的局部位置按 1e-7 坐标单位消除重新放置 / 采集带来的浮点噪声，原始科学数值不舍入。尺寸、缩放、旋转和原始路径控制数值不做相似度归一。

根样式显式默认色槽 0、空颜色映射与省略默认值等价；重插产生的这些默认字段不再造成同图核对失配。版本升级只重建派生内容索引，不改不可变快照。

这是原生内容核对，不是图同构、像素相似度或科学语义判断。绘制顺序不同、不同原生表示、不同尺度或未支持的源 SVG 效果可能无法匹配。SVG 比较的是解析后的原生图形，解析提示继续保留，仍需查看来源与预览。

## 索引与接口

`POST /api/component-library/content-matches` 接收 `{asset}`，与素材写入接口使用相同本机同源限制和请求大小限制。返回当前 assetSha256、contentSha256、checkedAt、候选总数、最多六份记录和索引进度。浏览器同时核对两个指纹；查看候选时再次读取完整快照并验证内容指纹，异步切换详情不会显示旧项结果。

SQLite 的 `snapshot_content` 是派生索引，原始 snapshots 的内容、ID、保存时间、来源与归档状态不改。新快照与索引同事务写入；旧库按每次最多 16 项补索引，界面可显示进度、暂停与重新核对。算法变化须升级算法标识，旧索引会重新建立。

候选展示前会重新验证源快照及规范内容，错误的派生索引可纠正；不可读快照留作未覆盖项，可重试。未完成或存在不可读项时不会把空结果当作全库无重复，也不自动选入“无提示项”。单次候选校验最多读 12 项，返回最多六项，库级数量来自当前内容索引。

关闭窗口保留队列。编辑检索信息后重新绑定核对结果；恢复原信息后需重新核对。发现本批其他文件的相同图形也默认不勾选，可明确保留。移出条目会重新计算批内对应。入库记录只附核对指纹、进度与候选名称 / ID，不嵌入候选缩略图。

## 验证（第七十批）

557 项核心 / 服务检查、40 个文件，Lint、类型 / 构建以及四条 1920×1080 流程通过；普通 UI 仍为五个文件、一个入口，四流程本机用时 43.15 秒。只在原 assets 与素材服务文件各增加一个有独立风险的场景，不新增逐功能脚本。

核心核对重新采集后 ID / 位置 / 元信息变化仍可匹配，同时区分文字、端口、字体、绘制顺序及 1e-9 的原始数值差异。服务覆盖归档候选、明确另存后的独立来源、重开库、16 项分批补索引、不可读项重试与错误索引核验。

既有助手 / 素材 UI 流程实际导入另一份改内部 ID 的 SVG，找到原 SVG 和信息派生快照两项候选，默认不勾选；并排预览后明确另存，读取结果与本次冻结 payload 完全一致，原来源不变。后续归档测试用的独立项，避免干扰原素材召回流程。

另一次独立临时库操作使用两份带 Encoder 内部结构的 SVG，只改变源 group ID 与文件名。两个原生预览实际显示；源文件与快照指纹不同，核对得到一项相同图形，明确保留后库中为两份快照，原来源、本次来源和画布均保持。页面零异常，冻结 16 个相关实现文件，没有调用模型。证据在 test-results/component-content-review-v1/：first.svg、second.svg、原始 / 独立素材与回执、content-matches.json、verification.json、comparison.png 和源码指纹。
