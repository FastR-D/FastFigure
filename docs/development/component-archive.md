# 素材快照归档与恢复

第五十批增加本机素材库的手工归档。它用于整理不再默认使用的旧版本，保留图形、来源与快照指纹。

## 操作

在“组件 → 本机素材库”选择“当前素材 / 已归档 / 全部版本”，再按名称、标签、引用或指纹检索。默认显示当前素材；范围和检索词在切换侧栏时保持。

打开快照详情，点击“归档快照”或“恢复快照”。归档后，卡片和详情标题显示状态，详情记录归档时间；可从“已归档”范围找回，也可从派生来源或历史助手记录按 SHA 打开。操作不改画布、插入比例或原保存时间。

归档不参与本机库的新任务自动召回，过滤发生在粗排和 24 项候选预算之前；普通关键词召回与助手逐项筛选共用该规则。已经冻结的绘图 / 规划清单保持，不重新筛选。已有图件和浏览器工作副本独立保留，不因库内归档被移除；用户仍可明确取用归档快照，或先恢复后交给本机库自动召回。

“导出原快照”始终使用未缩放的原组件。插入比例无效时，详情继续显示原尺寸预览、来源和接口，并允许导出原快照；需要有效缩放配置的插入 / 保存操作禁用，不用原尺寸悄悄替换用户选择。

## 状态与身份

归档状态保存在独立的 `snapshot_archives` 表，不写入组件 JSON、来源链或规范 SHA。原 `snapshots` 行的正文、元数据、检索文本、保存时间和字节数都保持。

状态请求明确提交 `{archived:true}` 或 `{archived:false}`，不是翻转开关。同一状态重复请求返回当前结果，重复归档保留第一次归档时间；恢复后再次归档会生成新的归档时间。这是当前状态，不是完整操作历史。

写入使用立即事务并先核对原正文指纹。不存在、损坏或参数错误的快照不会产生归档记录。原快照被归档后再次重复入库仍返回原快照和归档状态，不自动恢复；整理信息得到的新 SHA 则是独立版本，不会自动归档父版本。

归档不删除内容，也不释放容量；总数量和正文大小仍包含归档项。备份时仍须在服务停止使用该目录后复制整个库目录，包含状态表与 SQLite 日志。没有新增永久删除、账号、多机同步或自动晋升。

## 接口

沿用本机 Host、同源 Origin、JSON 大小和事务边界。

| 方法 | 路径 | 结果 |
| --- | --- | --- |
| GET | `/api/component-library/status` | 总数量、当前数量、归档数量及正文容量 |
| GET | `/api/component-library/snapshots?scope=active` | 当前快照；默认范围 |
| GET | `/api/component-library/snapshots?scope=archived` | 归档快照 |
| GET | `/api/component-library/snapshots?scope=all` | 全部版本；各范围均支持原有 q / offset / limit |
| GET | `/api/component-library/snapshots/:sha` | 按指纹读取原内容和当前状态，允许归档项 |
| POST | `/api/component-library/snapshots/:sha/state` | `{archived:boolean}`，返回 `{record}` |

客户端核对状态回执的 ID 与目标状态。请求失败时不乐观翻转显示，可重试同一目标状态或刷新核对。新入库、归档 / 恢复与批量队列共享写入锁；批量回执与导出记录标明回执时的归档状态。

## 验证

复用现有存储场景核对原 SQL 行不变、幂等请求、重复入库不恢复、跨句柄与重启、归档 / 全部范围及状态数量。召回场景先冻结候选，再归档 26 项并恢复一项，核对归档项不占候选预算、旧清单仍可复用；双 CLI 场景核对运行中归档和采用规划后的冻结来源保持。

现有助手 UI 流程覆盖提交成功但丢回执后的同状态重试、范围切换、从子版本打开归档父快照、恢复、历史助手来源查看，以及无效插入比例下的原预览和原快照导出。没有新增测试文件或逐按钮脚本。

512 项核心 / 服务检查、Lint、类型与构建通过；四条 1920×1080 UI 流程通过，25.207 秒，仍为五个文件。最后仅为消除模板变量重名警告更名一个计算值，已逐字核对除此之外源码不变，并重新完成 Lint / 类型 / 构建。

独立页面复用上一轮真实调用保存的 134 图元 / 九边组件及其信息整理版本，执行归档 → 恢复 → 再归档，核对三个范围、从子版本打开归档父版本、125% 插入比例保持、原快照导出及库重启。原 SQL 行逐字段不变，导出 SHA 等于原快照 ID；新候选只含当前版本，先前冻结的两份素材仍可使用。当前工程保持，零运行时错误、零模型调用。

第一次独立验证发现无效缩放会隐藏原预览和导出，等待下载因此超时；失败界面与记录保留在 `test-results/component-archive-ui-v1/`。修复后用相同两份快照在全新目录复验通过，实际截图、数据库、原 / 新清单、导出文件、源码和指标在 `test-results/component-archive-ui-v2/`；最后的纯变量更名另有源码与差异记录，没有覆盖前一轮证据。

这些检查证明归档状态与原生快照保持，不代表独立论文质量或素材相关性评测；批量版本整理、语义去重、视觉检索、自动晋升和 RSI 继续开发。
