# 组件默认主题色与方案绑定

第三十五批，2026-10-30。针对[真实组合验证](composition-style-live.md)中 MLP 保留青绿色、没有采用方案蓝色的问题，增加可审阅的组件默认色绑定。

## 人工编辑

右侧容器样式区域新增“默认主题色”色样；选择当前配色中的一个颜色，改变该容器范围内继承的填充、描边、结构图示与内部语义连接。全图写入 `style.colorIndex`，子容器写入 `appearance.colorIndex`。子容器可以恢复继承父级；全图恢复默认首色。更改可单步撤销，几何、文字、端口和连接保持。

风格编辑也可保存默认色槽；从当前容器或方案保存风格会保留它。切换到颜色数更少的配色后，继承色槽按当前颜色数循环解析；保存风格记录实际生效的色槽，避免有效画面无法保存。基础色槽随工程、组件捕获、缩放、插入和原生 SVG 元数据保存，导出的 SVG / draw.io 使用相同解析规则。draw.io 外部编辑往返仍未验证。

这是默认色，不是把整组强制涂成一种颜色。`visual.fill/stroke`、文字显式颜色、节点 / 容器的 `visual.colorIndex` 和内层样式覆盖继续优先。多色素材的显式色槽不会自动被重写。包含数据图表的容器不开放组件默认色绑定；系列与数值色阶继续使用图表自己的配色工具。

## 模型规划与生成

每份方案的 `sections[].components[]` 现在必须有全方案唯一的 `id`，与生成时的 `instances.id` 一致。同一素材在多个位置复用时，各实例可选择不同的 `colorIndex`；索引从零开始，必须属于方案所选配色的实际颜色数量。省略表示保留素材或继承的默认色。

例如 Publication Soft 的蓝色实际是第三个色槽 `#8DA0CB`，不是凭颜色名称猜测索引：

```json
{"id":"mlp","key":"asset:authored-mlp-head","colorIndex":2}
```

规划提示提供实际配色、素材默认主题和显式颜色 / 色槽对象数，要求模型将颜色用途写成明确绑定。方案视图展示素材名称、真实色样和色号；采用仍是显式操作。生成后程序先核对实例身份、素材及参数，再将方案配色和色槽写到该实例容器上。不会通过重绘内部节点来换色，不改变库中原素材。

全图默认色槽与固定风格也须一致。缺少计划实例、替换实例标识、重复标识、越界色槽和数据图表绑定会被拒绝，不产生可应用候选。旧的无实例标识方案需重新规划；本阶段按破坏性迭代推进，没有迁移旧报告。

## 验证

Lint、类型、501 项核心 / 服务检查、生产构建和 1920×1080 四条 UI 流程通过。新增检查集中在既有文件：同源双实例分别着色、实际 SVG 连接 / draw.io 颜色、原始节点与边不变、显式颜色优先、捕获与 SVG 往返、错误绑定拒绝。Codex / Claude 子进程夹具覆盖冻结方案应用；界面覆盖色样选择 / 撤销、风格保存和采用后实例绑定，仍只有五个 UI 文件。

单元检查证明指定色槽按程序规则生效，不证明模型必然选择合适的颜色、完整语义配色、科学正确性或论文质量。真实复验使用现有 `experiments/multi-reference-live.mjs`，与默认测试隔离。

## 真实复验

继续使用三张自制参考图、同一份 3–3–3–2 原生 MLP 和 Quiet paper 风格，没有在用户要求里直接指定色槽。模型根据风格说明“青色表示输入，蓝色表示处理”和实际颜色清单，在方案中返回 `mlp_head → colorIndex: 2`。开发助手检查方案后显式采用，再单独调用生成；没有自动重试或应用用户工程。

| 阶段 | 运行 ID | 耗时 |
| --- | --- | --- |
| 规划 | `39c39f1c-952f-479e-b09e-33266b85a170` | 77.550 秒 |
| 生成 | `8c5c6ddd-90b8-4ddd-a71c-5302d2d71529` | 204.754 秒 |

共两次 Codex CLI 0.165.0 实际调用，使用本机默认模型，模型身份未报告。候选中 11 个神经元及 24 条内部连接实际呈蓝色；0.75 等比几何、标签、原生字体和两个命名接口保持，两个外部连接正确绑定接口。三张实际输入字节与顺序经过 SHA-256 核对，源组件不变，捕获素材保留方案、风格和逐图来源。文字检查零项，26 条路线均未被判定受阻；仍有 MLP 全连接本身的交叉，路线检查不代表布局最优。

已查看实际图片，确认白底、输入青色、MLP 蓝色、输出符号与两条类别注释可读。产物在 `test-results/composition-theme-live-codex-v1/`，保留规划 / 生成提示、原始输出、来源快照、源码指纹、方案采用、待审候选、图片和指标。它是同一开发样例的后续验证，没有独立人工评分、真实论文或总体成功率结论。

真实调用结束后修复短配色的索引归一化，并拒绝组件占用根标识 `stage`。对原候选做零追加模型调用的当前 SVG 核对，确认候选数据不变、11 个神经元与 24 条内部边仍使用预期蓝色；结果及最终源码快照在 `post-run-verification/`。原始输入、输出和图片没有被替换。

默认绑定已修正本例的 MLP 颜色问题；素材中显式色槽、手工 RGB 和内部局部覆盖仍保留。多色素材内部各语义角色的映射、字体 / 遮挡与科学含义仍待扩展评估，不能将默认色绑定等同于完整风格迁移或 RSI。

第三十六批新增[多色角色映射](color-mapping.md)，可以显式映射对象色槽并同时交换角色颜色，固定 RGB 与原生结构继续保持。本页保留默认主题色自身的范围和第三十五批实测记录。
