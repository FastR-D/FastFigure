# 主图设计审阅

结构正确不保证读图清楚。重复卡片、平均分配面积、辅助框过重、长说明和局部结构间没有对应，都可能让整张图缺少重点。配方解决局部拓扑，主图还需要围绕研究论点安排概览、机制、细节与证据。

## 使用

助手的“本轮任务”选择“审阅当前主图”，说明本图要表达的研究论点和使用场景，再发送。助手看当前整张画布的实际渲染，先描述第一眼重点和阅读路径，再给出值得保留的表达、观察、阅读影响、具体建议和不确定事项。检查视觉主次、整体编排、图形表达、文字符号、密度留白、对应关系及待核对的科学含义。

点击建议标题可在受审整图上标出区域；“选中相关对象”只改变当前选区。画布已经变化时，历史报告与图片仍保留，相关对象定位暂停，需要重新审阅。没有提出问题不表示自动验收通过。

本轮没有候选图，也不会自动修复。可根据判断手工调整，或切换“生成候选图”，明确说明采用哪些建议。普通绘图仍通过候选审核后应用。审阅不强迫一张主图使用多个结构；结构组合必须服务论点，而不是为了丰富而堆砌。

## 实现边界

- 使用与可编辑候选相同的浏览器字形渲染器，固定完整 1000×620 画布，发送 1600×992 图片；不夹带参考图或组件图谱。
- 固定工程快照与图片字节指纹，服务检查实际尺寸；历史可回看实际发送的图片。客户端回看时核对字节和尺寸。指纹证明版本一致，不证明渲染忠实或审美正确。
- 使用新适配器与独立运行目录，不继承绘制会话。位置目录采用几何别名，节点、容器和连线可定位，不自动提供含答案的对象名称；已有方案意图另列为作者声明。
- 严格解析报告，拒绝未知对象、越界位置、补丁、图件或评分字段。观察、影响和建议分别保存；全部为模型意见，不作为科学结论或自动通过判据。
- 全图缩览不能保证识别所有小字，也不能替代最终刊印尺寸下的文字测量；没有目标尺寸时不声称已验证印刷可读性。当前只覆盖原生图件渲染，参考底图不是审阅主图的替代品。

双图重建保真度审阅仍用[原图与候选视觉审阅](visual-audit.md)，其原图差异类别与修复链保持独立。

## 验证与显式实验

核心检查报告契约、未知对象与版本变化；服务检查独立适配器、单张图片、指纹、历史和只读结果；在原有助手桌面流程核对实际解码、定位、选区与画布保持。普通检查使用协议夹具，不能证明模型审美。

真实模型继续使用已有实验入口，显式选择整图模式：

```bash
node experiments/visual-audit-live.mjs \
  --seed docs/research/assets/unet-mainfigure.json \
  --design-review \
  --output test-results/mainfigure-design-review-live
```

可用 `--goal` 指定论点与关注点，`--model` 指定本机 CLI 的模型。实验保留实际输入图片、完整提示、报告、运行事件与指标；一次真实调用只证明这条链路能运行，不构成独立审美评测。

一次已完成的实际调用及意见见[整图审阅记录](../research/2026-10-31-mainfigure-design-review.md)。
