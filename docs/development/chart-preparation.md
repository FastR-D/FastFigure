# 可审阅的长表展开与原始来源绑定

2026-10-30，第七十一批更新。支持把常见的 Run / Method / Metric 长表及复合条件、配对误差展开为宽表，让人和模型共用同一套不聚合的数据整理程序。整理预览、采用附件与生成图件是明确的三个步骤。

## 操作

从左侧助手的“导入数据，让助手选图”导入长表，填写数值含义和研究目标。助手可以返回“建议整理：长表转宽表”，只提出行标识键、组别键、数值及可选误差半宽的源列别名，本轮不生成图。点击“预览长表整理”，核对原表、宽表、空值、未提供的组合及未参与展开的列；每个数值和误差单元格可悬停查看对应的源表行号与列名。

点击“采用为数据附件”才替换当前助手附件，当前画布不变，也不自动调用模型。原研究问题回到输入框，再由人发送以继续选图。附件会带“已确认展开（原表保留）”标记；模型基于宽表选择现有图型，程序按源列生成待审阅候选。应用图件仍为一次可撤销操作。

导入对话框也有“手动设置长表展开”，行标识与组别各勾选 1–3 个字段，用上移 / 下移明确复合键的字段顺序，再选择数值列和可选误差半宽列。采用后同样进入助手附件。展开后的附件可填写数值含义等使用者声明，数值表保持绑定；“还原原始附件”恢复原表，“解除附件原表绑定”则明确转为手工数据。取消导入对话框不替换当前附件。

若预览来自历史消息，而当前附件已换成另一份数据，采用会提示先移除当前附件，避免覆盖后来导入的数据。刷新后原始附件仍需从历史预览采用或重新导入；本地服务内的整理报告保留完整原始表，服务重启不恢复内存会话。

```csv
Run,Method,Accuracy (%),Dataset
r2,Ours,82,A
r1,Baseline,0,A
r2,Baseline,,A
r1,Ours,81,A
r3,Baseline,78,A
r4,Ours,8.3e1,A
r4,Baseline,79,A
```

选择 Run / Method / Accuracy (%) 后，列为 `Run,Ours,Baseline`，行依次为 r2 / r1 / r3 / r4。r2 的 Baseline 是一条实际源记录中的空值；r3 的 Ours 是原表未提供的组合。两者在图中均不补值，预览与来源记录能区分；0 保持为 0，`8.3e1` 的原始数值文本保留，绘图时按 83 编码。Dataset 不参加展开，但完整内容仍保存在原表。

## 复合条件与配对误差

例如同一模型名会出现在不同数据集，单独用 Model 作为行键会误报重复；应明确选 Dataset 与 Model。方法配置也可由 Method 与 Mode 共同标识：

```csv
Dataset,Model,Method,Mode,Accuracy (%),SE (%),Note
D1,S,Base,fp16,76,.5,keep
D1,S,Ours,fp16,8.2e1,.4,keep
D2,S,Base,fp16,78,.6,keep
D2,S,Ours,fp16,,,explicit blank
D1,L,Base,fp16,0,0,zero
```

使用者声明这些数值为已汇总统计量，误差含义为 `Mean ± SE`，选择映射：

```json
{"kind":"pivot","rowColumns":["c0","c1"],"groupColumns":["c2","c3"],"valueColumn":"c4","errorColumn":"c5"}
```

宽表包含 `Dataset · Model` 行标识，以及每组的数值 / 误差两列，按组交错排列。行顺序为 D1 · S、D2 · S、D1 · L；组顺序为 Base · fp16、Ours · fp16。D2 · S 的 Ours 数值和误差来自实际空记录，D1 · L 的 Ours 组合没有提供；Base 的零数值与零误差都保留。

程序用完整字段元组判断身份，显示标签用 ` · ` 连接，并转义字段内部的反斜杠和 `·`，不会把拼接字符串当作判重依据。每组的数值与误差都来自同一条原始记录，列概况将其标为 `value` / `error` 并列出 `pairedValueColumn`，供助手选择对应字段。

误差列只接受已给定的非负对称 ± 半宽，需由使用者填写含义。不会由列名判断 SD / SE / CI、计算误差或把上下界当作半宽。只有误差而没有数值时拒绝；有数值而误差为空时保留该空值。已有误差含义却没有选误差列也会拒绝，避免静默丢掉不确定性。

## 整理规则与限制

每个“行标识＋组别”只允许一条源记录，即使重复数值相等、为空，或只是未映射的 Dataset 不同，也会拒绝，不平均、求和或覆盖。该不聚合和重复组合报错的原则可对照 [pandas DataFrame.pivot](https://pandas.pydata.org/docs/reference/api/pandas.DataFrame.pivot.html)；产品使用自己的实现，没有 pandas 运行依赖。

- 行和组各由 1–3 个源字段组成，完整组合按第一次出现的顺序保留；各字段不得为空，完整显示标签最多 24 字，不自动缩写。所有映射必须存在且互不重叠；组名与输出行标识表头重复时拒绝。
- 复合行表头按字段名连接，超过 40 字时显示为“组合行标识”，原字段名仍完整保留在来源映射。生成的误差列表头为组名加 ` · err`，必要时加序号避免与其他列重名；不依靠表头后缀判断配对关系。
- 单次只展开一个数值指标，非空值须为已支持的有限纯数值；不解析 `%`、单位文本、`NA`，不做单位换算。标识 / 数值不合法时指出源行，原行不被丢弃。
- 原始附件最多 480 行、12 列；整理结果为 2–80 个行标识、最多 12 列。无误差时最多 11 个数值组，有配对误差时最多 5 组。源文本仍最多 20,000 字符、文件最多 60 KB；原始规范化数据最多 24,000 字符，包含来源的附件最多 48,000 字符。超限报错，不截断。
- 当前图型仍有各自限制：箱线最多 6 组，热图最多 12 行，点线 / 柱状最多 4 个系列等。能整理不意味着所有图型都能绘制；助手仍需合理选型或提出待确认问题。
- 不支持透视聚合、自动筛选、多个指标合并或变换链。需要这些处理时返回 `needs-input`。不把行号捏造成 Run，也不推断原始样本、独立性或重复实验设计。已有整理附件不再次展开。

缺失来源按源行索引记录：实际空单元格保留源行，未提供组合为 null；另记录对应源列索引。每组的数值 / 误差重复同一源行索引，并分别指向各自的源列。原始表指导入和规范化后的表格，既有 CSV 解析会处理引号与首尾空白；不声称保留源文件的全部字节或原始排版。

## 原表与图表保持一致

附件的 `preparation={source,operation}` 保存原始数据快照及 pivot 字段映射；schema 会重算宽表，拒绝改动宽表但保留旧来源的附件。使用者修改名称、数值含义等声明不改变原始快照；模型不能通过推荐对象改写这些声明。当前协议使用 `rowColumns` / `groupColumns` 数组，不兼容旧的单数标量字段。

选图后的 `dataChart.spec.dataPreparation={preparation,selection}` 再记录宽表的 X / 系列 / 可选标注映射。程序从原表重算宽表并核对图表的行、系列名、原始数值和误差映射；源绑定不一致时拒绝。模型不能提供新值、来源快照、聚合指令或自造整理结果。

有配对误差时，每个选中的数值系列必须带上自己的误差列；不能丢弃、互换或把误差当成普通系列。误差列不能用作 X；带配对误差的数值列也不能用作 X，因为当前尚不支持横向误差。图型 / 数据量不合适时应提问或选择其他受支持形式，不通过丢误差迁就图型。

标题、轴范围、配色及原始点显示等表现仍可更改，图表重绘固定原始来源。数值表默认只读，查看原表不会解除绑定；“解除原表绑定以编辑数据”明确转为手工数值，保存时移除绑定。修改箱线示例数据仍需重新确认是原始观测。之前的原表可在助手历史回看，更新 / 解绑都可撤销。

图表保存、组件捕获 / 缩放 / 重插、助手样式重绘、工程 JSON 和 FastFigure SVG 元数据往返保留来源与选择映射。这里验证的是结构与值的一致性，不认证数据是否来自真实实验。自由修改图元仍可能改变视觉，重新按数据绘制会恢复生成图元。
