# 助手基于固定输入重绘图表

2026-10-29，第廿二批。把已有数据图表编译器接到助手组件协议，支持已保存图表的表现调整。模型提出选项，程序读取本轮所选组件的数据快照，生成原生可编辑候选并记录实际调用。

第廿三批增加数值散点与数据行标注。`kind` 可使用 `scatter`，要求源 X 已是数值，不把分类名猜成数值；原始行标注也固定保留。首次从原始表选型的入口与边界见 [数据可视化选型](chart-selection.md)。

第廿四批增加 [热图重绘](heatmaps.md)：源热图保持 `kind=heatmap`，用 `colorMin/colorMax/colorCenter/valueLabel` 调整数值色标及其标题，不与点线 / 柱状工具直接互转。数值色阶与画板分类配色分开，来源、矩阵与声明继续固定。

第廿五批增加 [箱线图重绘](boxplots.md)：保持原始样本与固定统计规则，可调整原始点叠加和中位数标签；关闭叠加仍显示全部离群点，报告摘要由程序重算。箱线与其他图型不直接互转。

第廿六批增加 [数值轴重绘](chart-axes.md)：可选择线性 / log10、数值 X/Y 范围，程序检查正域与完整原始误差端点，重绘记录报告实际坐标。箱线统计口径不因显示切换改变。

第廿七批的 [原表绑定](chart-preparation.md) 随图表样式工具保持：源快照、展开映射与图表选择映射不能由 chartOptions 修改，重绘记录可回看原始长表。

## 操作

1. 在“组件 → 实验图表”输入 CSV / TSV，确认误差含义和示例标记，预览图表。
2. 点“存为组件并交给助手”；已插入的图也可从“编辑图表数据”打开后保存。左侧助手会明确选择这一个图表资产。
3. 输入要求，例如“改成分组柱状图，纵轴从 0 到 100，用 Publication Soft 配色，隐藏网格和数值标签，保留注释”。范围需要覆盖所有输入和误差棒；柱状图须包含零。
4. 查看候选和“图表重绘记录”，核对图内标题、轴标题、配色、数据与注释后应用。运行本身不改变画布；应用为一次撤销记录。

切换左侧 Tab 保留草稿、消息和运行。刷新可恢复当前服务保留的记录与待审候选；服务重启不恢复内存会话。

## 固定数据与编辑语义

编译器读取最近一次数据编辑器保存的输入，固定横轴条件、系列名称、数值、缺失值、对称误差、误差含义、图下注释、来源和 `example/user` 标记。不会从手动拉伸的柱形、移动的点或改过的标签反推数据。示例图仍显示 Illustrative data，`user` 只表示使用者填写，不能证明实验真实性。

明确重绘时重新生成标题、轴、系列、图例和误差棒，会覆盖生成图元上的手动外观修改。没有生成标识的另加文字、图标、形状及命名接口保留。省略 `chartOptions` 时，仍复用整个保存外观；显式传 `{}` 也表示按原输入重新绘制。换数据或误差解释，应先在数据编辑器确认并重新保存 / 发送。

目前只接受根组合就是一个数据图表的个人组件，不遍历多图组合推测目标。数值折线转柱状时，将横轴按原输入顺序转为字符串分类；超过 12 个条件会拒绝，不删除数据。柱状改折线保留分类横轴，不猜测分类名称的数值间距。折线继续支持最多 20 个数值 X 和 1–4 个系列。

程序保护适用于本编译路径。模型仍可提出普通 FigureIR 图元，人工改图也可改变图形；这些自由编辑不构成图形与统计含义一致的证明。标题和轴标题允许按要求调整，仍需人工核对单位和解释。

## 协议

普通绘图请求、SSE、历史与审阅接口不变。返回的 `instances` 选择已在本轮清单中的图表资产，可带：

```json
{
  "id": "comparison",
  "componentKey": "asset:source-chart",
  "parentId": "stage",
  "x": 60,
  "y": 150,
  "scale": 0.7,
  "keepAppearance": true,
  "chartOptions": {
    "kind": "bar",
    "title": "Controlled bar comparison",
    "yMin": 0,
    "yMax": 100,
    "paletteId": "figureforge-publication-soft",
    "grid": false,
    "showValues": false
  }
}
```

`chartOptions` 只接受表现字段：通用字体 / 字号、类型、标题 / 轴标题、数值显示、网格与配色；坐标类图表还可设置 X/Y 刻度与范围，热图使用独立色标参数，箱线图另有原始点显示。完整字段见[类型契约](../../src/core/dataChartSchema.ts)，字体能力见[统一字体 / 字号](chart-typography.md)。省略字段沿用原配置；数值范围及色标的可空字段可用 null 单独恢复自动值。标题及轴标题输入须为单行。实例 `title` 只改组名称，`chartOptions.title` 才改图内标题。实例 `scale` 在重绘之后整体等比缩放，不改源资产。

传入观测、`origin`、`errorLabel` 等额外字段会拒绝整轮候选；范围截断输入 / 误差、非零柱状基线、无效配色、容量或布局失败同样原子拒绝。失败保留此前可用候选及当前画布。重绘合并旧来源与编译器配色来源，最多 12 条；不静默丢弃来源。

清单为支持的资产附上固定 `dataChart` 和能力说明。上下文包含当前与输入配置配色，另提供 FigureForge 的 16 组名称、ID 和色值，不要求用户写内部 ID。模型仅返回受控 JSON，不执行绘图代码，也未新增 MCP 注册。

`components[].chart` 由程序实际编译结果产生，包含源 / 新图表版本、类型、系列 / 条件数、数据身份、使用选项、生成及保留对象数。模型不能自行声明重绘已成功。消息展示该记录，历史和刷新保留。

实现位于 `src/core/chartTool.ts`、`dataChartSchema.ts`、`catalogue.ts`、`harness.ts` 和 `components/harness/ChartToolSummary.vue`。
