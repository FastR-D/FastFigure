# 可编辑 SVG / draw.io 素材导入

在组件库点击“导入 SVG / draw.io”，选择页面、整个图件或其中的分组，先检查由 FigureIR 重新绘制的预览，再选择插入当前容器、新建图件并插入、存入工作组件或加入本机入库队列。支持可选论文引用；保存后可供人和 Harness 使用同一素材。名称只改检索名称，不重写图中标题与标签。当前容器放不下时保留预览并显示原因，可选择新建图件。取消和解析失败均不更改当前工程或素材库；插入可以单步撤销。

## SVG 当前范围

| 内容 | 转换方式 |
| --- | --- |
| rect / circle / ellipse | 适合的轴对齐图形变为矩形 / 椭圆，其余保留为路径 |
| line / polyline / polygon / path | 相对 / 绝对命令统一成直线、二次或三次贝塞尔；圆弧转换为贝塞尔近似 |
| 多轮廓与闭合 | 保留子路径、闭合标记、nonzero / evenodd 填充规则 |
| text / tspan | 独立可编辑文字；保留字体、字号、数值字重、斜体、字距、x/y/dx/dy、分块对齐与基线 |
| transform / viewBox | matrix、平移、缩放、旋转、倾斜；将几何变换展开到坐标，文字保留二维变换 |
| g / 本地 use / symbol | 可保留分组、文件内引用和 symbol 的视图；可选择子组，包含 defs 中的分组 |
| 基础 CSS | 展示属性、行内样式、标签 / ID / 类 / 后代选择器与常规层叠 |
| 颜色和笔画 | 实色 / none、颜色 alpha、填充 / 描边透明度、线宽、虚线及偏移、端帽、转角与尖角限值 |
| 线性渐变 | 形状和路径的填充 / 描边；2–32 个停靠点、停靠点透明度、两种坐标单位、渐变变换、本地 href 继承、外延与插值 |
| 组合透明度 | 保留整组叠加的 alpha；与逐对象 alpha 分开，避免重叠区变深 |
| 简单 marker-end | 映射为标准可编辑开放 / 实心箭头，并在报告中说明尺寸适配 |
| FastFigure SVG | 默认从有效的 0.2 工程元数据恢复结构，忽略参考图片数据，再补充源文件记录；也可关闭恢复、直接解析 |

素材按完整几何等比缩小到约 880 × 420 的范围，保留留白，不放大小图。不保留原始物理尺寸或视框裁切。非等比变换的描边单独保留矩阵；文字保存基点、字形矩阵和基线，不把旋转文字压成水平排版。已知字体会在预览解析前等待载入；未安装字体按当前设备回退。输出 SVG 保存字体名称，不嵌入字体文件。

容量为文件 2 MB、XML 元素 4,096、图元 240、容器含根 21、嵌套深度 6；路径每条最多 128 个锚点，全图锚点与控制点共 4,096。可以选择较小子图，或关闭保留无透明度的分组，满足这些约束。仍有透明度的分组不能直接扁平化。

径向渐变、文字 / 容器渐变、图案、裁剪、mask、滤镜、slice 视图、图片、外部资源、动画、foreignObject、不支持的 CSS 选择器、CSS transform、逐字旋转 / 强制字宽、独立变换的 tspan、textPath 和起点 / 中点箭头暂不支持；遇到这类实际内容返回原因，不交付局部成功的图。忽略非 SVG 命名空间的编辑器 / RDF 元数据。当前不是任意 SVG 渲染器，也没有 OCR、连接语义推断或位图自动矢量化。

源文件只进入 XML 分析器，不挂载进页面或通过 innerHTML 绘制。预览和画布仅使用已验证的 FigureIR。禁止 DTD / entity、事件和外部资源；use 引用检测循环。样式颜色通过浏览器解析成规范实色值，不保留原 CSS 文本。

## 线性渐变编辑与复用

选中一个形状或路径，在属性栏选择“填充 / 描边”通道，再将方式改为“线性渐变”。可调整方向、停靠点颜色 / 位置 / 不透明度，增删停靠点，选择延伸端点色、镜像重复或重复，以及 sRGB / 线性 RGB 插值。切回“单色”或从中心工具栏指定单色会清除同通道渐变；路径也可在属性栏指定单色或无填充 / 无描边。修改渐变角度会重新铺满形状边界，未修改时保留源映射。

`objectBoundingBox` 使用真实贝塞尔极值边界，不使用控制点包围框；`userSpaceOnUse` 的百分比使用当前 SVG 视口。几何和 `gradientTransform` 一起转换为原生颜色场，正确保留旋转、斜切、非等比缩放和独立描边矩阵。零高度 / 宽度路径的用户空间描边仍可保留；对象边界退化时按 SVG 规则不绘制对象边界渐变。单停靠点、重合端点转换为相应单色，未提供停靠点时不绘制。

原生字段为 `visual.fillGradient` / `strokeGradient`，结构为 `{type:'linear',vector:[a,b,c],stops:[{offset,color,opacity}],spread,interpolation}`。采用 `u=(x-node.x)/(node.width||node.height)`、`v=(y-node.y)/(node.height||node.width)` 与 `t=a*u+b*v+c` 表示颜色位置；它保存完整仿射映射，避免仅变换两个端点造成斜切后的颜色偏差。方向向量必须非零，停靠点按位置排序，重复位置可表达硬边。Harness 省略字段时保留原值，显式 `null` 清除渐变；普通单色换色直接清除覆盖。透明清除标记不影响本机素材的原生图形内容核对。

渐变随素材采集、缩放、插入、工程 JSON 和 SVG 元数据保存。SVG 使用原生 `linearGradient`；每个对象的定义带对象身份及绘制内容指纹，防止同一图件内重复 ID，以及画布 / 预览显示不同停靠点时互相引用。draw.io 源文件的普通形状 `gradientColor` 已支持四个基本方向和独立填充 / 描边透明度，水平泳道渐变仅用于标题区域；竖向泳道和不支持的分组透明合成明确拒绝。

FigureForge 的 `heatmap`（108 个原生图元）和 `comp-abc`（118 个）现可复用渐变色条，可用静态模板由 18 增至 20。静态色条不推断实验原值；真正的数据热图仍从用户原始矩阵编译。渐变系列不作为单色共享图例，手工渐变色格会停用与原数值色阶不一致的共享色标。

实现参照 [SVG 2 线性渐变和停靠点](https://www.w3.org/TR/SVG2/pservers.html#LinearGradients)及[对象包围框坐标](https://www.w3.org/TR/SVG2/coords.html#ObjectBoundingBox)。浏览器对斜切曲线、带硬边 / 线性 RGB 插值的重复填充、仿射描边共 13 个内部采样点，源 SVG 与原生导出 RGBA 一致；这是受控样例的采样结果，不表示任意 SVG 全图像素一致。证据位于 `test-results/gradient-proof/`；此功能没有调用真实模型。

## 路径和文字编辑

路径锚点显示为圆点，贝塞尔控制点显示为黄色方点，均可拖动或用方向键 / Shift 微调。选中锚点后可在属性栏将到达该点的线段切换为直线、二次或三次贝塞尔。增加折点使用 De Casteljau 拆分，保留曲线形状；删除中间锚点会改变形状，子路径起止边界不能删除。闭合 / 复合轮廓不接受开放端点绑定。

双击导入文字后可改字，中心格式栏可改字体、1–256 字号、粗斜体、颜色及对齐。改字或格式保持原有基点并重算包围盒，透明素材组合按需要扩大边界；超出画布等约束时原子回退。拖动文字选择框的大小会缩放其字形矩阵。组合只改变边界，不隐式缩放其所有内容。

整组透明度可在透明自由组合的属性中调整。解组会丢失整体叠加语义，因此要求先设为 100%，并显示具体原因。

`ComponentSource.file={format:'svg',fileName,sha256}` 保存原始字节的 SHA-256。原始 SVG 字节不写入素材 JSON，节点证据、组件来源及再次采集会保留引用和指纹。来源记录不是额外授权；使用第三方素材仍需遵循其来源许可。

## draw.io 源素材

第七十三批把已有 XML / SVG 几何、字形和曲线解析器接到 draw.io 源文件，输出统一的原生 FigureIR，没有引入绘图库生产依赖。

- 输入 `.drawio` / `.xml` 的 mxfile、单页 diagram、裸 mxGraphModel；支持未压缩页面与 Base64 / raw DEFLATE / URI 编码页面混用。`.drawio.svg` 从根 content 属性读取嵌入源图，而不是猜测外层截图。单图多页文件必须明确选页；[批量入口](component-batch-import.md)按页拆成独立项，逐页预览、选择、保存。
- 矩形 / 圆角矩形、圆 / 椭圆、菱形转为原生形状；三角形、六边形、平行四边形、梯形、圆柱和横向泳道使用可编辑路径近似。支持常见填色、描边、虚线和透明度。原有分组保留；根 / 默认层及单对象的结构包装不重复制造容器。
- 文字保留为独立对象；常见 HTML 加粗、斜体、字号、颜色、换行与上下标转为原生字形。换行、基线和宽度按字体估算，仍需看预览。导入文字同时记录源单元 ID。
- 连线读取父级相对端点、entry / exit 比例及手工控制点；普通直线 / 折线与有明确控制点的曲线可编辑。标准开放 / 实心箭头是样式适配。无手工控制点的正交 / 肘形连线调用现有避障器，程序只排除连线自身的包装与标签，保留实际图形障碍；受阻时保留端点直线并显示原因。
- 连线标签按路径相对距离、带方向的垂直偏移和 offset 放置；重算路线时同步位置。之后作为独立文字编辑，尚无“标签始终沿用户后续修改的路线移动”的语义约束。曲线标签、独立的 edgeLabel 子单元、自动曲线和无控制点自环需先在源编辑器展开。
- 旋转图形或部分扩展形状通过不可见的逻辑边界锚点保存连接，移动整组时端点跟随。此类锚点用于编辑，不进入最终可见画面；不是对任意轮廓的精确连接推断。选择子图后，范围外的绑定解除，报告明确列出数量。
- 只接受内嵌 SVG 图像并继续解析为图元；不保留外部图片或位图。FastFigure 导出的空文字裁剪包装可安全清除，包含实际文字 / 图形的裁剪仍拒绝。内嵌 SVG 的实际整体透明度继续保留。

`file={format:'drawio',fileName,sha256,page:{index,id,name},objectId?}` 记录原字节、零基页序号、源页名 / ID 及原单元 ID。库来源按文件 / 页面合并，对象记录保留自己的单元 ID，避免同页每个标签都占一条来源；不同页不会合并。入库、再次采集、缩放和重插会保留这些记录，原 XML 不写进素材正文。

原文件上限 2 MB、1–50 页、解压合计 8 MB；每页 XML 最多 8,192 元素 / 4,096 单元，转换后继续遵守 240 图元、20 个非根容器和深度预算。关闭保留分组或先在源编辑器拆分可减少容量。未知模板形状、命名样式、自定义库、不支持的渐变方向、阴影、Sketch / 翻转、旋转容器、竖排 / RTL、特殊文字裁剪 / 背景 / 边框、数据占位、起点 / 双向箭头及宽箭头等效果会拒绝。单页中有不支持的实际内容时，需先在源编辑器隔离，不能从该失败页继续选择未转换的子图。不会推断数据图统计、命名接口或科学含义。

依据：[draw.io 文件格式](https://github.com/jgraph/drawio/wiki/File-Format)、[官方样式表](https://www.drawio.com/docs/reference/diagram-generation/style-reference/)、[mxGeometry](https://jgraph.github.io/mxgraph/docs/js-api/files/model/mxGeometry-js.html) 与 [mxGraphView 的标签位置算法](https://github.com/jgraph/mxgraph/blob/master/javascript/src/js/view/mxGraphView.js)。

## 导出与 Harness

SVG 保留原生可编辑曲线与文字，同时附带不含参考图片的工程元数据。工程 JSON 保留全部新增字段。导出支持 SVG、PNG 和工程 JSON；draw.io 仅用于素材导入。

素材入库后仍通过固定的 catalogue 快照复用，程序重映射 ID，保留路径、文字变换、字重 / 字距、透明度与来源。已有图件修订时，模型省略这些字段会保留，候选差异能报告文字矩阵、图元名称和组合透明度。本批没有新增真实模型调用，自动检查使用契约与测试 CLI。

## 验证与依据

早期 SVG 接入时累计 150 项单元 / 集成检查，新增 33 项，覆盖仿射变换、贝塞尔精确拆分、闭合编辑、SVG 图元 / CSS / 字体 / viewBox / use / 子组、透明度、元数据恢复、来源与素材往返、Harness 字段保留和非法 / 超限输入。当时的浏览器检查包括多个 PC 视口；当前只维护 1920×1080。

早期定向验收用自建编码器、富文字和复合特征体样例做过源 SVG 与原生 FigureIR 的浏览器像素比较。1000 × 620、相同字体和适配坐标下，当时平均通道差约 0.001 / 255，21 个像素的最大通道差超过 16；门限为平均差 < 0.1 且差值 > 16 的像素 < 1,000。仅说明该受控样例的外观，没有覆盖所有来源。截图、像素报告和 SVG / draw.io 文件位于忽略提交的 `test-results/svg-*`。该逐功能脚本已清理，当前 `test:ui` 在助手与素材流程中验证 SVG 批量导入、原生图形与来源保留，测试范围见[开发与验收约定](testing.md)。

实现依据：[SVG 2 路径](https://www.w3.org/TR/SVG2/paths.html)、[SVG 2 坐标与变换](https://www.w3.org/TR/SVG2/coords.html)、[svgpath](https://github.com/fontello/svgpath)。svgpath 2.6.0 为生产依赖，MIT 许可保留在 `public/notices/svgpath-MIT.txt`；[@xmldom/xmldom](https://github.com/xmldom/xmldom) 只用于 Node 测试，浏览器导入使用原生 DOMParser。导入界面与解析依赖按需加载。

第七十三批最终 Lint、类型 / 构建、557 项核心 / 服务检查与四条 1920px 流程通过；完整 UI 实测 50.134 秒，仅代表本机本轮。原 SVG 检查文件新增三个必要场景，现有助手流程覆盖混合原始 / 压缩页、失败页隔离、默认不选、明确提交及原文件 / 页面 / 文字单元来源和绑定保留；仍为 40 个核心 / 服务检查文件、五个 UI 文件，没有新增维护脚本。

独立临时库与新浏览器的 `test-results/drawio-import-dialog-v2/` 保存实际界面和结果：自制的嵌入源图 SVG 先明确选页，不支持的页不沿用旧范围；选择菱形子图后加入队列、明确入库，再从库新建图件并插入；对象来源可见，改字 / 撤销 / 刷新有效。入库前原工程保持，最终图谱与前次实操一致。

`test-results/drawio-engine-v3/` 使用官方旧 mxGraph 4.2.2 开源包做离线交叉验证：引擎实际改字 / 移动并编码的 XML 可原生导入，标签位置与引擎结果相差小于 0.06 源单位；历史 draw.io 导出经真实引擎解码 / 再编码后仍保留两个端点绑定；该导出功能现已移除。此次发现并修正了无用分组膨胀、名称导致普通连线矢量化丢绑定，以及带矢量边距目标的比例换算。最终源码回放保持同一原生图谱和送入引擎的 XML；266 个生产源文件指纹随验收保存。

这是旧引擎上的受控样例，不是当前 draw.io 应用或任意模板的兼容性结论。尝试当前官方嵌入页时，浏览器收到 HTTP 403，未获得在线编辑结果，证据在 `test-results/drawio-external-v1/`。旧包只用于临时验收，没有加入生产依赖。此批零新增模型调用，不代表真实论文绘图质量、科学验收或 RSI 效果。
