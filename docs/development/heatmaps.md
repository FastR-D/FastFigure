# 原始矩阵热图与助手选型

2026-10-29，第廿四批。热图加入数据图表编辑器、原始表选型和助手重绘。编译结果为独立单元格、缺失标记、文字、外框和数值色标，继续支持编辑、缩放、入库与候选审阅。

## 操作

直接绘图：在“组件 → 实验图表 → 矩阵热图”粘贴 CSV / TSV，首列为行标签，其余表头是矩阵列。设置标题、横向列 / 纵向行标题、色标标题 / 单位、色阶、可选边界、数值标签和分隔线，预览后插入。

```csv
Method,Set A,Set B,Set C
B,-2,0,1
A,3,,1.5
C,0,-1,4
```

该表可声明为准确率改变量（百分点），使用以零为中心的发散色阶；程序不会仅根据数值猜测单位。空格显示为带 × 的缺失单元格，0 则仍按数值色阶编码。保留输入的 B / A / C 顺序，不排序、聚类、归一化或补值。

助手选型：人从“导入数据，让助手选图”附上原表，说明研究问题与数值含义，可附参考图片。模型选择 `heatmap`、行标签列、同量纲矩阵列、数值色阶和单位；程序从固定输入读取全部所选行列，生成可审阅候选。报告列出行 / 列映射、未绘制的列，以及实际编译的色标范围与中心。不同量纲的附加列可留在未绘制列中，不自动换算或放入同一色标。

已保存的热图可交给助手调整色阶、色标范围 / 中心、标题、边界与数值标签，保留源矩阵、声明和另加对象。热图与点线 / 柱状图的行列语义不同，此工具不直接互转；需要转换时从原始数据重新选型或明确整理表格。候选不会自动应用，应用后仍可单步撤销。

## 数值与视觉规则

- 顺序蓝、顺序青绿使用原值大小编码；没有自动零基线或数据归一化。自动范围覆盖实际最小 / 最大值，常量场扩展为非零区间，也可手动设定。
- FigureForge 蓝白红使用已固定源码中 `heatmap.dv` 的实际端点 `#2166ac / #f7f7fa / #b2182b`，围绕中心分段进行 sRGB 通道插值；默认中心为 0、自动范围围绕中心对称。自定义中心须位于色标范围内部。
- 手动范围不能截断任何原值，包括极小的正负数；非法范围整轮拒绝，不裁剪数据来凑图。顺序色阶不接受发散中心。
- 色标采用 32 个独立矢量色块近似连续显示，并标出边界 / 中心；不是通用 SVG 渐变能力。单元格颜色按其原始数值计算，不将数据转为色块序号。
- 单元格为等大的正方形。行列名称、色标、单位和缺失说明单独可编辑；深色单元格的数值采用浅色文字。中文色标标题可换行，括号内的短单位整体换行，不截断或缩小字号。
- 数字沿用数据图表的格式化显示，较大 / 极小值使用科学记数；原始数值保留在数据配置中。精确核对请查看数据表，数值标签过密时要求关闭标签，不额外降低显示精度或删格来排版。

数值色阶独立于 FastPPT 画板分类配色；应用画板配色不会改写热图的数值颜色或配置。通过“编辑图表数据”修改色阶，才重新按同一原始矩阵计算颜色。

直接编辑器最多 12 行 × 12 个数值列；原始表选型附件目前总计最多 12 列，包含行标签列，因此单次选型最多 11 个数值列。总图元容量仍为 240，色标、数值和缺失标记也计入；大矩阵或大量缺失 / 注释可能先达到容量，会明确拒绝，不自动抽样或丢行列。长标签也可能要求缩短。

热图不接受误差棒、点标注或纵轴数值范围。已有误差说明的表需要先确认如何表达不确定性；不会擅自丢掉误差声明改成热图。该流程不计算显著性、相关系数或混淆矩阵归一化。

## 数据和接口

沿用 `container.dataChart`：`kind=heatmap`，内部 `x` 保存从上到下的行标签，`series` 保存从左到右的数值列及逐行值。`valueLabel` 表示色标标题 / 单位，`colorMin/colorMax/colorCenter` 是可选的表现参数；`yMin/yMax` 仍只用于点线 / 柱状。

热图 CSV 不把 `_err` 或 `_label` 视为保留列名，而是普通矩阵列。生成的单元格按行标签和列名匹配身份；行 / 列重排保留连接，删除仍有连接的单元格会原子拒绝。缺失也是该单元格的一种状态，不被解释成删除该坐标。

`chartOptions` 的 `colorMin/colorMax/colorCenter=null` 恢复该项自动范围 / 默认中心；省略则保留原配置，0 则是真实设定值。热图清单只提供 `kind=heatmap`，并附上三组数值色阶信息。原始表选型的推荐使用严格的字段映射，不接受 `normalize`、新数值或任意绘图代码。报告中的 `scale` 由实际编译产生。

生成图元 `chart.role=heat`，不参与分类系列换色。另加的注释、命名接口和已有生成标识继续按原规则处理。重绘会覆盖生成图元的手工修改，保留无生成标识的额外对象。工程、组件捕获 / 重插、缩放、JSON 和 FastFigure SVG 元数据往返保留数据与声明。

核心实现：`src/core/heatmap.ts`、`chartText.ts`、`dataChartSchema.ts`、`dataChartTable.ts`、`chartRecommendation.ts` 与 `src/data/heatmapPalettes.ts`。FigureForge 色阶来源、固定版本和 MIT 署名随组件保存；现有上游静态模板仍为 18 个，本批没有把其聚类树或一般渐变导入器冒充为已实现能力。
