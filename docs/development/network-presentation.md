# 网络间距与组合内部连线设置

2026-10-29，第卅批。在原生直线连接基础上，补充可配置的层间留白，以及人和助手共用的组合内部连线设置。

## 人工操作

在“组件 → 参数化组合 → 全连接网络”中配置拓扑、层间距和神经元间距，预览和组件备份使用同一结果。间距为未缩放的坐标单位；整体缩放后按比例变化，神经元自身的大小、字号及拓扑仍按原配方保存。

| 参数 | 选项 | 默认值 |
| --- | --- | --- |
| `layerGap`，两层神经元边界之间的水平距离 | 32、48、64、80、104、120 | 80 |
| `neuronGap`，同层神经元边界之间的垂直距离 | 12、24、40、56、64 | 24 |

默认由原先固定 40 / 12 改为 80 / 24；所有层仍按自身神经元数在纵向居中。较大配置可能放不进当前容器，“插入当前容器”会禁用并提示，可明确缩放或新建图件。不会为了插入而压回原间距。最大已声明配置为 4–4–4–4–3，间距 120 / 64，组件 928 × 580，支持作为新图件或明确缩放后插入。

选择容器或组合后，右侧“内部连线”显示总数和两种方式的数量，可一次改成全部直线或全部折线避障。操作覆盖子树内、两个端点均属于该子树的语义边；连接到外部对象的边、命名接口、节点几何与自由路径均保留。选主容器可处理全图内部连接，选子组合只处理该范围。混合方式可明确统一，一次撤销恢复所有原选择；已统一到目标方式的按钮禁用，不产生额外修改。

实际阻塞仍由路由器检查，批量改成直线不会强行绕过方向或遮挡问题。已有已保存素材保持其原来几何；调整间距目前适用于新配方，已插入的手工布局可使用现有自动布局预览或手动调整，不因改线而重建配方。

## 助手调用

清单为 MLP 提供带标签的参数选项、默认值；有内部语义边的素材另提供 `internalEdges`，包含当前数量、已有方式和可选方式。请求示例：

```json
{
  "id": "network",
  "componentKey": "recipe:mlp",
  "parentId": "stage",
  "x": 100,
  "y": 170,
  "scale": 0.5,
  "parameters": {
    "inputs": 3, "hiddenLayers": 2, "hidden": 3, "outputs": 2,
    "layerGap": 104, "neuronGap": 40
  },
  "edgeRouting": "straight"
}
```

`edgeRouting` 是实例内部呈现设置，作用于源快照的副本，支持 `straight` / `orthogonal`。不提供则保留原方式；显式提供但源没有内部语义边会拒绝，避免声称已经修改自由路径。程序先按可用配方参数产生几何或读取保存快照，再设置内部方式、改显式标签、等比缩放并插入，最后绑定实例间连接。因此外部 `instanceLinks` 不会被内部设置覆盖。

保存素材可使用 `edgeRouting`，但仍不接受配方 `parameters`，避免重建用户手工结构。源资产、修订时间、来源及配方记录不修改；实例的实际边保存自己的方式，复用报告记录 `edgeRouting`，消息、历史和刷新后可见。模型候选仍需明确应用，可单步撤销。
