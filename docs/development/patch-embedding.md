# 原生图像分块与嵌入

第四十九批完成 `recipe:patch-embedding`。在“组件 → 参数化组合 → 图像分块与嵌入”配置，可插入当前容器或新建图件；助手检索、方案规划、实例编译与重建素材图谱共用同一配方。

## 表示与使用

依据 [ViT 原论文 §3.1 / 式 1](https://arxiv.org/html/2010.11929v2#S3.SS1) 核对关系，独立构造原生几何：图像分块按行展平，经同一个共享线性投影 E，再可选拼接可学习 CLS、加入可学习位置嵌入，输出编码器输入序列。CLS 不经过图像投影，位置嵌入在拼接后相加。

`z₀ = concat(x_class, X_p E) + E_pos`

该配方只表示编码器之前的流程，不包括注意力、Transformer 编码器或分类头。关闭 CLS 或位置嵌入会改变标题、公式、行数和符号形状，明确显示为变体。

每个图像分块、向量行、网格线、投影矩阵、拼接 / 相加算子与文字都可单独选择、编辑。向量 / 矩阵网格线绑定外框，移动外框时端点跟随。语义边引用原生对象，捕获、缩放与重插保留内部关系；保存后的组件使用手工快照，不按配方重新生成。

| 参数 | 选项 | 含义 |
| --- | --- | --- |
| `grid` | 2 / 3 / 4，默认 3 | 展示 2×2、3×3 或 4×4 个示意分块 |
| `classToken` | show / hide，默认 show | 是否拼接可学习 CLS |
| `position` | learned / none，默认 learned | 是否加入可学习位置嵌入 |
| `details` | show / hide，默认 show | 是否显示符号维度与公式 |

格数和向量单元都是示意，不推断真实像素、权重、H/W/P/C/N/D 或实验结果。`N=HW/P²` 假设 H、W 可被 P 整除，当前不表示补边或裁剪。示意说明始终显示，隐藏维度不会去掉它。

组件宽 940，按配置高 432–564，可在 1000×620 画布新建；放入已有容器时可以显式等比缩放，助手可用 `fit` 分配区域。`image-in` 是图像输入，`tokens-out` 是所选 CLS / 位置配置下的编码器输入序列，不是编码后的特征。接口及完整来源随捕获和 SVG 元数据保留。

为便于在 1920px 桌面核对复杂结构，组件详情 / 配置弹窗宽 1400px，预览区高 480px，右侧参数区宽 340px。没有增加其他宽度的布局分支。
