# 从图件采集可编辑素材

第五十六批接通“候选 / 工程 → 局部原生组件 → 待入库队列 → 本机素材库”。可以直接积累重绘结果中的结构，也可以拆出当前工程中的子图，不必先导出整张 SVG 再导入。

## 操作

1. 在左侧助手的候选详情点击“从候选图采集素材”；或在“组件 → 本机素材库”点击“从当前图件采集”。打开时冻结来源和候选当时的处理状态。
2. 在来源预览点击对象，Shift / Ctrl 多选；也可使用对象列表、名称 / ID 搜索、容器或描摹分区预设。选中容器会包含后代，命名接口跟随其所属容器。
3. 填写组件名称、检索说明、标签及可选补充引用，点击“准备采集预览”。检查实际原生结果、连线和文字提示；改选对象或修改信息后需要重新准备。
4. 点击“加入待入库队列”，可以继续准备其他片段。打开队列逐项核对并明确选择“将 N 项入库”。有连接受阻或文字适配提示的项默认不勾选。

采集、预览和入队都保留当前画布及候选的原状态。队列沿用[批量导入](component-batch-import.md)的冻结提交、回执核对和重试语义；收起或切换侧栏不丢失队列，刷新会清空尚未提交的页面队列。已入库组件可以直接插入、缩放、编辑或用于助手参考。

“导出采集组件”保存已经准备的完整组件 JSON。“导出来源快照”保存采集窗口冻结的规范工程 JSON，文件字节的 SHA-256 对应采集记录中的 FigureIR 指纹；包含工程内的便携参考预览，不包含浏览器原图缓存中的另存高清文件。

## 几何与数据边界

内部语义边随两端对象保留，按采集后的范围重新路由；跨到未选对象的语义边被排除并列出 ID。路径指向未选图元的端点先按原工程同步几何，再解除该端绑定；保留的端点仍跟随原生目标。采集不会凭空补齐外部结构。

跨容器选择会增加最少的透明样式层，保留颜色映射、继承样式、度量比例和祖先透明度，收紧空白。完整选中的可见容器仍保留原框；需要保留外部透明度时使用透明外层。容量、尺寸和层级沿用 FigureIR 契约，超限明确拒绝。

局部选择的样式层不携带旧容器的整图修复 / 原生复用记录，节点自身的图像证据和组件派生历史仍保留。完整容器可保留其内部记录。“描摹分区”预设只选择该分区及子分区中的描摹图元，原生复用组可以单独选择。

数据图表需要选取完整的图表容器，保留原始观测、缺失、统计口径、误差说明和示例标记；不把单独截取的柱、点或坐标轴发布为一份完整数据图表。

采集预览执行已有路由与文字检查，队列解析时再检查一次。提示可帮助发现明显的遮挡或容纳问题，最终仍需查看原生图形及其科学含义。

## 来源与身份

`ComponentSource.collection` 保存来源类型、工程标题、完整工程 SHA、选择 SHA、采集时间、请求对象 / 实际对象 ID、样式层、排除边、解除绑定及受阻边。候选来源另外保留运行 UUID 和采集当时的待审 / 已应用 / 已丢弃状态。节点原图区域保持；有明确已选对象区域时，汇总图像来源收紧为这些区域的覆盖范围，祖先上下文仍可作为引用保留。

选择 SHA 使用稳定字段顺序和对象 ID 排序。浏览器准备提交与服务入库都核对选择记录指纹；组件正文继续使用完整规范快照 SHA。来源引用中保存完整工程 / 选择 SHA，沿用现有库级关键词检索。服务校验的是内容一致性，不能仅凭客户端提交的采集记录独立认证原运行、作者或科学质量；需要对照时另存来源快照。

每次重新准备会创建新的组件 ID 和采集时间。当前不承诺跨次采集的视觉 / 语义去重，同一份已经入队的冻结内容可以按原回执重试。来源最多 12 条、派生最多 16 条；预算不足时拒绝，不截断证据。结构化采集记录占一条来源。

这一步提供素材积累入口。独立质量标签、受控排名、样本工厂与 RSI 版本晋升继续按开发目标推进，采集本身不自动更新这些环节。
