# 库素材辅助重建

第三十八批让原图描摹与原生素材复用进入同一个待审候选。该模式允许用库中匹配的结构近似原图局部，适用于方法图与架构图；它会保留源素材的结构，并明确披露与原图的差异。

## 操作

在参考图中准备整图或选区重建后，左侧助手可勾选“库素材辅助重建”，展开现有“参考组件”选择方式，自动检索或手动选择至多六项。默认关闭，每次准备新的重建任务都会关闭；未开启时仍逐图元描摹。开启但没有组件时，发送前要求选择或关闭选项。失败或取消后，点击“重新准备重建”只恢复要求与任务，再核对组件并明确发送，避免重试静默更换素材或退回描摹。第三十九批起会同时发送[实际组件图谱与结构目录](component-previews.md)，不再只依靠名称与简略节点清单。

也可以先点击“看图找重绘素材”，由模型分析真实裁片，再结合冻结目录筛选。找素材不生成图件；明确采用后，服务沿用原裁片与选定快照，再生成图谱并发送重绘。流程、两阶段耗时与边界见[看图寻找重绘素材](component-image-search.md)。

模型可返回零至六个匹配：组件清单 key、图片匹配框、理由、至少一条差异 / 待核对处，以及允许的配方参数与节点标签。找不到合适的结构时应不复用。匹配框使用本轮实际裁片像素，程序先转换回原图注册坐标，再按完整组件尺寸等比居中放置，不拉伸或重画内部结构。其余区域继续转为独立文字和路径；复用区域内不应再重复描摹内部对象。

候选叠加核对区逐项显示源素材、匹配区域、版本、理由与差异；所选组件属性也能回看。候选仍由人明确应用或丢弃。采用后可直接编辑原生对象、缩放、撤销和捕获入库。像素分区修复把素材内部对象作为只读上下文，修改科学结构应回到原生编辑流程。

## 编译与来源

`reuse` 是初建响应的独立数组，节点保持既有 Scene 协议。编译器使用本轮冻结组件快照，由现有组件展开器生成独立节点、命名接口与内部语义连接；源外观保持。只允许本轮清单中的 key，参数与节点别名仍由既有库契约校验。

区域须完整处于所选原图范围内；等比比例须在 0.1–4 内，组件之间不得重叠，最终工程继续受节点 / 容器 / 连接数量及几何限制。错误选择、非法参数、区域越界、重复 ID 或缺少差异说明时整轮拒绝，不写入画布。可复用素材包含数据图表时拒绝替换，必须使用原始数据选图。

复用容器保存 `reconstructionReuse`：源 key、素材 ID / 名称 / 版本、图片 SHA、归一化区域、理由和差异；另保留原生 `component` 来源与本轮图片证据。内层手工素材的原始证据保持，其布局来自 AI 草稿时在复用组记录 AI 来源，不把手工图元冒充图片生成物。完整图像规格仍由工程 `imageDrafts` 保存，捕获 / 插入 / 缩放 / 原生 SVG 元数据保留。

普通助手不能伪造或改写这份匹配记录，省略已有记录时程序恢复。插入当前容器时，复用报告使用实际移植后的实例 ID。分区修复不接受另附组件，只处理其原有可编辑描摹对象。

## 验证

在现有核心测试中增加三项场景：原生拓扑与等比几何 / 来源往返 / 只读修复；高清裁片坐标及移植后实例；非法替换的原子拒绝。现有服务文件增加一项双 CLI 子进程协议检查，核对发送后修改库不影响快照、候选保持待审及伪造 key 拒绝。总计 512 项核心 / 服务检查、Lint、类型与构建通过。

现有重建 UI 流程串联“草稿 → 指定库组件 → 初建 → 待审 / 应用 → 人工注释 → 分区修复 / 撤销”，核对原生组和 AI 来源保持；仍为五个 UI 文件、四条 1920×1080 流程。重建失败改为重新准备后，最终 Lint、类型 / 构建与四流程再次通过，最新用时 18.198 秒。夹具只证明操作与协议，不能证明视觉理解或科学匹配质量。

## 一次真实开发样例

复用第三十七批原生生成图片及完整内容规格，附带其原图裁片与唯一 `seed:tensor` 组件清单，真实 Codex CLI 0.165.0 调用一次，未重试、未重新生图。运行 `af3a7139-0dcc-4221-8fbe-684dfdd1ae9f`，233.685 秒完成待审候选：51 个描摹节点（含 17 条路径、7 个定位文字）和 1 个原生 tensor 节点。

模型仅在右侧 Embeddings 区域复用该组件，程序按 0.8072727273 比例等比展开；`Feature maps` 标签明确改为 `Embeddings`，源素材快照保持。候选和捕获组件保留原始图像规格，复用组保留 AI 图片证据与库来源。实际几何 / 指纹核对及图片查看已完成，没有用户画布应用或库晋升。

实际结果的库内张量是带网格符号的矩形表示，与源图五层橙色透视片存在明显外观差异；模型无法仅凭清单知道逐层渲染细节，报告没有声称精确复刻。匹配框、颜色 / 层数 / 标签布局差异与外部箭头未绑定原生端口均已披露。模型还保留原草稿的残差语义、内外数据流高度不一致与注释不足警告。科学含义和视觉效果仍需作者审阅。

文字报告为 0 项，但只检查了 1 个原生节点，7 个定位文字未进入换行检查，不能推广为整图文字适配通过。该样例验证混合编译链路，没有像素质量优势或独立论文效果结论。

完整输入、裁片、源组件、原始响应、候选 / SVG / PNG、捕获组件、编译源码指纹与几何核对记录保存在 `test-results/reconstruction-library-live-codex-v1/`。这是尚未附带图谱时的历史样例；后续图谱接入与验证单独记录，不把这一输出冒充带预览的实验结果。

## 当前边界

匹配理由与差异由模型提出，不是自动科学验收。程序不推断跨描摹曲线与原生命名接口的语义绑定，也不校验原图内部算法是否正确；需要作者核对端点与方法含义。匹配区域与描摹层可能有视觉重叠，最终仍须叠加审阅。数据图表不能借用其他素材中的观测或示例值来填图。

该功能使用手动选择或看图检索后采用的素材清单，尚无图片向量检索、自动库晋升或 RSI。PC 工作台继续只验收 1920×1080。
