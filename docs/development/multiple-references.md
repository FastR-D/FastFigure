# 多参考图输入、逐图用途与来源保留

2026-10-29，第廿八批。普通绘图和数据选图可同时附带工程中的三张参考图，逐张指定用途。模型逐图解释采用 / 舍弃的部分，历史可回看本轮图片输入快照，已采用来源随图件和组件保存。

## 使用

从“参考图”Tab 导入图片，或从顶会图库导入带来源的图片，再打开左侧助手的“多图与用途”。勾选各图并指定用途；既有“附带当前参考图”保留为当前图的快捷选择。选择按工程参考图顺序发送，切换当前查看图片不会悄悄改掉其他选择。切换素材 / 助手 Tab 保留本页的选择，刷新后需重新选择下一轮的附图；已完成轮次的输入和用途不受影响。

| 用途 | 可以借鉴 | 仍需核对 |
| --- | --- | --- |
| 样式 | 配色、字体、线条、留白 | 不把原图数值或科学结论当作新图内容 |
| 构图 | 分区、视觉层次、布局、连接方向 | 不因为布局相似而添加未声明模块或关系 |
| 结构语义 | 分析结构与标注 | 科学含义以用户目标为准，不能推断未提供的结构细节 |

数据选图只允许样式 / 构图，数值、误差和分组来自固定数据附件。若先选了结构语义图再导入数据，须明确调整用途；客户端在发起请求前拦截，服务端也校验。不静默改用途、不抄图片中的实验值。

本轮报告显示每张图的用途、模型观察、采用位置 / 不采用原因及不确定性。说明来自模型，不是自动视觉质量验收。缺少图片时不得声称看过本轮图片；不适合的参考可以明确舍弃。

“查看本轮参考图”读取运行快照，并检查实际字节指纹、解码和像素尺寸。当前工程删图、换图后，仍可回看尚未清理的旧轮次输入；指纹不符、解码失败或运行已清理时停止显示，不回退成另一张当前图片。该快照表示为本轮准备并交给适配器的图片载荷，不证明模型已消费或理解全部像素。

普通多图使用工程内的压缩预览，不会自动从 IndexedDB 取三张完整原件。原图指纹和实际输入指纹分别保留；普通导入可能是原文件 PNG / JPEG，经浏览器压缩为 WebP 后发送。结构重建仍有独立的原图裁片流程。

## 协议与输入顺序

普通请求可用：

```json
{
  "referenceInputs": [
    {"id": "ref-layout", "purpose": "layout"},
    {"id": "ref-style", "purpose": "style"},
    {"id": "ref-structure", "purpose": "content"}
  ]
}
```

数组最多 3 项，ID 必须在本轮工程中，不能重复。请求数组顺序就是图片顺序，目录 index 从 1 开始；UI 按工程顺序生成数组。单张 `referenceId` 入口默认用于样式，两种入口不能同时指定，包括空数组与单张入口同时出现。

程序生成 `referenceInputs` 目录：index、ID、标题、用途、引用、文件名、原文件指纹、输入尺寸，以及服务端计算的实际输入 SHA-256。目录不含 data URL。Codex 的 localImage 列表与 Claude 的 image 列表均按同一顺序提供，临时文件以图号命名。

模型在普通绘图 / 选图 JSON 的顶层另返回：

```json
{
  "referenceNotes": [
    {"image": 1, "decision": "use", "observation": "可见的相关特征", "application": "借鉴到哪里", "uncertainty": "仍需核对之处"}
  ]
}
```

实际附带几张就必须恰好解释几项，包括 `omit` 的参考；图号不能遗漏、重复或超出目录。模型不能返回 / 改写源 ID、指纹或用途。解释经校验后与可信目录合并为 `referenceUse`，进入 SSE、轮次、历史和选图报告。无附图时省略或返回空数组。漏说明或编造别名会拒绝整轮候选，已有候选和画布保持。

每轮最多 3 图仍受既有工程总预览 1,200,000 字符、单张 600,000 字符及请求 2 MB 限制；不会为发送成功而丢图。声明不支持图片的适配器在调用前拒绝，不静默发送纯文字。

重建 / 修复使用任务固定来源和原始 / 预览裁片，不接受额外普通多参考图；双图视觉审阅继续使用对齐的原图 / 候选输入，未改为任意图片比较。

## 图件与素材来源

图件的 `referenceUses` 由程序维护，只保存已采用记录。改已有图会保留旧来源，并按原文件指纹＋用途合并新记录；同源不同用途分别保留，最多 12 条。右侧属性可明确移除记录，并可撤销。模型返回的图体不能伪造或抹除这些记录。数据选图生成完整新图，只记录本次采用的来源，不把被替换的旧图来源混入新图。

保存组件时，已采用记录转入带图像指纹和 `purpose` 的来源；捕获 / 缩放 / 重插、工程 JSON、FastFigure SVG 元数据往返保持。不同用途不会被来源去重误合并。已有组件来源和区域证据保持在先，新全图参考追加在后；原图长标题和引用保留，未采用图仍留在本轮说明中，进入素材来源的只有已采用图。

这些是全图参考记录，捕获子树也保留相关上级背景来源，不宣称已定位到每个图元；图元级证据仍使用已有 evidence 区域。组件不携带整张参考位图，保留来源记录；历史图片依赖本地服务尚未清理的运行，重启服务不会恢复运行。当前没有长期图片服务、独立风格方案资产或自动多参考检索。
