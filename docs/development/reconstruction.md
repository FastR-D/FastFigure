# 参考图结构重建与分区修复

2026-10-29。将参考图片经本地 Harness 转成可编辑文字、形状和曲线，再按语义分区提交修复补丁。用户审阅后应用，保持 PC 工作台、左侧助手、单应用和 pnpm。

## 操作流程

1. 在“参考图”导入 PNG / JPEG / WebP，选择“生成新图件候选”或“插入当前容器候选”，再点击“重建整张参考图”或“重建框选区域”。新图件会替换画布，当前容器模式保留已有工程。
2. 左侧助手固定本轮来源图片和范围，显示任务类型及目标位置。可以修改要求，发送时才调用模型。“返回自由绘图”退出重建模式。
3. 候选图提供本轮实际输入裁片与原生结果的对齐叠加，透明度从 0 到 100%；可核对文字、曲线、边界及遗漏。读取或解码失败时明确回退工程参考图，并可重试；警告随重建组保存，通用改动清单和生成前 / 后预览同时保留。
4. 应用为一个撤销步骤。生成或审阅期间画布有变化时，阻止应用旧结果。取消、丢弃、无效 JSON、几何或补丁错误均不写入工程。
5. 选中重建组，在右侧“原图分区修复”选择区域、查看原图范围，再交给助手。模型只返回该区操作，其他分区和手工新增对象作为只读上下文。每轮修复仍先审阅。
6. 可编辑重建图元、整体缩放、移动、布局、存入“我的组件”并重插。组件只保存来源指纹和区域，不复制参考图二进制；新建图件重插后需重新导入对应原图才能继续修复。

## 局部原图输入

导入参考图时，在工程中保留既有压缩预览，同时尝试将原文件存入浏览器 IndexedDB。原图缓存独立于工程文件，按原文件 SHA-256 去重，限制 24 张 / 96 MB，并按最近使用情况清理；单文件仍遵守 12 MB / 2400 万像素。浏览器拒绝存储、配额不足或缓存损坏时，不阻止预览导入及重建。

发送重建或分区修复前，程序按本轮范围生成实际位图裁片：优先读取本地原图，缺失时从工程预览裁取。裁片最长边不超过 2000，数据 URL 不超过 600,000 字符，必要时降低编码质量与分辨率。不会把低清预览放大后宣称为高清原图。参考图面板显示缓存状态，可清除此图缓存，或选择相同原文件补充；补充时核对指纹，工程和画布不变。工程 JSON 不包含这份缓存，跨浏览器或清理网站数据后可补充原文件，也可继续用预览裁片。

本轮 `inputImage` 包含裁片位图、实际宽高、源图坐标范围、原文件指纹和 original / preview 来源类型；消息和历史只保留元数据，不重复存储图片字节。发送前准备图片期间锁定助手提交；画布若已变化则不启动基于旧图的运行。服务端在启动 CLI 前检查来源和区域是否与任务一致，并检查 PNG / WebP 图片头的尺寸；完整图片的解码由浏览器导入与裁取阶段完成。

模型收到的就是裁片，所有输出坐标都使用裁片的实际像素。初次 Scene 的 canvas 等于裁片尺寸，由程序映射回参考图坐标；修复目录、只读上下文、排除区和核心范围先换算为裁片坐标，返回 patch 后再反向转换，随后执行既有版本 / 归属 / 完整工程校验。源图坐标和 FigureIR 来源记录保持原约定。文字基点、字形矩阵、旋转几何和贝塞尔路径随坐标换算；非等比栅格取整造成的描边比例差采用几何平均值近似，仍需视觉核对。

## 数据与范围约束

初次重建返回 `{message,warnings,scene}`；无法识别时 `scene=null`。Scene 的 canvas 必须等于所附压缩图片的像素尺寸，nodes 按背景到前景排序，regions 表示可嵌套的语义分区。仅接受 rect / ellipse / text / line / path / polyline，文字每行独立，颜色限十六进制或 none；不允许图片、脚本、外部引用或任意标签。支持字体、数值字重、字距、旋转、圆角、贝塞尔曲线、透明度、虚线和箭头。

参考图片沿用既有 12 MB 原图、压缩后最长边 2,000 像素、每个工程至多 3 张的约束。识别区域至少 3×3 像素；最多 24 个语义分区、240 个图元、单路径 128 个锚点、全图 4,096 个路径锚点与控制点。图元真实字号与描边继续遵守 FigureIR 限制；超限时明确失败，不为通过校验而丢弃复杂细节。

重建组记录来源 SHA-256、压缩图片尺寸、归一化选区、源图到画布的原点与比例、分区和修订号。图元记录源对象 ID、归属和版本，并附各自证据区域。移动、缩放、容器布局、采集和重插都更新坐标注册。修复目录从当前可编辑图元实时反推，而非使用过期识别快照；不支持继续反推的人工结构转换会成为只读对象。

修复返回 `{message,patch:{operations}}`，支持 add / update / delete / split / merge。目录采用相对于分区裁片原点的局部坐标，附只读上下文、核心范围、排除区与对象版本。父区剩余部分、未覆盖区和大区细节可单独检查。越权更新、删除、过期版本、无效路径或最终 FigureIR 校验失败时整轮不应用；上游可忽略的重复 / 范围外新增会显示数量。没有有效变化时不产生候选图。

同源更新沿用已有原生 ID、未修改对象、手工对象、端口和外部连接，保留绘制顺序；省略的可选文字 / 形状样式从现状继承。明确修改粗体或数值字重时同步其实际绘制值。删除或合并若导致外部连接悬空，由最终完整工程校验拒绝。候选应用前还检查整个工程基准，防止把基于旧图的补丁应用到新图。

## 当前边界与后续

- VLM 已接收实际局部裁片，可从本地原图读取更高分辨率；没有原图时明确使用预览裁片。单裁片仍受 2000 像素与请求预算限制，尚无自动多尺度分块调度。
- 自动校验检查数据结构、几何、归属与引用，不能证明方法正确、视觉一致或文字无误；已有六类自制 CS 图的离线分项评测，尚无代表真实论文的独立大样本集、在线自动质量门、自动重试或预算驱动修复循环。评测与命令见 [CS 评测集](../../benchmarks/cs-figures-v1/README.md)。
- 图片、渐变、滤镜和照片区域当前不能原样矢量表达；模型应明确列出未重建部分，不得用文字框冒充。普通曲线和箭头是可编辑路径，尚不自动推断连接到算子的语义关系。
- 图像草稿与规格来源已接入，见[图像草稿](image-drafts.md)；初建可明确开启库素材辅助，见[混合重建](reconstruction-library.md)。尚无云端素材同步、自动质量晋升或 RSI，仍需扩大独立样本与质量评测。
