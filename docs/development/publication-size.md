# 论文尺寸与可读性

画布工具栏的尺子按钮和导出弹窗进入“论文尺寸与可读性”。工作台仍固定为 1920px；这里的宽度是整张图放入论文时的毫米数，与窗口适配无关。

可以选择 IEEE 单栏 88.9mm、双栏 182mm 或自定义 20–420mm。两项尺寸来自 [IEEE 期刊作者指南](https://journals.ieeeauthorcenter.ieee.org/create-your-ieee-journal-article/create-graphics-for-your-article/resolution-and-size/)；默认 9pt 文字参考其[会议图件建议的约 9–10pt](https://conferences.ieeeauthorcenter.ieee.org/write-your-paper/improve-your-graphics/)。它们是可修改参考，不能代替目标刊会要求。0.25pt 描边为工具默认参考，并非引用的统一投稿标准。

预览按 CSS 96dpi 换算，提供 100% / 200% 查看；显示器像素与缩放未经物理校准。200% 只放大预览。宽度按完整 1000×620 画布计算，保留其中的空白，不自动裁切或调整图元。工程标题开关只影响自动显示的工程名，容器、坐标轴和子图文字保持。

应用前只预览；应用将 `publication` 设置写入工程，支持单步撤销、重做、保存和恢复。移除设置恢复无物理尺寸配置的输出。图元、原始数据、配方参数、连接、手工内容与来源不因尺寸设置而改变。

## 检查与输出

检查直接遍历实际 SVG 场景，组合父子变换和透明度，汇总节点标签、注释、内部结构文字、容器标题和语义连接。普通文字的换算为：

`最终 pt = SVG 字号 × 有效变换缩放 × widthMm / 1000 × 72 / 25.4`

原生组件缩放与导入的文字 / 描边矩阵均参与计算，避免把已经记录的缩放字号再乘一次。等比变换得到确定大小；非等比和斜切以矩阵最小 / 最大奇异值给出等效范围。描边用保守下界提示“可能存在细线”，并不声称所有方向的线宽相同。

完全透明、无填充的文字与无描边路径不计入；定义、裁剪定义和箭头标记不当作图元重复计算。同一对象字段的多行文字合并，复杂轮廓的描边按对象合并。详细清单至多 80 项，文字优先，省略数及完整统计保留；可从列出的项回到画布定位。检查没有分析遮挡 / 裁剪的实际覆盖、真实字形、字体是否嵌入、填充细条、箭头标记和科学内容。行数省略继续由独立的原生文字检查报告。

设置后，SVG 使用毫米 `width/height`，保留 `viewBox` 和全部原生坐标。例如 182mm 输出为 182×112.84mm；工程 JSON 和 SVG 元数据保留配置。draw.io 保持其原来的尺寸规则。SVG 是可编辑的交付中间格式，投稿输出按目标刊会的格式要求处理；未接入 PPTX 或 PDF 导出。

检查报告导出为 `fastfigure.publication-check` JSON，包含设置、报告、时间和源 FigureIR 的规范化 SHA-256，不携带整张工程或图片。点击时先冻结源和设置再异步计算，散列不是任意缩进 JSON 文件的原始字节散列。允许导出尚未应用的预览配置，因此报告设置可能与源工程中的已保存设置不同。

## 助手与素材

普通绘图上下文包含人设定的目标和程序检查摘要；规划、数据选图与重建提示也带目标尺寸。候选原生图会重新计算并显示报告。模型响应不能更改或删除人的配置；普通底图、组合参数更新、数据选图和新图重建沿用原设置。

助手可以据此建议减少无效留白、增大文字 / 描边或拆分图件，不能以改宽度、降阈值、删原文或改观测消除提示。尺寸检查本身不自动修复；原生数据图可通过[字体 / 字号配置](chart-typography.md)重算文字空间，仍未建立出版质量自动接受规则。采集组件及用组件新建工程时不继承原整图的出版尺寸，避免素材把另一张论文图的上下文带入新工程。

## 验证

在既有文字检查文件增加两个风险场景，覆盖缩放与仿射换算、透明父级、物理 SVG、标题、资产边界以及异步导出的冻结散列；原上下文场景核对程序报告和模型伪造尺寸被忽略。既有编辑 UI 流程增加一次设置预览 / 应用和 SVG 实际尺寸核对，没有增加测试文件或逐按钮脚本。

525 项核心 / 服务检查、Lint、类型与构建通过；仍为 40 个核心文件、5 个 UI 文件、4 条 1920×1080 流程。本次最终 UI 34.576 秒通过，耗时只代表本机样例。开发时修正了尺寸弹窗事件表达式的编译错误；最终结果见 `test-results/ui/results.json`。

另在私有端口、浏览器和临时素材目录中复核第五十八批原有的真实模型候选，212 个原生图元；没有再次调用模型，没有改用户打开的工程或源文件。证据在 `test-results/publication-check-v1/`：

| 整图宽度 | 最小等效字号 | 最小描边下界 | 小文字字段 | 可能含细线的对象 |
| --- | --- | --- | --- | --- |
| 88.9mm | 1.33693pt | 0.08510pt | 117 | 225 |
| 182mm | 2.73701pt | 0.17423pt | 117 | 184 |

两种输出均统计到 117 项文字和 230 个描边对象。独立读取导出 SVG 的浏览器 `getScreenCTM` 与计算样式，核对总数、最小字号 / 描边，并比较报告列出的文字变换范围；最大偏差 0.000085pt，小于允许的 0.002pt 屏幕像素取整误差。不是独立论文质量或实际印刷评测。
