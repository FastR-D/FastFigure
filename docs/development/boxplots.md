## 操作

在“组件 → 实验图表”或左侧助手点“导入数据，让助手选图”，粘贴 CSV / TSV 或导入文件，检查列类型与缺失，再选择“数值含义 → 逐次原始观测”。程序记录的是使用者声明，不能从 Run / Seed 表头验证样本独立性。修改附件表格或换文件会清除原声明，需要重新确认。

附给助手后说明希望表达的问题，例如“比较三个方法重复实验的结果分布与稳定性，同时保留偏离主体的观测”。可附参考图借鉴配色、字体与留白；图片内的实验值和误差解释不进入本次数据。助手返回选型理由、备选、局限、字段映射及未绘制列，程序按固定源列生成待审阅候选。

## 固定统计与几何规则

- 四分位数采用 type 7 线性插值：私有排序后的有效样本为 `a[0..n-1]`，`h=(n-1)p`，在 `floor(h)` 与相邻样本间线性插值，分别取 `p=.25/.5/.75`。原始数组及顺序不变。该定义对应 [R quantile 的 type 7](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/quantile.html) 和 [NumPy quantile 的 linear 方法](https://numpy.org/doc/stable/reference/generated/numpy.quantile.html)。不声称与 R boxplot 默认 hinges 相同。
- `IQR=Q3-Q1`；须线取 `[Q1-1.5 IQR, Q3+1.5 IQR]` 内最远的真实观测，边界相等算在内，不把围栏数值直接画成须线。范围外观测逐个保留，规则参考 [Matplotlib boxplot](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.boxplot.html)。离群标记不代表数据错误。
- 空值不补零，不计入 n；每组同时报告有效 n、缺失数、Q1 / 中位数 / Q3、上下须及离群数。图内保留统计规则说明与示例身份；完整摘要可在编辑器和助手报告展开查看。
- 原始点只做固定的横向错位，纵坐标直接编码原值；组名与 Run 标识相同，行重排后错位不变。`showSamples=false` 只隐藏非离群原始点叠加，全部离群点仍显示。所有输入仍保存。
- Q1=Q3 时，箱体为真实位置的水平线；不人为增加高度。中位数和须线可重合，原始点仍保留。纵轴覆盖所有原始观测，包含离群点；自定义边界若截断则拒绝整轮。

不从均值、SD / SE / CI、误差棒、分位数或图片重建样本；不计算置信区间、缺口、显著性或因果关系。原始观测声明不等于实验设计或统计有效性验证，单位与分组含义仍需人核对。

## 数据与工具边界

每图 1–6 组、2–80 行，每组至少 2 个非空样本。总图元上限 240，叠加密集原始点可能先达到上限；明确要求关闭叠加或调整输入，不自动截断、抽样或删离群点。另受既有文字长度和布局容量限制。

附件 `sampleMeaning` 可为 `raw-observations`、`summaries` 或未声明。未明确声明原始样本时，模型应返回 `needs-input`；若仍试图生成箱线图，程序拒绝。模型只能选择列、图型与允许的样式字段，不能提供样本、统计结果或改变声明。

`container.dataChart.spec` 中 `kind=boxplot`、`xMode=category`；`x` 保存逐行样本标识，`series` 保存分组列和原始值。固定 `boxplot={sampleMeaning:'raw-observations',quartiles:'linear-type7',whiskers:'1.5-iqr'}`；`showSamples` 控制点叠加，`showValues` 控制中位数标签。箱线不接受误差列、非空误差说明、点标注或热图色标字段。

已保存箱线图的 `chartOptions` 只允许保持 `kind=boxplot`，调整标题、轴标题 / 范围、配色、网格、原始点叠加与中位数标签。不能直接与其他图型互转或修改统计规则。原始输入、样本标识、声明、来源、示例身份和另加对象保持。推荐报告和重绘记录中的 `boxplot` 摘要均由程序计算，进入消息与历史。

样本图元按组名与唯一样本标识匹配，箱体 / 中位数 / 须线 / 组名按组名匹配。重排保留身份；隐藏或删除仍有外部连接的点，以及把已连接箱体变为水平路径，均原子拒绝。工程、捕获 / 重插、等比缩放与 FastFigure SVG 元数据往返保留数据和规则。

现有 FigureForge 静态模板仍为 18 个；本批是原始数据编译器，没有从那些示例 SVG 的箱体几何反推样本。
