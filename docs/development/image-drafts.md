# 图像草稿与可编辑重建

第三十七批接通了“内容规格 → 平台图像草稿 → 人工核对 → 原生重建候选 → 可复用组件”的链路。草稿是视觉设计参考，其科学含义仍须核对；数值图表继续由导入的数据生成。

## 绘图方案生成草稿（2026-10-31）

助手返回已明确分区和主次的可采用方案后，点击“用此方案准备图像草稿”，会打开参考图侧栏的 AI 图像草稿表单。该操作只准备表单，不调用模型或修改画布；检查后点击“生成一张草稿”才提交。已应用方案和草稿来源中保存的方案也能复用。待补充方案和缺少明确版面的旧方案需先重新规划。

方案路径沿用原始要求、目标、分区比例、主次、结构理由、图示说明、组件实例及参数、色槽映射、连接类型和方向、注释、参考观察与不确定项。编译器不额外生成面板或模块，不再次调用模型。frame 映射到所选方向的归一化内容区；组件清单只记录实例、名称和参数，未传入其实际图元外观，提示明确禁止从名称猜测未知内部结构。

视觉丰富度来自内容本身的轮廓、图示、层次、语义配色和必要局部细节，不设置固定面板数或填充率。数据流、反馈、参数迁移和局部对应分别解释；无数据时不加统计图，不用虚构模块、反馈或数值填空。完成前要求模型对照规格自查，这属于生成指令，不能证明图片已通过科学正确性审阅。

表单固定方案内容、风格和参考用途，可调整画幅、名称与视觉要求。需要修改科学内容或另选风格时先清除方案，或重新规划。仅传入方案采用的图片，并将原规划图号重映射到本轮实际图号；被舍弃的图不发送。提交前检查来源、尺寸、用途及顺序，规划记录带实际输入指纹时还核对图片字节；丢失或变化时拒绝，不静默换图。过长提示在调用模型前拒绝，不截断科学内容。新建或导入工程会清除尚未提交的方案选择。

实际生成提示与完整方案快照保存在草稿来源，可在“本次草稿的绘图方案”中回看，随草稿包、工程、重建图件、组件采集和原生 SVG 保留。程序验证输入一致性及来源往返，未对生成位图做自动模块识别或科学关系判定。当前仍是一轮一张图，显式审阅和重建。

验证沿用图像草稿服务与助手 UI 流程：覆盖图号重映射、参数及关系完整编译、冻结来源、过长提示和来源漂移拒绝，以及生成／保存／重建往返。协议夹具不能作为真实生图质量提升证据；独立视觉对照评测仍需另行开展。

本轮最终验证：611 项核心／服务检查、Lint、类型与生产构建全部通过；1920×1080 四条 UI 流程通过，实测 63.336 秒，结果在 `test-results/ui/results.json`，已查看助手结束截图。全量检查发现的组合参数更新字号截断也已修复：文字格式逐属性保留，未手改字号跟随新比例，明确手改的字号保持。

## 使用

1. 左侧“参考图”切换“AI 图像草稿”，填写名称、内容规格和视觉要求，选择当前或保存的风格、横纵方向及运行时限。
2. 可选至多三张参考图，逐张声明样式、构图或结构用途，再点击“生成一张草稿”。使用本机已登录的 Codex，不增加 API Key 配置。
3. 查看大图及生成规格。可以下载原图，或导出 `fastfigure.image-draft` 草稿包，包含原始图片字节与完整生成记录。
4. “导入参考”只增加参考图片及其来源；“重建草稿”导入后准备助手要求。仍须在左侧助手明确发送，随后审阅候选并应用。图片生成成功不会自动重建或覆盖画布。
5. 候选应用后可编辑独立形状、路径和文字，捕获容器存入“我的组件”。完整规格及 AI 来源随工程、组件和原生 SVG 元数据保留。

导出的草稿包可在“导入与重绘 → 导入已保存的 AI 草稿包”恢复，导入时核对原始字节 SHA-256 及尺寸。普通工程保存压缩预览，浏览器另存原图缓存；草稿包保留原图，适合跨工程转移。包内不包含历史参考图片的原文件，仅保留其输入目录与指纹。

## 原生图像协议

实现参考 FastPPT 的原生 Codex 图像路径，并核对本机 CLI 0.165.0 生成的实验协议。独立适配器启用 `image_generation`，接收 `imageGeneration` 项的内联结果或原生保存路径。仅有不可读取的文件标识时明确失败，不声称已有图片。

每轮创建独立临时目录、复制已选择的实际图片，冻结提交提示与风格。Shell、其他执行工具、沙箱网络访问和会话续接关闭；工作区写权限限本轮临时目录，平台图像服务仍通过 Codex 登录调用。首张图完成即停止适配器，不自动生成变体或重试。重复提交相同请求标识及内容返回同一运行，更换内容则拒绝；此约束在本地服务生命周期内有效。

`model` 表示请求的文本模型，不代表图像模型版本。只有原生结果实际报告时才记录 `imageModel`。当前真实运行未报告具体图像模型版本，界面显示“平台未报告具体版本”。同样，图像引擎返回参考图片路径及实际字节指纹后才标记核对：

| 状态 | 含义 |
| --- | --- |
| `verified` | 实际回执涵盖本轮全部参考图 |
| `partial` | 有回执，但只涵盖部分参考图 |
| `unreported` | 平台未返回实际输入目录，不能断言图像引擎直接读取了参考图 |

目录同时保留源原图 SHA 和本轮传输图片字节 SHA，压缩后的输入不冒充原文件。回执出现清单之外图片或指纹不符时拒绝结果。

## 来源与容量

`imageDrafts` 在工程根部保存至多八份完整记录：原始内容、视觉要求、风格快照、实际提交提示、平台修订提示、方向要求、输出实际尺寸、运行时间、CLI 版本、来源目录与指纹。节点、参考图和组件来源只保存紧凑的运行 ID / SHA / AI 标记，避免每个图元重复嵌入完整提示。

合并素材时不允许同一运行 ID 改写完整记录；候选编译保留已有记录，检查 AI 证据来源。删除完整记录仍保留图元上的 AI 标记，缺原规格时重建提示要求补充。已知来源的原图重新导入会恢复 AI 标记。数据选型使用草稿作为样式参考时，也保留原始规格，数值仍取自原表。

本地运行记录随同一服务的页面刷新恢复，服务重启后不恢复。最多保留 20 条运行记录、12 张输出图片及 96 MB 图片缓存；过期图片显示不可用。单张输出原文件不超过 12 MB、8192 边长及 2400 万像素；导入草稿包不超过 17 MB。普通参考图仍最多三张。取消与超时会请求停止，不据此推断提供方已停止全部工作或费用；目前没有金额预算或计费回执。
