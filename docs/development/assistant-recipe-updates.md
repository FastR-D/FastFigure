# 助手调整已有组合参数

第五十八批把原生组合参数编辑接入左侧助手。模型根据当前工程中的组合、参数能力和要求提出修改，程序重绘后生成待审候选；当前图件保持，点击“应用候选图”后才更新。

## 使用

1. 在左侧“助手 → 本轮任务”选择“调整已有组合参数”。“可调整的画布组合”列出名称、当前参数、修订和与选中对象的关系，可以定位组合。
2. 描述目标组合及要改的格数、层数、分支、间隔或方向，说明保持原外框还是原绘制比例。此任务不附带参考组件，不访问本机库召回；已有素材选择偏好仍保留给其他任务。
3. 发送后查看逐组合报告：实际参数前后值、修订、比例、保留 ID、新增 / 移除和组内另加对象数量。助手理由单独标明，图元数量和实际参数由程序计算。
4. 对照生成前与候选结果，再明确应用或丢弃。参数值和绘制比例都未变化时保留报告，按无变更处理，不因相同配置重新生成所有图元。应用 / 撤销、过期候选阻断、历史恢复沿用现有流程。

先清除当前数据 / 重建或已采用方案，再切换本轮任务；切换入口会清理相冲突的未发送状态及风格附件。参考图片可以沿用现有逐图说明协议；本批真实例未附图。没有参数化对应记录的图件可先从六种内置配方插入，完整采集入库再插入的组合也可继续使用。

## 模型与程序边界

上下文增加 `recipeUpdateTargets`：原工程中的唯一组合 ID、名称、当前参数、可选字段 / 选项、接口、修订、尺寸与相关选区。完整图元对应表留在程序中，不在模型上下文里重复展开；原节点几何仍可作为当前图件查看。

响应格式为：

```json
{
  "message": "简洁说明",
  "figure": null,
  "recipeUpdates": [
    {
      "containerId": "原工程中的组合ID",
      "parameters": { "layers": 7 },
      "layout": "frame",
      "keepEdits": true,
      "reason": "根据要求说明修改理由"
    }
  ]
}
```

`parameters` 是补丁，未提供的值保持；字段和值必须属于目标配方。`frame` 固定原外框、内部等比适配，`scale` 保持原绘制比例并按内容调整外框。`keepEdits` 默认开启，作用于内部生成对象的改字 / 外观；外框名称、外观与初始来源保持。已有手工公式和说明应对照新参数查看。

每轮最多 12 个不同组合，按声明顺序在源工程副本中重绘。某项失败时整批拒绝，不发布前项的部分结果。未知 / 重复 ID、非法参数、模型自报图元数量等额外字段均拒绝。已有连接 / 对应、空间和容量边界沿用[原生参数编辑器](recipe-parameters.md)。参数任务不接受完整底图、新实例、实例间连线、引线附着或已采用方案；需要补充信息时可返回 `figure:null` 和空更新数组。

普通绘图也可以提出参数更新，但该次响应仍须单独使用 `recipeUpdates`。普通底图编辑缺省的 `parametric` 记录由程序恢复，不能伪造 / 修改对应表。助手生成新的配方实例继续使用 `instances.parameters`，两种入口分别服务已有组合和新实例。

## 报告、保存与回看

`recipeUpdates` 报告进入完成事件和会话历史。每项包含请求理由、规范参数前后值、中文字段 / 选项、修订、比例以及程序重绘结果。刷新或打开旧轮次会恢复报告；已有候选仍按原应用 / 丢弃状态显示。

候选的当前参数与对应关系跟随 FigureIR、SVG 元数据和完整组件采集保存，原库快照及来源配置保持。此操作不发布素材或形成质量标签，素材积累仍通过[采集预览和明确入库](component-capture.md)。
