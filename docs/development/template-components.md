筛选前渲染并查看全部源页。基础矩形、圆形、算子、特征体、投影及已覆盖的常见关系结构沿用现有组件，避免重复增加入口。模板中的论文图片、引用段落、年份和实验内容不作为默认事实复制。新增组件是依据模板视觉结构重新构建的通用示意，不是原图复现，也不是通用 PPTX 导入能力。

实现集中在 `src/data/templateComponents.ts`，来源名称、页码、原文件指纹保存在组件来源及根组合证据中。组件接入界面和 `createCatalogue`，支持助手默认检索、冻结目录与原生实例编译。ID 使用 `paper-template-` 前缀，遵循已有内置论文图示规则，不挤占个人组件的最近使用回退位置。源 PPTX 无需复制到仓库或随应用分发。

原生路径使用端点绑定；收放轮廓使用闭合路径的显式几何锚点，重新插入时由现有组件机制重映射。阶段、重复块、细节区各自保留子组合。环形分区、时间轴和路线图的尺寸不编码真实数量或时长；特征条带不声明真实张量维度。缺失模态组件只表示缺失位置，不提供补全算法。

验证覆盖十项组件的文字容纳、原生 SVG 往返、缩放、双份插入的端点隔离、再采集与来源保留，以及默认目录中的中英文检索。独立浏览器流程逐项执行搜索、查看来源、100% 新建图件插入和撤销，并核对全部／模型／论文结构三种筛选结果。视觉预览和该轮记录位于忽略目录 `test-results/template-components/`；测试使用独立临时素材库，不读写用户的本机库。
