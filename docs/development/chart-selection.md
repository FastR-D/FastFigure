# 从人导入的数据选择可视化形式

当前推荐及每个多视图子图也可选择 `fontFamily/fontSize`，由程序重新排版并报告实际基准设置，见[统一字体 / 字号](chart-typography.md)。以下历史验证中的字段与用时不代表当前契约的全部能力。

2026-10-29，第廿三批。先让人导入原始表，助手结合研究问题、数据列概况和可选的参考图片选择可视化形式，再由程序按所选字段读取原数据生成可编辑候选。这个入口不要求先配置某种图型。

第廿四批增加矩阵热图、独立数值色阶与实际色标报告，详细约束和新验证见 [热图](heatmaps.md)。

第廿五批增加原始样本箱线图。附件可声明原始观测 / 已汇总统计量；模型不能代替人确认原始样本，统计由程序按固定规则计算。见 [箱线图](boxplots.md)。

第廿六批增加 [线性 / log10 坐标选型](chart-axes.md)。模型可根据跨数量级 / 倍数比较目标选择坐标，程序检查原始数值与误差端点，报告实际刻度类型和范围。

[可审阅长表展开](chart-preparation.md)支持助手或人选择 1–3 列复合行键、1–3 列复合组键、单指标与可选配对误差半宽；程序保留所有源记录并提供预览，明确采用后才继续选图，图表保存来源绑定。

第廿八批支持 [多参考图](multiple-references.md)，数据选型只允许样式 / 构图用途；每张图都有程序目录与模型采用说明，图中数值和分组不能替代原始表。

第卅二批增加导入时的“图要回答什么问题？”，目标随固定数据附件进入助手、列概况和推荐报告。本轮明确修改目标时优先本轮要求；含义不足时先提问。真实 Codex 自制数据验证在未指定图型时选择散点，保留重复值 / 缺失 / SE 与模型名，记录见[表达目标与方案](composition-plans.md)。

第五十三批增加[同一附件的多视图选型](chart-multi-view.md)，适合多个互补问题或不同单位的指标；逐图保留行、字段与误差归属，程序生成可编辑的组合候选。

## 使用

1. 在“组件 → 实验图表”或左侧助手底部点“导入数据，让助手选图”。粘贴 CSV / TSV 或导入文件，查看列类型、缺失数、不同值数量和前五行。
2. 填写数据名称、图要回答的问题、来源、图下注释、数据身份和数值含义。表达目标可选填最多 2,000 字，导入后进入助手草稿和报告；无需先选图型。分布图需要明确声明逐次原始观测；更换附件数据后需重新确认。若已有误差半宽，填写 Mean ± SD / SE / CI 等明确含义。程序不会根据列名推断统计口径。
3. 点“附到左侧助手”，再说明图要回答的问题，例如“表达各模型延迟与准确率的关系”。需要参考样式时，先从工作台导入参考图，在助手中勾选附带。
4. 助手返回推荐形式、理由、备选、字段映射、未绘制的列和待核对事项。支持编译的结果附带原生候选；查看数据与图形后再应用。

候选为新图件，应用会替换当前工程的图形、保留参考图，并形成一次可撤销操作。运行本身不改画布，画布变化后阻止应用旧结果。附图分析的是构图和样式，不用图片内的数值替代导入表。

数据附件随当前页面保留，切换左侧 Tab 不会丢失；可编辑或移除。刷新后原始附件需重新导入，当前本地服务中的推荐记录与候选仍可恢复。已应用图件保存所选 X、系列、误差、数据行标注、来源和声明，支持数据编辑器及工程 / 组件 / SVG 元数据往返；未绘制的原始列暂未作为持久素材服务保存。服务重启不恢复内存会话。

## 输入与选择

数据为带表头的 CSV / TSV 表：2–12 列、2–480 行，文件不超过 60 KB，文本不超过 20,000 字符、原始规范化数据不超过 24,000 字符，包含原表的整理附件不超过 48,000 字符。列名唯一且最多 40 字，单元格为单行文本；空数值保留为空，零仍是零。明确的全空 CSV 记录也保留，缺失 X 会拒绝绘制，不自动删行。纯空白物理行忽略。

列概况只描述可见输入：数值、文本 / 分类、混合或全空，另有缺失 / 不同值计数、数值范围、输入顺序是否单调及至多五个样本。不解析百分号、日期或带单位字符串，不自动换算，也不证明数据统计有效。全部原始单元格仍随本轮固定快照交给模型。

点线 / 柱状由模型按列别名选择 X、1–4 个 Y、可选误差列和数据行标注列。热图与箱线另按对应矩阵列 / 原始样本组规则映射。程序校验别名存在且用途不重叠，读取对应原始列，保留每行输入顺序、空值和误差含义；不接受模型提供的新数值、过滤、聚合或统计估计；不聚合的长表展开只通过待确认的 prepare 分支。箱线的固定描述统计由程序从原始样本计算。标注直接读取模型名等原始文字，每项最多 24 字，缺失 Y 的标注也不绘制。

目前可编译的形式：

| 形式 | 适用表达 | 边界 |
| --- | --- | --- |
| 折线 | 有序变化、训练过程、趋势 | 数值 X 按真实间距，最多 20 行且 X 唯一；分类 X 等距、最多 12 项；缺失处断线 |
| 分组柱状 | 分类条件下的数值对比 | 最多 12 行且分类唯一、包含零基线、按输入顺序排列 |
| 散点 | 两个数值变量的关系 | 最多 80 行、允许重复 X、不连线或拟合；可选模型名称标注 |
| 热图 | 同量纲矩阵的大小 / 正负模式 | 行标签和数值列按输入顺序，数值色阶 / 范围 / 中心，不归一化或聚类；零与缺失分开显示 |
| 箱线 | 原始重复样本的分布与离群点 | 使用者声明原始观测，唯一 Run 标识、1–6 组 / 80 行、每组至少 2 点；程序固定 type 7 / 1.5 IQR，始终保留离群点 |

总容量仍为 240 个图元，多系列、误差和标签可能先达到容量。误差路径分块保持每条路径不超过 128 个锚点。不会删点或缩小统计口径来凑图。

若最合适的是小提琴等尚未支持的形式，或需要先确认原始样本 / 分组 / 单位，模型可返回 `needs-input`：展示建议形式和问题，不生成误导性替代图。推荐的理由和图片风格解释来自模型；程序无法证明其选择最优或单位语义正确，仍由人审阅。密集标注的遮挡需要人工核对和调整。

## 实现

- `src/core/chartDataset.ts`：原始表契约、共享 CSV / TSV 解析和程序列概况。
- `chartRecommendationContract.ts`：严格的 `ready / multi-view / prepare / needs-input` 协议和逐图报告。
- `chartRecommendation.ts`：数据 / 图片选型提示，按映射编译候选，不接收模型图元或观测值。
- `dataChart.ts / dataChartSchema.ts`：数值散点、重复 X、误差分块和数据行标注，继续使用现有原生编辑 / 复用能力。
- `components/charts/ChartDataImportDialog.vue`、`components/harness/ChartRecommendation.vue`：导入检查和左侧推荐说明。

沿用 `/api/harness/runs`，新增可选 `chartData` 附件；与重建 / 分区修复和参考组件模式互斥。服务在本轮受限目录保存数据、提示和结果，图片通过两种适配器的原有图片通道实际发送。历史摘要仅保存附件规模和推荐报告，不重复整表。`chartRecommendation` 由服务校验、编译后进入完成事件和消息历史。

数据图表编辑器可用 `_label` 列修改行标注。有非空行标注的散点按系列名、标注和重复次序匹配观测；无标注时按 X、Y、误差和重复次序匹配。删除仍有外部连接的观测原子拒绝，避免将重复 X 的连接误移到另一条数据。
